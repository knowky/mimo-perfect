# 古典密码学章节

## 1. 引言：密码学的黎明

密码学作为保护信息安全的科学与艺术，其历史可追溯至人类文明早期。古典密码学是指20世纪现代密码学诞生前使用的加密方法，主要依赖手工或简单机械操作。这些密码虽然在现代看来安全性较低，但它们奠定了密码学的基础概念，并深刻影响了后续密码学的发展。

古典密码学的主要特点是：
- **依赖替代与置换**：基本操作包括字符替换和位置调换
- **计算简单性**：通常可通过纸笔或简单机械实现
- **算法相对简单**：密钥空间较小，容易被暴力破解
- **安全性依赖保密性**：通常基于"算法保密"而非"密钥保密"

## 2. 替换密码

### 2.1 单表替换密码

#### 2.1.1 凯撒密码（Caesar Cipher）

**历史背景**：凯撒密码由古罗马统帅尤利乌斯·凯撒使用，是他与将领通信时采用的加密方法。

**加密原理**：
- 将明文中的每个字母在字母表中向后移动固定位数
- 移动位数即为密钥（通常为3）
- 数学表示：$E(x) = (x + k) \mod 26$
  其中 $x$ 是明文字母的数字表示（A=0, B=1, ..., Z=25），$k$ 是密钥

**示例**：
- 明文：HELLO
- 密钥：3
- 加密过程：H→K, E→H, L→O, L→O, O→R
- 密文：KHOOR

**解密过程**：
- $D(y) = (y - k) \mod 26$

**安全性分析**：
- 密钥空间极小（仅25种可能）
- 容易通过频率分析破解
- 保留明文语言的统计特性

#### 2.1.2 仿射密码（Affine Cipher）

**加密原理**：
- 结合乘法和加法的线性变换
- 数学表示：$E(x) = (ax + b) \mod 26$
- 约束条件：$a$ 与26互质（确保解密唯一）

**示例**：
- 密钥：$a = 5$, $b = 8$
- 明文：HELLO
- 加密：H(7)→(5×7+8) mod 26 = 43 mod 26 = 17 → R
- 类似地：E→C, L→J, L→J, O→R
- 密文：RCJJR

**解密公式**：
- $D(y) = a^{-1}(y - b) \mod 26$
- 其中 $a^{-1}$ 是 $a$ 在模26下的乘法逆元

#### 2.1.3 简单替换密码（Simple Substitution）

**加密原理**：
- 创建随机的字母置换表
- 每个明文字母映射到一个固定的密文字母
- 密钥是整个置换表（$26!$ 种可能）

**示例**：
- 明文字母表：ABCDEFGHIJKLMNOPQRSTUVWXYZ
- 密文字母表：QWERTYUIOPASDFGHJKLZXCVBNM
- 明文：HELLO
- 密文：ITSSG

**安全性分析**：
- 密钥空间巨大（$26! ≈ 4×10^{26}$）
- 但仍可通过频率分析破解
- 保留双字母组合（digram）频率特性

### 2.2 多表替换密码

#### 2.2.1 维吉尼亚密码（Vigenère Cipher）

**历史背景**：由法国外交官布莱斯·德·维吉尼亚于1586年发明，曾被称为"不可破译的密码"。

**加密原理**：
- 使用一系列凯撒密码组成多表替换
- 密钥是重复使用的单词或短语
- 数学表示：$E_i(x) = (x + k_i) \mod 26$
- 其中 $k_i$ 是密钥的第 $i$ 个字母对应的数字

**示例**：
- 明文：ATTACKATDAWN
- 密钥：LEMON（重复使用）
- 密钥流：LEMONLEMONLE
- 加密过程：
  - A(0)+L(11)=L(11)
  - T(19)+E(4)=X(23)
  - T(19)+M(12)=F(5)
  - 等等
- 密文：LXFOPVEFRNHR

**解密过程**：
- $D_i(y) = (y - k_i) \mod 26$

**破解方法**：
1. 卡西斯基测试（Kasiski examination）：确定密钥长度
2. 频率分析：对每个位置分别进行单表分析

#### 2.2.2 自动密钥密码（Autokey Cipher）

**加密原理**：
- 改进维吉尼亚密码的密钥重复问题
- 密钥由种子+明文组成
- 数学表示：$E_i(x) = (x + k_i) \mod 26$
- 其中 $k_0$ 是种子，$k_i = x_{i-1}$（$i ≥ 1$）

**示例**：
- 明文：ATTACKATDAWN
- 种子：QUEEN
- 密钥流：QUEENATTACKATDAWN
- 加密后第一个字母：A+Q=Q，后续类似

## 3. 置换密码（换位密码）

### 3.1 列换位密码（Columnar Transposition）

**加密原理**：
1. 将明文按行写入固定宽度的矩阵
2. 按密钥指定的列顺序读出

**示例**：
- 明文：WEAREDISCOVEREDFLEEATONCE
- 密钥：312（列读出顺序为2,3,1）
- 矩阵排列：
  ```
  1 2 3
  W E A
  R E D
  I S C
  O V E
  R E D
  F L E
  E A T
  O N C
  E
  ```
- 按列2,3,1读出：EEOODRSEEEFRICAVDLETNWEAC

### 3.2 栅栏密码（Rail Fence Cipher）

**加密原理**：
1. 将明文字母写成对角线形式
2. 按行读出

**示例**：
- 明文：WEAREDISCOVEREDFLEEATONCE
- 栅栏数：2
- 排列：
  ```
  W E R D S O E E F E E T N E
   E A I C V R D L E A O C
  ```
- 密文：WERDSOEEFEETNE EAICVRDLEAOC

### 3.3 双换位密码（Double Transposition）

**加密原理**：
1. 进行两次列换位
2. 安全性明显高于单次换位

**历史应用**：二战期间被盟军广泛使用

## 4. 古典密码的分析与破解

### 4.1 频率分析法

**原理**：
- 自然语言中字母出现频率不均匀
- 英语中E、T、A等字母出现频率最高
- 通过分析密文字母频率，可以推断映射关系

**步骤**：
1. 统计密文字母频率
2. 与已知语言频率分布对比
3. 逐步推断映射关系

**示例**：英语字母频率分布
```
E: 12.70%   T: 9.06%   A: 8.17%   O: 7.51%   I: 6.97%
N: 6.75%    S: 6.33%   H: 6.09%   R: 5.99%   D: 4.25%
```

### 4.2 卡西斯基测试（Kasiski Examination）

**原理**：
- 寻找密文中重复的片段
- 重复片段间的距离可能是密钥长度的倍数
- 统计多个距离的最大公约数，推断密钥长度

### 4.3 重合指数法（Index of Coincidence）

**公式**：
$$IC = \frac{\sum_{i=0}^{25} n_i(n_i-1)}{N(N-1)}$$

**应用**：
- 英语文本IC值约为0.0667
- 随机文本IC值约为0.0385
- 通过IC值判断是否使用了多表密码

## 5. 机械密码机时代

### 5.1 恩尼格玛密码机（Enigma Machine）

**历史背景**：
- 20世纪20年代发明
- 二战期间纳粹德国使用
- 最终被布莱切利园破译

**加密原理**：
1. 转子组：3-4个可旋转的转子
2. 接线板（Steckerbrett）：交换特定字母对
3. 反射器：确保加密解密过程互逆

**工作流程**：
1. 电流从键盘输入
2. 经过接线板交换
3. 通过转子组（每个转子有不同的内部连线）
4. 被反射器反射，再次经过转子组
5. 返回接线板，点亮对应的灯

**安全性**：
- 转子初始位置：26³ = 17,576种（3个转子）
- 加上接线板配置：增加巨大密钥空间
- 但存在设计弱点，最终被图灵等人破解

### 5.2 其他机械密码机

- **TypeX密码机**：英国使用
- **SIGABA密码机**：美国使用
- **紫密码机**：日本使用

## 6. 古典密码的安全性评估

### 6.1 安全性度量

1. **密钥空间大小**：可能的密钥数量
2. **算法复杂性**：加密解密过程的复杂程度
3. **统计特性保留**：是否泄露语言统计特征
4. **对已知攻击的抵抗能力**

### 6.2 主要攻击方式

1. **唯密文攻击**：仅知密文，试图恢复明文
2. **已知明文攻击**：知道部分明文-密文对
3. **选择明文攻击**：可加密任意选择的明文
4. **选择密文攻击**：可解密任意选择的密文

## 7. 古典密码学的遗产与影响

### 7.1 对现代密码学的贡献

1. **概念奠基**：提出了密钥、加密、解密等基本概念
2. **算法思想**：替代与置换仍是现代密码的基本操作
3. **分析方法**：频率分析等思想在现代密码分析中仍有体现

### 7.2 教学价值

古典密码学作为密码学入门的优秀教材：
- 原理直观，易于理解
- 历史故事丰富，提高学习兴趣
- 展示密码学攻防的基本思想

### 7.3 现代应用中的古典思想

1. **教育演示**：用于教学和竞赛
2. **简单加密需求**：低安全要求场景
3. **文化符号**：出现在文学、影视作品中
4. **基础理解**：帮助理解现代密码学原理

## 8. 实验与实践

### 8.1 凯撒密码实现示例

```python
def caesar_encrypt(plaintext, shift):
    result = ""
    for char in plaintext:
        if char.isalpha():
            ascii_offset = 65 if char.isupper() else 97
            encrypted_char = chr((ord(char) - ascii_offset + shift) % 26 + ascii_offset)
            result += encrypted_char
        else:
            result += char
    return result

# 示例使用
message = "Hello, World!"
encrypted = caesar_encrypt(message, 3)
print(f"明文: {message}")
print(f"密文: {encrypted}")
```

### 8.2 维吉尼亚密码实现

```python
def vigenere_encrypt(plaintext, key):
    result = ""
    key_index = 0
    
    for char in plaintext:
        if char.isalpha():
            shift = ord(key[key_index % len(key)].upper()) - ord('A')
            if char.isupper():
                result += chr((ord(char) - ord('A') + shift) % 26 + ord('A'))
            else:
                result += chr((ord(char) - ord('a') + shift) % 26 + ord('a'))
            key_index += 1
        else:
            result += char
    
    return result

# 示例使用
message = "ATTACKATDAWN"
key = "LEMON"
encrypted = vigenere_encrypt(message, key)
print(f"明文: {message}")
print(f"密钥: {key}")
print(f"密文: {encrypted}")
```

## 9. 总结

古典密码学是密码学发展的必经阶段，虽然它们在现代计算机面前显得脆弱，但为现代密码学奠定了坚实的基础。通过研究古典密码，我们能够：

1. 理解密码学的基本概念和发展脉络
2. 学习密码设计与分析的基本思想
3. 认识到安全性需要数学严谨性，而非仅仅依赖复杂性
4. 为学习现代密码学做好准备

古典密码的故事也提醒我们：**没有绝对安全的密码，只有不断进步的密码学**。从简单的凯撒密码到复杂的现代加密算法，密码学始终在攻防博弈中不断发展。
