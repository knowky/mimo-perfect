## 概述

### 1.1 平台简介
CI/CD（持续集成/持续部署）流水线平台是一个自动化软件交付系统，用于实现代码的自动化构建、测试、部署和监控。本平台基于云原生架构设计，支持多环境部署，提供高度可扩展的流水线配置能力。

### 1.2 核心价值
- **自动化流程**：减少人工干预，提高软件交付效率
- **质量保障**：通过自动化测试确保代码质量
- **快速反馈**：开发人员能快速获得构建和测试结果
- **标准化部署**：确保各环境部署的一致性和可靠性
- **可观测性**：提供完整的流水线执行监控和日志

### 1.3 适用场景
- Web应用程序持续部署
- 微服务架构的自动化部署
- 移动应用自动化构建和发布
- 基础设施即代码（IaC）自动化管理
- 多环境（开发、测试、预生产、生产）部署

### 2.2 组件详解

## 核心功能

### 3.1 流水线管理

#### 3.1.1 流水线定义
支持通过YAML文件定义流水线：
```yaml
# pipeline.yaml
name: my-application
stages:
  - build:
      image: maven:3.8.4-openjdk-11
      script:
        - mvn clean package
      artifacts:
        - target/*.jar
  
  - test:
      image: maven:3.8.4-openjdk-11
      script:
        - mvn test
      needs: [build]
  
  - deploy-staging:
      image: kubectl:latest
      script:
        - kubectl apply -f k8s/staging/
      needs: [test]
      environment: staging
  
  - deploy-production:
      image: kubectl:latest
      script:
        - kubectl apply -f k8s/production/
      needs: [deploy-staging]
      environment: production
      manual_approval: true
```

#### 3.1.2 触发机制
- **代码触发**：Git push、Pull Request事件
- **定时触发**：Cron表达式配置
- **手动触发**：Web界面手动启动
- **外部触发**：Webhook回调
- **依赖触发**：上游流水线完成触发

### 3.2 构建管理

#### 3.2.1 多语言支持

- Node.js (npm/yarn)
- Python (pip/poetry)
- Go

#### 3.2.2 构建环境

## 配置说明

### 5.1 流水线配置

#### 5.1.1 完整配置示例
```yaml
# 完整的流水线配置示例
name: fullstack-app
description: "全栈应用程序CI/CD流水线"

# 全局配置
global:
  timeout: 3600
  retry: 2
  cancel_on_failure: false
  notifications:
    on_success:
      - type: slack
        channel: "#deployments"
      - type: email
        to: ["devops@company.com"]
    on_failure:
      - type: slack
        channel: "#alerts"
      - type: pagerduty
        service: "APP-SERVICE"

# 变量定义
variables:
  APP_NAME: "my-fullstack-app"
  REGISTRY: "registry.example.com"
  KUBECONFIG: "/etc/kubeconfig/prod.yaml"
  
  # 环境特定变量
  staging:
    DB_HOST: "staging-db.example.com"
    ENVIRONMENT: "staging"
  production:
    DB_HOST: "prod-db.example.com"
    ENVIRONMENT: "production"

# 阶段定义
stages:
  # 代码质量检查
  - quality:
      parallel: true
      steps:
        - name: lint
          image: node:16
          script:
            - npm install
            - npm run lint
        
        - name: format-check
          image: node:16
          script:
            - npm run format:check
        
        - name: security-audit
          image: node:16
          script:
            - npm audit --audit-level=high
          allow_failure: true

  # 构建阶段
  - build:
      needs: [quality]
      steps:
        - name: build-backend
          image: maven:3.8.4-openjdk-11
          script:
            - cd backend
            - mvn clean package -DskipTests
          artifacts:
            paths:
              - backend/target/*.jar
            expire_in: "1 week"
        
        - name: build-frontend
          image: node:16
          script:
            - cd frontend
            - npm install
            - npm run build
          artifacts:
            paths:
              - frontend/dist/
            expire_in: "1 week"
        
        - name: build-docker
          image: docker:20.10
          script:
            - docker build -t $REGISTRY/$APP_NAME:$CI_COMMIT_SHA .
            - docker push $REGISTRY/$APP_NAME:$CI_COMMIT_SHA
          services:
            - docker:dind

  # 测试阶段
  - test:
      needs: [build]
      steps:
        - name: unit-tests
          image: maven:3.8.4-openjdk-11
          script:
            - cd backend
            - mvn test
          artifacts:
            reports:
              junit: backend/target/surefire-reports/*.xml
              coverage: backend/target/site/jacoco/
          coverage_threshold: 80%
        
        - name: integration-tests
          image: maven:3.8.4-openjdk-11
          script:
            - cd backend
            - mvn verify -P integration
          services:
            - postgres:13
            - redis:6
          timeout: 15m
        
        - name: e2e-tests
          image: cypress/included:10.0.0
          script:
            - cd frontend
            - npx cypress run
          artifacts:
            paths:
              - frontend/cypress/videos/
              - frontend/cypress/screenshots/
            expire_in: "3 days"

  # 部署到预发布环境
  - deploy-staging:
      needs: [test]
      environment:
        name: staging
        url: https://staging.example.com
      steps:
        - name: deploy
          image: bitnami/kubectl:1.23
          script:
            - kubectl config use-context staging
            - kubectl apply -f k8s/staging/
            - kubectl rollout status deployment/$APP_NAME -n staging
          variables:
            IMAGE_TAG: $CI_COMMIT_SHA

  # 部署到生产环境（需手动审批）
  - deploy-production:
      needs: [deploy-staging]
      environment:
        name: production
        url: https://www.example.com
      manual_approval: true
      approval_users: ["admin@example.com", "release-manager@example.com"]
      steps:
        - name: canary-deploy
          image: bitnami/kubectl:1.23
          script:
            - kubectl config use-context production
            - kubectl apply -f k8s/production/canary.yaml
            - sleep 300  # 金丝雀发布监控5分钟
            - kubectl apply -f k8s/production/full.yaml
          when: manual
          allow_failure: false

# 部署后操作
post_deploy:
  smoke_test:
    script:
      - curl -f https://www.example.com/health
    timeout: 5m
  
  notification:
    script:
      - echo "Deploy to production completed"
    notifications:
      - type: slack
        message: "🚀 Production deployment completed successfully!"
      - type: webhook
        url: https://hooks.example.com/deploy-complete
```

### 6.3 流水线运行

    """根据代码变更动态生成流水线配置"""
    changed_files = get_changed_files()
    
    pipeline = {
        'stages': []
    }
    
    if any(f.endswith('.java') for f in changed_files):
        pipeline['stages'].append({
            'name': 'java-build',
            'image': 'maven:3.8.4-openjdk-11',
            'script': ['mvn clean package']
        })
    
    if any(f.startswith('frontend/') for f in changed_files):
        pipeline['stages'].append({
            'name': 'frontend-build',
            'image': 'node:16',
            'script': ['npm install', 'npm run build']
        })
    
    return pipeline
```

## 1. 概述

回滚机制是CI/CD流水线的关键组成部分，确保在部署失败或应用程序出现问题时能够快速恢复到稳定状态。本文档详细设计并实现一套完整的回滚机制。

## 2. 核心设计原则

### 2.1 快速回滚
- 目标：在5分钟内完成回滚操作
- 保证最小的服务中断时间
- 自动化回滚流程，减少人工干预

### 2.2 可追溯性
- 完整记录所有部署和回滚操作
- 支持任意版本回滚能力
- 保留完整的审计日志

### 2.3 安全性
- 基于角色的回滚权限控制
- 双人复核机制（可选）
- 回滚前的完整性校验

# rollback_trigger.py
import logging
from datetime import datetime

class RollbackTrigger:
    def __init__(self, monitoring_client, deployment_manager):
        self.monitoring = monitoring_client
        self.deployment = deployment_manager
        self.thresholds = {
            'error_rate': 5.0,      # 错误率超过5%
            'response_time': 2000,   # 响应时间超过2秒
            'cpu_usage': 80.0,      # CPU使用率超过80%
            'memory_usage': 85.0,   # 内存使用率超过85%
            'success_rate': 95.0    # 成功率低于95%
        }
    
    def check_health_metrics(self, deployment_id):
        """检查部署后的健康指标"""
        metrics = self.monitoring.get_current_metrics(deployment_id)
        
        triggers = []
        
        if metrics['error_rate'] > self.thresholds['error_rate']:
            triggers.append(f"错误率过高: {metrics['error_rate']}%")
        
        if metrics['response_time'] > self.thresholds['response_time']:
            triggers.append(f"响应时间过长: {metrics['response_time']}ms")
        
        return triggers
    
    def should_rollback(self, deployment_id, time_window=300):
        """判断是否应该回滚（5分钟窗口）"""
        issues = self.check_health_metrics(deployment_id)
        
        if issues:
            logging.warning(f"检测到部署问题: {issues}")
            
            # 检查问题是否持续存在
            if self.monitoring.is_issue_persistent(deployment_id, time_window):
                logging.error("问题持续存在，触发自动回滚")
                return True, issues
        
        return False, []
    
    def auto_rollback(self, deployment_id):
        """执行自动回滚"""
        should_rollback, reasons = self.should_rollback(deployment_id)
        
        if should_rollback:
            # 发送告警通知
            self.send_alert(deployment_id, reasons)
            
            # 执行回滚
            rollback_result = self.deployment.rollback(deployment_id)
            
            # 记录回滚事件
            self.log_rollback_event(deployment_id, reasons, rollback_result)
            
            return rollback_result
        
        return None
    
    def send_alert(self, deployment_id, reasons):
        """发送回滚告警"""
        alert_message = f"""
        ⚠️ 自动回滚已触发
        部署ID: {deployment_id}
        时间: {datetime.now()}
        原因: {', '.join(reasons)}
        """
        # 实现告警通知逻辑（邮件、Slack、钉钉等）
        pass
    
    def log_rollback_event(self, deployment_id, reasons, result):
        """记录回滚事件"""
        log_entry = {
            'event_type': 'auto_rollback',
            'deployment_id': deployment_id,
            'timestamp': datetime.now().isoformat(),
            'reasons': reasons,
            'result': result,
            'operator': 'system'
        }

#!/bin/bash
# k8s-rollback.sh

set -e

NAMESPACE="production"
DEPLOYMENT="myapp"
REVISION=${1:-"previous"}  # 默认回滚到上一个版本

echo "开始Kubernetes回滚操作..."

# 获取当前部署信息
CURRENT_REVISION=$(kubectl rollout history deployment/$DEPLOYMENT -n $NAMESPACE | tail -2 | head -1 | awk '{print $1}')
echo "当前版本: $CURRENT_REVISION"

if [ "$REVISION" = "previous" ]; then
    # 回滚到上一个版本
    echo "执行回滚到上一个版本..."
    kubectl rollout undo deployment/$DEPLOYMENT -n $NAMESPACE
else
    # 回滚到指定版本
    echo "执行回滚到版本 $REVISION..."
    kubectl rollout undo deployment/$DEPLOYMENT -n $NAMESPACE --to-revision=$REVISION
fi

# 等待回滚完成
echo "等待回滚完成..."
kubectl rollout status deployment/$DEPLOYMENT -n $NAMESPACE --timeout=300s

if [ $? -eq 0 ]; then
    echo "✅ 回滚成功完成"
    
    # 验证回滚后的版本
    NEW_REVISION=$(kubectl rollout history deployment/$DEPLOYMENT -n $NAMESPACE | tail -2 | head -1 | awk '{print $1}')
    echo "回滚后的版本: $NEW_REVISION"
    
    # 执行健康检查
    echo "执行回滚后健康检查..."
    kubectl get pods -n $NAMESPACE -l app=$DEPLOYMENT
else
    echo "❌ 回滚失败或超时"
    exit 1
fi

# argocd_rollback.py
import requests
import json

class ArgoCDRollback:
    def __init__(self, argo_server, auth_token):
        self.server = argo_server
        self.token = auth_token
        self.headers = {
            'Authorization': f'Bearer {self.token}',
            'Content-Type': 'application/json'
        }
    
    def get_application_history(self, app_name):
        """获取应用版本历史"""
        url = f"{self.server}/api/v1/applications/{app_name}/revisions"
        response = requests.get(url, headers=self.headers)
        
        if response.status_code == 200:
            return response.json()['revisions']
        else:
            raise Exception(f"获取版本历史失败: {response.text}")
    
    def rollback_to_revision(self, app_name, revision):
        """回滚到指定版本"""
        url = f"{self.server}/api/v1/applications/{app_name}/rollback"
        
        payload = {
            "name": app_name,
            "id": revision,
            "prune": True
        }
        
        response = requests.post(url, headers=self.headers, json=payload)
        
        if response.status_code == 200:
            print(f"✅ 回滚到版本 {revision} 成功")
            return response.json()
        else:
            raise Exception(f"回滚失败: {response.text}")
    
    def auto_rollback_on_sync_failure(self, app_name):
        """同步失败时自动回滚"""
        # 获取最新同步状态
        app_info = self.get_application_status(app_name)
        
        if app_info['status']['sync']['status'] == 'OutOfSync':
            if app_info['status']['health']['status'] == 'Degraded':
                # 获取上一个成功版本
                history = self.get_application_history(app_name)
                if len(history) > 1:
                    previous_revision = history[-2]['revision']
                    return self.rollback_to_revision(app_name, previous_revision)
        
        return None
```

CI/CD 流水线平台主入口

from pipeline.engine import PipelineEngine
from pipeline.scheduler import PipelineScheduler
from api.routes import create_api_server

class CICDPlatform:

        """
        初始化 CI/CD 平台
        
        Args:
            config_path: 配置文件路径
        """
        self.config_path = config_path
        self.config = None
        self.engine = None
        self.scheduler = None
        self.api_server = None
        self.running = False

        try:
            # 加载配置

            logger.info("配置加载完成")
            
            # 初始化流水线引擎
            self.engine = PipelineEngine(self.config)
            await self.engine.initialize()
            logger.info("流水线引擎初始化完成")
            
            # 初始化调度器
            self.scheduler = PipelineScheduler(self.engine)
            await self.scheduler.initialize()
            logger.info("调度器初始化完成")
            
            # 初始化 API 服务器
            self.api_server = create_api_server(self.engine, self.scheduler)
            logger.info("API 服务器初始化完成")
            
            self.running = True
            logger.info("CI/CD 平台初始化成功")
            
        except Exception as e:
            logger.error(f"初始化失败: {e}")
            raise
            
    async def start(self):
        """启动平台"""
        logger.info("正在启动 CI/CD 平台...")
        
        # 启动组件
        tasks = [
            self.scheduler.start(),
            self.api_server.start()
        ]
        
        # 注册信号处理
        self._register_signal_handlers()
        
        # 启动所有组件
        await asyncio.gather(*tasks)
        
    def _register_signal_handlers(self):
        """注册信号处理器"""
        signal.signal(signal.SIGINT, self._handle_shutdown)
        signal.signal(signal.SIGTERM, self._handle_shutdown)
        
    def _handle_shutdown(self, signum, frame):
        """处理关闭信号"""
        logger.info(f"收到信号 {signum}，正在关闭平台...")
        self.running = False
        asyncio.create_task(self.shutdown())
        
    async def shutdown(self):
        """关闭平台"""
        logger.info("正在关闭 CI/CD 平台...")
        
        if self.scheduler:
            await self.scheduler.stop()
            
        if self.api_server:
            await self.api_server.stop()
            
        logger.info("CI/CD 平台已关闭")

async def main():
    """主函数"""
    platform = CICDPlatform()
    
    try:
        await platform.initialize()
        await platform.start()

        logger.info("收到键盘中断信号")
    except Exception as e:
        logger.error(f"运行时错误: {e}")
    finally:
        await platform.shutdown()

### `src/pipeline/engine.py`
```python
"""
流水线引擎 - 核心调度和执行引擎
"""

import asyncio
import uuid
from datetime import datetime
from typing import Dict, List, Optional, Any
from enum import Enum

from .stage import PipelineStage, StageStatus
from .executor import PipelineExecutor
from agents.base_agent import BaseAgent
from utils.logger import setup_logger
from utils.helpers import generate_id

logger = setup_logger(__name__)

class PipelineStatus(Enum):
    """流水线状态枚举"""
    PENDING = "pending"
    RUNNING = "running"
    SUCCESS = "success"
    FAILED = "failed"
    CANCELLED = "cancelled"
    TIMEOUT = "timeout"

class PipelineContext:
    """流水线上下文"""
    
    def __init__(self, pipeline_id: str, config: Dict[str, Any]):
        """
        初始化流水线上下文
        
        Args:
            pipeline_id: 流水线ID
            config: 流水线配置
        """
        self.pipeline_id = pipeline_id
        self.config = config
        self.variables = {}
        self.artifacts = []
        self.metrics = {
            'start_time': None,
            'end_time': None,
            'duration': 0,
            'stages_completed': 0,
            'stages_total': len(config.get('stages', {}))
        }
        
    def set_variable(self, key: str, value: Any):
        """设置变量"""
        self.variables[key] = value
        
    def get_variable(self, key: str, default: Any = None) -> Any:
        """获取变量"""
        return self.variables.get(key, default)
        
    def add_artifact(self, artifact: Dict[str, Any]):
        """添加制品"""
        self.artifacts.append(artifact)

class PipelineEngine:
    """流水线引擎主类"""
    
    def __init__(self, config: Dict[str, Any]):
        """
        初始化流水线引擎
        
        Args:
            config: 全局配置
        """
        self.config = config
        self.pipelines: Dict[str, Dict] = {}
        self.active_pipelines: Dict[str, asyncio.Task] = {}
        self.executor = PipelineExecutor()
        self.agent_registry: Dict[str, BaseAgent] = {}
        self.lock = asyncio.Lock()
        
    async def initialize(self):
        """初始化引擎"""
        logger.info("正在初始化流水线引擎...")
        
        # 初始化执行器
        await self.executor.initialize()
        
        # 初始化代理注册表
        await self._init_agents()
        
        logger.info("流水线引擎初始化完成")
        
    async def _init_agents(self):
        """初始化代理"""
        # 动态导入和初始化代理
        from agents.build_agent import BuildAgent
        from agents.test_agent import TestAgent
        from agents.deploy_agent import DeployAgent
        
        self.agent_registry = {
            'build': BuildAgent(),
            'test': TestAgent(),
            'deploy': DeployAgent()
        }
        
        # 初始化所有代理
        for agent in self.agent_registry.values():
            await agent.initialize()
            
    async def create_pipeline(self, 
                            name: str, 
                            stages_config: List[Dict],
                            environment: str = "development") -> str:
        """
        创建新的流水线
        
        Args:
            name: 流水线名称
            stages_config: 阶段配置
            environment: 目标环境
            
        Returns:
            流水线ID
        """
        async with self.lock:
            pipeline_id = generate_id()
            
            # 创建阶段对象
            stages = []
            for i, stage_config in enumerate(stages_config):
                stage = PipelineStage(
                    name=stage_config['name'],
                    order=stage_config.get('order', i),
                    config=stage_config,
                    environment=environment
                )
                stages.append(stage)
                
            # 按顺序排序阶段
            stages.sort(key=lambda s: s.order)
            
            pipeline = {
                'id': pipeline_id,
                'name': name,
                'stages': stages,
                'status': PipelineStatus.PENDING.value,
                'environment': environment,
                'created_at': datetime.utcnow().isoformat(),
                'updated_at': datetime.utcnow().isoformat(),
                'context': PipelineContext(pipeline_id, self.config)
            }
            
            self.pipelines[pipeline_id] = pipeline
            logger.info(f"创建流水线: {pipeline_id} - {name}")
            
            return pipeline_id
            
    async def execute_pipeline(self, 
                             pipeline_id: str, 
                             variables: Optional[Dict] = None) -> Dict:
        """
        执行流水线
        
        Args:
            pipeline_id: 流水线ID
            variables: 流水线变量
            
        Returns:
            执行结果
        """
        if pipeline_id not in self.pipelines:
            raise ValueError(f"流水线 {pipeline_id} 不存在")
            
        pipeline = self.pipelines[pipeline_id]
        
        # 检查是否已在执行
        if pipeline_id in self.active_pipelines:
            raise ValueError(f"流水线 {pipeline_id} 正在执行中")
            
        # 设置变量
        if variables:
            for key, value in variables.items():
                pipeline['context'].set_variable(key, value)
                
        # 更新状态
        pipeline['status'] = PipelineStatus.RUNNING.value
        pipeline['context'].metrics['start_time'] = datetime.utcnow()
        
        # 创建执行任务
        task = asyncio.create_task(
            self._run_pipeline(pipeline)
        )
        self.active_pipelines[pipeline_id] = task
        
        logger.info(f"开始执行流水线: {pipeline_id}")
        
        # 等待任务完成或返回
        try:
            result = await task
            return result
        except Exception as e:
            logger.error(f"流水线执行失败: {pipeline_id} - {e}")
            pipeline['status'] = PipelineStatus.FAILED.value
            raise
        finally:
            if pipeline_id in self.active_pipelines:
                del self.active_pipelines[pipeline_id]
                
    async def _run_pipeline(self, pipeline: Dict) -> Dict:
        """
        运行流水线内部逻辑
        
        Args:
            pipeline: 流水线数据
            
        Returns:
            运行结果
        """
        pipeline_id = pipeline['id']
        context = pipeline['context']
        
        try:
            # 执行所有阶段
            for stage in pipeline['stages']:
                if not stage.enabled:
                    logger.info(f"跳过禁用的阶段: {stage.name}")
                    continue
                    
                # 执行阶段
                stage_result = await self._execute_stage(stage, context)
                
                # 检查阶段执行结果
                if stage_result['status'] != StageStatus.SUCCESS.value:
                    if stage_result.get('continue_on_failure', False):
                        logger.warning(f"阶段 {stage.name} 失败，但继续执行")
                    else:
                        logger.error(f"阶段 {stage.name} 失败，停止执行")
                        raise Exception(f"阶段 {stage.name} 执行失败")
                        
                # 更新上下文
                context.metrics['stages_completed'] += 1
                
                # 等待阶段间冷却时间
                await asyncio.sleep(1)
                
            # 流水线成功完成
            pipeline['status'] = PipelineStatus.SUCCESS.value
            context.metrics['end_time'] = datetime.utcnow()
            context.metrics['duration'] = (
                context.metrics['end_time'] - 
                context.metrics['start_time']
            ).total_seconds()
            
            logger.info(f"流水线 {pipeline_id} 执行成功")
            
            return {
                'pipeline_id': pipeline_id,
                'status': PipelineStatus.SUCCESS.value,
                'metrics': context.metrics,
                'artifacts': context.artifacts
            }
            
        except Exception as e:
            logger.error(f"流水线 {pipeline_id} 执行失败: {e}")
            pipeline['status'] = PipelineStatus.FAILED.value
            context.metrics['end_time'] = datetime.utcnow()
            context.metrics['duration'] = (
                context.metrics['end_time'] - 
                context.metrics['start_time']
            ).total_seconds()
            
            return {
                'pipeline_id': pipeline_id,
                'status': PipelineStatus.FAILED.value,
                'error': str(e),
                'metrics': context.metrics
            }
            
    async def _execute_stage(self, 
                           stage: PipelineStage, 
                           context: PipelineContext) -> Dict:
        """
        执行单个阶段
        
        Args:
            stage: 阶段对象
            context: 流水线上下文
            
        Returns:
            阶段执行结果
        """
        logger.info(f"执行阶段: {stage.name}")
        stage.status = StageStatus.RUNNING
        
        try:
            # 获取阶段配置
            stage_config = stage.config
            
            # 根据阶段类型选择代理
            agent_type = stage_config.get('type', 'build')
            agent = self.agent_registry.get(agent_type)
            
            if not agent:
                raise ValueError(f"未找到代理: {agent_type}")
                
            # 准备阶段参数
            parameters = stage_config.get('parameters', {})
            parameters['context'] = context
            parameters['environment'] = stage.environment
            
            # 执行阶段
            result = await agent.execute(
                task_name=stage.name,
                parameters=parameters
            )
            
            # 更新阶段状态
            stage.status = StageStatus.SUCCESS
            stage.result = result
            
            logger.info(f"阶段 {stage.name} 执行成功")
            
            return {
                'stage_name': stage.name,
                'status': StageStatus.SUCCESS.value,
                'result': result,
                'continue_on_failure': stage_config.get('continue_on_failure', False)
            }
            
        except Exception as e:
            logger.error(f"阶段 {stage.name} 执行失败: {e}")
            stage.status = StageStatus.FAILED
            stage.error = str(e)
            
            return {
                'stage_name': stage.name,
                'status': StageStatus.FAILED.value,
                'error': str(e),
                'continue_on_failure': stage.config.get('continue_on_failure', False)
            }
            
    async def get_pipeline_status(self, pipeline_id: str) -> Dict:
        """
        获取流水线状态
        
        Args:
            pipeline_id: 流水线ID
            
        Returns:
            流水线状态信息
        """
        if pipeline_id not in self.pipelines:
            raise ValueError(f"流水线 {pipeline_id} 不存在")
            
        pipeline = self.pipelines[pipeline_id]
        
        # 收集阶段状态
        stages_status = []
        for stage in pipeline['stages']:
            stages_status.append({
                'name': stage.name,
                'status': stage.status.value,
                'order': stage.order,
                'error': stage.error
            })
            
        return {
            'pipeline_id': pipeline_id,
            'name': pipeline['name'],
            'status': pipeline['status'],
            'stages': stages_status,
            'metrics': pipeline['context'].metrics,
            'created_at': pipeline['created_at'],
            'updated_at': pipeline['updated_at']
        }
        
    async def cancel_pipeline(self, pipeline_id: str) -> bool:
        """
        取消流水线执行
        
        Args:
            pipeline_id: 流水线ID
            
        Returns:
            是否取消成功
        """
        if pipeline_id not in self.active_pipelines:
            return False
            
        task = self.active_pipelines[pipeline_id]
        
        # 取消任务
        task.cancel()
        
        # 更新状态
        if pipeline_id in self.pipelines:
            self.pipelines[pipeline_id]['status'] = PipelineStatus.CANCELLED.value
            
        logger.info(f"取消流水线: {pipeline_id}")
        return True
        
    async def get_metrics(self) -> Dict:
        """
        获取引擎指标
        
        Returns:
            引擎指标信息
        """
        total_pipelines = len(self.pipelines)
        active_pipelines = len(self.active_pipelines)
        successful_pipelines = len([p for p in self.pipelines.values() 
                                  if p['status'] == PipelineStatus.SUCCESS.value])
        failed_pipelines = len([p for p in self.pipelines.values() 
                              if p['status'] == PipelineStatus.FAILED.value])
        
        return {
            'total_pipelines': total_pipelines,
            'active_pipelines': active_pipelines,
            'successful_pipelines': successful_pipelines,
            'failed_pipelines': failed_pipelines,
            'success_rate': successful_pipelines / total_pipelines if total_pipelines > 0 else 0,
            'failure_rate': failed_pipelines / total_pipelines if total_pipelines > 0 else 0
        }

    async def execute_command(self, 
                            command: str,
                            cwd: Optional[str] = None,
                            environment: Optional[Dict] = None,
                            timeout: int = 3600) -> Dict:
        """
        执行命令
        
        Args:
            command: 要执行的命令
            cwd: 工作目录
            environment: 环境变量
            timeout: 超时时间（秒）
            
        Returns:
            执行结果
        """
        async with self.semaphore:
            logger.info(f"执行命令: {command}")
            
            # 准备环境
            env = os.environ.copy()
            if environment:
                env.update(environment)
                
            try:
                # 创建子进程
                process = await asyncio.create_subprocess_shell(
                    command,
                    cwd=cwd,
                    env=env,
                    stdout=asyncio.subprocess.PIPE,
                    stderr=asyncio.subprocess.PIPE
                )
                
                # 等待进程完成或超时
                try:
                    stdout, stderr = await asyncio.wait_for(
                        process.communicate(),
                        timeout=timeout
                    )
                except asyncio.TimeoutError:
                    # 超时，终止进程
                    process.kill()
                    await process.wait()
                    return {
                        'returncode': -1,
                        'stdout': stdout.decode() if stdout else '',
                        'stderr': stderr.decode() if stderr else '',
                        'timeout': True,
                        'error': '命令执行超时'
                    }
                    
                # 解码输出
                stdout_str = stdout.decode('utf-8', errors='replace')
                stderr_str = stderr.decode('utf-8', errors='replace')
                
                result = {
                    'returncode': process.returncode,
                    'stdout': stdout_str,
                    'stderr': stderr_str,
                    'timeout': False
                }
                
                if process.returncode != 0:
                    result['error'] = f"命令执行失败，返回码: {process.returncode}"
                    
                return result
                
            except Exception as e:
                logger.error(f"命令执行异常: {e}")
                return {
                    'returncode': -1,
                    'stdout': '',
                    'stderr': str(e),
                    'timeout': False,
                    'error': str(e)
                }

            执行结果

        script_file = self.temp_dir / f"script_{os.getpid()}.{script_type}"
        
        try:
            # 写入脚本文件
            script_file.write_text(script_content)
            script_file.chmod(0o755)
            
            # 构建执行命令
            if script_type == "bash":
                command = f"bash {script_file}"
            elif script_type == "python":
                command = f"python {script_file}"
            elif script_type == "node":
                command = f"node {script_file}"
            else:
                command = f"sh {script_file}"
                
            # 执行脚本
            result = await self.execute_command(command, **kwargs)
            
            return result
            
        finally:
            # 清理临时文件
            script_file.unlink(missing_ok=True)

    case_id: str

    error_message: str = None
    performance_data: Dict = None
    artifacts: List[str] = None

class TestExecutionEngine:
    """测试执行引擎"""
    
    def __init__(self, max_workers: int = 10):
        self.max_workers = max_workers
        self.docker_client = docker.from_env()
        self.executor = concurrent.futures.ThreadPoolExecutor(max_workers=max_workers)
        self.results = []
        
    async def execute_parallel_tests(self, test_cases: List[Dict], 
                                    environment: TestEnvironment) -> List[TestResult]:
        """并行执行测试用例"""
        loop = asyncio.get_event_loop()
        tasks = []
        
        for case in test_cases:
            task = loop.run_in_executor(
                self.executor,
                self._execute_single_test,
                case,
                environment
            )
            tasks.append(task)
        
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        # 处理异常结果
        processed_results = []
        for i, result in enumerate(results):
            if isinstance(result, Exception):
                processed_results.append(TestResult(
                    case_id=test_cases[i]['id'],
                    status='error',
                    duration=0,
                    error_message=str(result)
                ))
            else:
                processed_results.append(result)
        
        return processed_results
    
    def _execute_single_test(self, test_case: Dict, 
                           environment: TestEnvironment) -> TestResult:
        """执行单个测试用例"""
        start_time = time.time()
        
        try:
            # 创建测试容器
            container = self._create_test_container(test_case, environment)
            
            # 执行测试
            exit_code, output = container.exec_run(
                test_case.get('test_command', 'pytest'),
                workdir='/app'
            )
            
            # 收集测试产物
            artifacts = self._collect_artifacts(container, test_case)
            
            # 计算持续时间
            duration = time.time() - start_time
            
            return TestResult(
                case_id=test_case['id'],
                status='passed' if exit_code == 0 else 'failed',
                duration=duration,
                error_message=output.decode('utf-8') if exit_code != 0 else None,
                artifacts=artifacts
            )
            
        except Exception as e:
            return TestResult(
                case_id=test_case['id'],
                status='error',
                duration=time.time() - start_time,
                error_message=str(e)
            )
        finally:
            # 清理容器
            if 'container' in locals():
                container.remove(force=True)
    
    def _create_test_container(self, test_case: Dict, 
                             environment: TestEnvironment) -> docker.models.containers.Container:
        """创建测试容器"""
        container_config = {
            'image': environment.container_image,
            'environment': environment.environment_vars,
            'volumes': environment.volumes,
            'detach': True,
            'labels': {
                'test_case_id': test_case['id'],
                'test_type': test_case['type'],
                'pipeline_id': test_case.get('pipeline_id')
            }
        }
        
        # 添加资源限制
        if environment.resource_limits:
            container_config['mem_limit'] = environment.resource_limits.get('memory')
            container_config['cpu_period'] = 100000
            container_config['cpu_quota'] = int(environment.resource_limits.get('cpu', '1.0') * 100000)
        
        return self.docker_client.containers.run(**container_config)

            '/app/reports/*.json',

        ]

                self._save_tar_stream(tar_stream, artifact_path)
                artifacts.append(artifact_path)
            except:
                continue
        
        return artifacts

                            test_cases: List[Dict]) -> List[Dict]:
        """分析代码变更影响"""
        impacted_tests = []
        
        for test_case in test_cases:
            # 计算变更文件与测试用例的关联度
            impact_score = self._calculate_impact_score(
                changed_files, 
                test_case.get('associated_files', []),
                test_case.get('test_type')
            )
            
            if impact_score > 0.3:  # 阈值可配置
                test_case['impact_score'] = impact_score
                test_case['priority_score'] = self._calculate_priority_score(test_case)
                impacted_tests.append(test_case)
        
        # 按优先级排序
        impacted_tests.sort(
            key=lambda x: (x['priority_score'], x['impact_score']), 
            reverse=True
        )
        
        return impacted_tests
    
    def _calculate_impact_score(self, changed_files: List[str], 
                              associated_files: List[str],
                              test_type: str) -> float:
        """计算影响分数"""
        if not associated_files:
            return 0.0
        
        # 文件路径相似度计算
        intersection = set(changed_files) & set(associated_files)
        union = set(changed_files) | set(associated_files)
        
        if not union:
            return 0.0
        
        jaccard_similarity = len(intersection) / len(union)
        
        # 根据测试类型调整权重
        type_weights = {
            'unit': 1.0,
            'integration': 1.5,
            'api': 1.2,
            'e2e': 2.0,
            'performance': 0.8,
            'security': 1.3
        }
        
        weight = type_weights.get(test_type, 1.0)
        
        return jaccard_similarity * weight
    
    def _calculate_priority_score(self, test_case: Dict) -> float:
        """计算优先级分数"""
        priority_weights = {
            'critical': 4.0,
            'high': 3.0,
            'medium': 2.0,
            'low': 1.0
        }
        
        base_score = priority_weights.get(test_case.get('priority', 'medium'), 2.0)
        
        # 考虑历史失败率
        failure_rate = test_case.get('historical_failure_rate', 0.1)
        history_factor = 1 + failure_rate * 2
        
        # 考虑测试持续时间（快速测试优先）
        duration_factor = 1 / (1 + test_case.get('avg_duration', 30) / 60)
        
        return base_score * history_factor * duration_factor
    
    def schedule_tests_for_pipeline(self, pipeline_context: Dict) -> Dict:
        """为流水线调度测试"""
        strategy = self._determine_test_strategy(pipeline_context)
        
        scheduled_tests = {
            'fast_tests': [],      # 快速测试（单元测试、少量集成测试）
            'standard_tests': [],  # 标准测试
            'full_tests': [],      # 完整测试
            'performance_tests': [],  # 性能测试
            'security_tests': []   # 安全测试
        }
        
        # 根据策略分配测试
        for test_case in pipeline_context.get('test_cases', []):
            category = self._categorize_test(test_case, strategy)
            scheduled_tests[category].append(test_case)
        
        return scheduled_tests
    
    def _determine_test_strategy(self, context: Dict) -> str:
        """确定测试策略"""
        change_type = context.get('change_type', 'feature')
        branch = context.get('branch', 'main')
        time_of_day = datetime.now().hour
        
        # 基于规则的策略选择
        if change_type == 'hotfix':
            return 'fast'
        elif branch == 'main':
            return 'full'
        elif 9 <= time_of_day <= 17:  # 工作时间
            return 'standard'
        else:
            return 'full'  # 非工作时间运行完整测试

import docker

            return self._provision_docker_environment(config)
        elif self.environment_type == 'kubernetes':
            return self._provision_k8s_environment(config)
        else:
            raise ValueError(f"Unsupported environment type: {self.environment_type}")
    
    def _provision_docker_environment(self, config: Dict) -> str:
        """ provision Docker 测试环境 """
        network_name = f"test_network_{config['test_id']}"
        
        # 创建网络
        network = self.client.networks.create(network_name, driver='bridge')
        
        # 启动服务
        services = {}
        for service_name, service_config in config.get('services', {}).items():
            container = self.client.containers.run(
                image=service_config['image'],
                name=f"{config['test_id']}_{service_name}",
                network=network_name,
                environment=service_config.get('environment', {}),
                ports=service_config.get('ports', {}),
                volumes=service_config.get('volumes', {}),
                detach=True,
                healthcheck=service_config.get('healthcheck')
            )
            services[service_name] = container
        
        # 等待服务就绪
        self._wait_for_services_ready(services, config.get('startup_timeout', 60))
        
        return {
            'network': network_name,
            'services': services,
            'cleanup_func': lambda: self._cleanup_docker_environment(network_name, services)
        }
    
    def _provision_k8s_environment(self, config: Dict) -> str:
        """ provision Kubernetes 测试环境 """
        namespace = f"test-{config['test_id']}"
        
        # 创建命名空间
        namespace_body = {
            'apiVersion': 'v1',
            'kind': 'Namespace',
            'metadata': {'name': namespace}
        }
        self.client.create_namespace(namespace_body)
        
        # 部署服务
        for service_name, service_config in config.get('services', {}).items():
            self._deploy_k8s_service(namespace, service_name, service_config)
        
        # 等待Pod就绪
        self._wait_for_pods_ready(namespace, config.get('startup_timeout', 120))
        
        return {
            'namespace': namespace,
            'cleanup_func': lambda: self._cleanup_k8s_namespace(namespace)
        }
    
    def _wait_for_services_ready(self, services: Dict, timeout: int):
        """等待服务就绪"""
        import time
        
        start_time = time.time()
        while time.time() - start_time < timeout:
            all_ready = True
            
            for service_name, container in services.items():
                container.reload()
                if container.status != 'running':
                    all_ready = False
                    break
                
                # 检查健康状态
                if hasattr(container.attrs, 'Health'):
                    health_status = container.attrs['Health']['Status']
                    if health_status != 'healthy':
                        all_ready = False
                        break
            
            if all_ready:
                return
            
            time.sleep(2)
        
        raise TimeoutError(f"Services not ready within {timeout} seconds")
    
    def _cleanup_docker_environment(self, network_name: str, services: Dict):
        """清理 Docker 环境"""
        # 停止并删除容器

            try:
                container.stop(timeout=10)
                container.remove(force=True)
            except:
                pass
        
        # 删除网络
        try:
            network = self.client.networks.get(network_name)
            network.remove()

            pass

### 2.3 自动化部署脚本

```bash
#!/bin/bash
# deploy.sh - 自动化部署脚本

set -e

# 配置变量
APP_NAME=$1
VERSION=$2
ENVIRONMENT=$3
DOCKER_REGISTRY=${DOCKER_REGISTRY:-"registry.example.com"}
BACKUP_DIR="/backup/deployments"

# 颜色定义
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m' # No Color

# 日志函数
log() {
    echo -e "[$(date +'%Y-%m-%d %H:%M:%S')] $1"
}

error() {
    log "${RED}ERROR: $1${NC}"
    exit 1
}

warn() {
    log "${YELLOW}WARNING: $1${NC}"
}

success() {
    log "${GREEN}SUCCESS: $1${NC}"
}

# 前置检查
pre_deploy_checks() {
    log "执行前置检查..."
    
    # 检查Docker镜像是否存在
    if ! docker manifest inspect "${DOCKER_REGISTRY}/${APP_NAME}:${VERSION}" > /dev/null 2>&1; then
        error "Docker镜像 ${APP_NAME}:${VERSION} 不存在"
    fi
    
    # 检查Kubernetes连接
    if ! kubectl cluster-info > /dev/null 2>&1; then
        error "无法连接到Kubernetes集群"
    fi
    
    # 检查命名空间是否存在
    if ! kubectl get namespace "${ENVIRONMENT}" > /dev/null 2>&1; then
        warn "命名空间 ${ENVIRONMENT} 不存在，将创建新命名空间"
        kubectl create namespace "${ENVIRONMENT}"
    fi
    
    success "前置检查通过"
}

# 创建备份
create_backup() {
    if [ "$ENVIRONMENT" = "production" ]; then
        log "创建生产环境备份..."
        BACKUP_FILE="${BACKUP_DIR}/${APP_NAME}/$(date +%Y%m%d_%H%M%S)_backup.yaml"
        mkdir -p "$(dirname "$BACKUP_FILE")"
        
        # 导出当前部署配置
        kubectl get deployment,service,ingress -n "${ENVIRONMENT}" -l app="${APP_NAME}" -o yaml > "$BACKUP_FILE"
        
        success "备份已创建: $BACKUP_FILE"
    fi
}

# 执行滚动更新
rolling_update() {
    log "开始滚动更新 ${APP_NAME} 到版本 ${VERSION}..."
    
    # 更新镜像版本
    kubectl set image deployment/"${APP_NAME}" \
        "${APP_NAME}=${DOCKER_REGISTRY}/${APP_NAME}:${VERSION}" \
        -n "${ENVIRONMENT}"
    
    # 等待滚动更新完成
    if kubectl rollout status deployment/"${APP_NAME}" -n "${ENVIRONMENT}" --timeout=300s; then
        success "滚动更新完成"
    else
        error "滚动更新失败"
    fi
}

# 执行蓝绿部署
blue_green_deploy() {
    log "开始蓝绿部署 ${APP_NAME}..."
    
    # 获取当前活跃颜色
    CURRENT_COLOR=$(kubectl get service "${APP_NAME}" -n "${ENVIRONMENT}" \
        -o jsonpath='{.spec.selector.version}' || echo "blue")
    
    if [ "$CURRENT_COLOR" = "blue" ]; then
        NEW_COLOR="green"
    else
        NEW_COLOR="blue"
    fi
    
    log "当前版本: $CURRENT_COLOR, 新版本: $NEW_COLOR"
    
    # 部署新版本
    cat <<EOF | kubectl apply -f -
apiVersion: apps/v1
kind: Deployment
metadata:
  name: ${APP_NAME}-${NEW_COLOR}
  namespace: ${ENVIRONMENT}
spec:
  replicas: 3
  selector:
    matchLabels:
      app: ${APP_NAME}
      version: ${NEW_COLOR}
  template:
    metadata:
      labels:
        app: ${APP_NAME}
        version: ${NEW_COLOR}
    spec:
      containers:
      - name: ${APP_NAME}
        image: ${DOCKER_REGISTRY}/${APP_NAME}:${VERSION}
        ports:
        - containerPort: 8080
EOF
    
    # 等待新版本就绪
    if kubectl rollout status deployment/"${APP_NAME}-${NEW_COLOR}" -n "${ENVIRONMENT}" --timeout=300s; then
        # 切换流量
        kubectl patch service "${APP_NAME}" -n "${ENVIRONMENT}" \
            -p "{\"spec\":{\"selector\":{\"version\":\"${NEW_COLOR}\"}}}"
        
        success "流量已切换到 ${NEW_COLOR} 版本"
        
        # 清理旧版本（可选）
        read -p "是否删除旧版本 (${CURRENT_COLOR})? (y/N): " -n 1 -r
        echo
        if [[ $REPLY =~ ^[Yy]$ ]]; then
            kubectl delete deployment "${APP_NAME}-${CURRENT_COLOR}" -n "${ENVIRONMENT}" --ignore-not-found
            success "旧版本已清理"
        fi
    else
        error "新版本部署失败"
    fi
}

# 部署后验证
post_deploy_validation() {
    log "执行部署后验证..."
    
    # 等待Pod完全启动
    sleep 30
    
    # 检查Pod状态
    READY_PODS=$(kubectl get pods -n "${ENVIRONMENT}" -l app="${APP_NAME}" --field-selector=status.phase=Running -o name | wc -l)
    DESIRED_PODS=$(kubectl get deployment "${APP_NAME}" -n "${ENVIRONMENT}" -o jsonpath='{.spec.replicas}')
    
    if [ "$READY_PODS" -eq "$DESIRED_PODS" ]; then
        success "所有Pod已就绪 ($READY_PODS/$DESIRED_PODS)"
    else
        warn "Pod状态异常 ($READY_PODS/$DESIRED_PODS)"
    fi
    
    # 运行健康检查
    if kubectl exec -n "${ENVIRONMENT}" deploy/"${APP_NAME}" -- curl -f http://localhost:8080/health > /dev/null 2>&1; then
        success "健康检查通过"
    else
        error "健康检查失败"
    fi
    
    # 检查服务端点
    ENDPOINTS=$(kubectl get endpoints "${APP_NAME}" -n "${ENVIRONMENT}" -o jsonpath='{.subsets[*].addresses[*].ip}')
    if [ -n "$ENDPOINTS" ]; then
        success "服务端点已就绪: $ENDPOINTS"
    else
        error "没有可用的服务端点"
    fi
}

# 回滚函数
rollback() {
    if [ "$ENVIRONMENT" = "production" ]; then
        log "开始回滚..."
        
        # 查找最近的备份
        LATEST_BACKUP=$(ls -t "${BACKUP_DIR}/${APP_NAME}/"*_backup.yaml 2>/dev/null | head -1)
        
        if [ -n "$LATEST_BACKUP" ]; then
            log "使用备份文件回滚: $LATEST_BACKUP"
            kubectl apply -f "$LATEST_BACKUP"
            success "回滚完成"
        else
            # 使用Kubernetes内置回滚
            kubectl rollout undo deployment/"${APP_NAME}" -n "${ENVIRONMENT}"
            success "使用Kubernetes回滚完成"
        fi
    else
        kubectl rollout undo deployment/"${APP_NAME}" -n "${ENVIRONMENT}"
        success "回滚完成"
    fi
}

# 主函数
main() {
    log "开始部署 ${APP_NAME} 版本 ${VERSION} 到 ${ENVIRONMENT} 环境"
    
    # 前置检查
    pre_deploy_checks
    
    # 创建备份
    create_backup
    
    # 根据环境选择部署策略
    case "${ENVIRONMENT}" in
        "production")
            log "生产环境使用蓝绿部署策略"
            blue_green_deploy
            ;;
        "staging"|"qa")
            log "${ENVIRONMENT} 环境使用滚动更新策略"
            rolling_update
            ;;
        *)
            log "使用默认滚动更新策略"
            rolling_update
            ;;
    esac
    
    # 部署后验证
    post_deploy_validation
    
    success "部署完成: ${APP_NAME} ${VERSION} -> ${ENVIRONMENT}"
}

# 错误处理
trap 'error "部署过程中发生错误，开始回滚..."; rollback' ERR

# 执行主函数
main "$@"
```

```python
# config_manager.py - 配置管理工具
import os
import yaml
import json
from typing import Dict, Any
from cryptography.fernet import Fernet

class ConfigManager:
    def __init__(self, environment: str):
        self.environment = environment
        self.config_dir = os.getenv('CONFIG_DIR', './configs')
        self.secrets_key = os.getenv('SECRETS_KEY')
        
    def load_config(self, app_name: str) -> Dict[str, Any]:
        """加载应用配置"""
        config_file = os.path.join(
            self.config_dir, 
            self.environment, 
            f"{app_name}.yaml"
        )
        
        if not os.path.exists(config_file):
            raise FileNotFoundError(f"配置文件不存在: {config_file}")
        
        with open(config_file, 'r') as f:
            config = yaml.safe_load(f)
        
        # 处理环境变量替换
        config = self._replace_env_vars(config)
        
        # 解密敏感信息
        if self.secrets_key:
            config = self._decrypt_secrets(config)
        
        return config
    
    def _replace_env_vars(self, config: Dict) -> Dict:
        """替换配置中的环境变量"""
        def replace_in_dict(d):
            for key, value in d.items():
                if isinstance(value, dict):
                    d[key] = replace_in_dict(value)
                elif isinstance(value, str) and value.startswith('${'):
                    env_var = value[2:-1]
                    default = None
                    if ':' in env_var:
                        env_var, default = env_var.split(':', 1)
                    
                    env_value = os.getenv(env_var, default)
                    if env_value is None:
                        raise ValueError(f"环境变量 {env_var} 未设置且没有默认值")
                    d[key] = env_value
            return d
        
        return replace_in_dict(config)
    
    def _decrypt_secrets(self, config: Dict) -> Dict:
        """解密配置中的敏感信息"""
        fernet = Fernet(self.secrets_key.encode())
        
        def decrypt_in_dict(d):
            for key, value in d.items():
                if isinstance(value, dict):
                    d[key] = decrypt_in_dict(value)
                elif isinstance(value, str) and value.startswith('ENC['):
                    encrypted = value[4:-1]
                    d[key] = fernet.decrypt(encrypted.encode()).decode()
            return d
        
        return decrypt_in_dict(config)
    
    def generate_k8s_configmap(self, app_name: str) -> str:
        """生成Kubernetes ConfigMap"""
        config = self.load_config(app_name)
        
        configmap = {
            'apiVersion': 'v1',
            'kind': 'ConfigMap',
            'metadata': {
                'name': f"{app_name}-config",
                'namespace': self.environment,
                'labels': {
                    'app': app_name,
                    'environment': self.environment
                }
            },
            'data': {
                'config.yaml': yaml.dump(config),
                'environment': self.environment
            }
        }
        
        return yaml.dump(configmap)

# 使用示例
if __name__ == "__main__":
    manager = ConfigManager("production")
    config = manager.load_config("myapp")
    print(f"配置内容: {json.dumps(config, indent=2)}")

### 3.2 自动化回滚机制

```python
# auto_rollback.py - 自动化回滚系统
import asyncio
import logging
from datetime import datetime, timedelta
from typing import Optional
from dataclasses import dataclass

@dataclass
class DeploymentStatus:
    deployment_id: str
    app_name: str
    version: str
    environment: str
    timestamp: datetime
    success: bool
    metrics: dict

class AutoRollbackSystem:
    def __init__(self, k8s_client, prometheus_client):
        self.k8s = k8s_client
        self.prom = prometheus_client
        self.logger = logging.getLogger(__name__)
        
        # 配置阈值
        self.thresholds = {
            'error_rate': 0.05,  # 5%错误率
            'response_time': 1000,  # 1000ms响应时间
            'availability': 0.99,  # 99%可用性
            'rollback_timeout': 300  # 5分钟
        }
    
    async def monitor_deployment(self, deployment: DeploymentStatus):
        """监控部署状态"""
        self.logger.info(f"开始监控部署: {deployment.app_name} v{deployment.version}")
        
        start_time = datetime.now()
        check_interval = 30  # 30秒检查一次
        
        while True:
            await asyncio.sleep(check_interval)
            
            # 检查部署健康状态
            health_status = await self._check_health(deployment)
            if not health_status:
                await self._trigger_rollback(deployment, reason="健康检查失败")
                break
            
            # 检查性能指标
            metrics = await self._collect_metrics(deployment)
            if self._check_metrics_threshold(metrics):
                await self._trigger_rollback(deployment, reason="性能指标超标")
                break
            
            # 检查超时
            elapsed = (datetime.now() - start_time).total_seconds()
            if elapsed > self.thresholds['rollback_timeout']:
                self.logger.info(f"监控超时，部署成功: {deployment.app_name}")
                break
    
    async def _check_health(self, deployment: DeploymentStatus) -> bool:
        """检查部署健康状态"""
        try:
            # 获取Pod状态
            pods = await self.k8s.get_pods(
                namespace=deployment.environment,
                label_selector=f"app={deployment.app_name}"
            )
            
            ready_pods = [p for p in pods if p.status.phase == "Running" and p.status.ready]
            
            if len(ready_pods) < len(pods) * 0.8:  # 80% Pod就绪
                self.logger.warning(f"Pod就绪率过低: {len(ready_pods)}/{len(pods)}")
                return False
            
            return True
            
        except Exception as e:
            self.logger.error(f"健康检查失败: {str(e)}")
            return False
    
    async def _collect_metrics(self, deployment: DeploymentStatus) -> dict:
        """收集部署指标"""
        try:
            # 查询Prometheus指标
            metrics = {}
            
            # 错误率
            error_query = f"""
                sum(rate(http_requests_total{{app="{deployment.app_name}", status=~"5.."}}[5m])) 
                /
                sum(rate(http_requests_total{{app="{deployment.app_name}"}}[5m]))
            """
            metrics['error_rate'] = await self.prom.query(error_query)
            
            # 响应时间
            response_query = f"""
                histogram_quantile(0.95, 
                    sum(rate(http_request_duration_seconds_bucket{{app="{deployment.app_name}"}}[5m])) by (le)
                ) * 1000
            """
            metrics['response_time'] = await self.prom.query(response_query)
            
            # 可用性
            availability_query = f"""
                sum(up{{app="{deployment.app_name}"}}) 
                / 
                count(up{{app="{deployment.app_name}"}})
            """
            metrics['availability'] = await self.prom.query(availability_query)
            
            return metrics
            
        except Exception as e:
            self.logger.error(f"收集指标失败: {str(e)}")
            return {}
    
    def _check_metrics_threshold(self, metrics: dict) -> bool:
        """检查指标是否超过阈值"""
        for metric, threshold in self.thresholds.items():
            if metric in metrics and metrics[metric] > threshold:
                self.logger.warning(f"指标 {metric} 超过阈值: {metrics[metric]} > {threshold}")
                return True
        return False
    
    async def _trigger_rollback(self, deployment: DeploymentStatus, reason: str):
        """触发回滚"""
        self.logger.error(f"触发回滚: {deployment.app_name} v{deployment.version}, 原因: {reason}")
        
        try:
            # 执行Kubernetes回滚
            await self.k8s.rollback_deployment(
                namespace=deployment.environment,
                deployment_name=deployment.app_name
            )
            
            # 发送告警
            await self._send_alert(deployment, reason)
            
            # 记录回滚事件
            await self._log_rollback_event(deployment, reason)
            
        except Exception as e:
            self.logger.error(f"回滚失败: {str(e)}")
            # 执行紧急恢复
            await self._emergency_recovery(deployment)
    
    async def _send_alert(self, deployment: DeploymentStatus, reason: str):
        """发送告警通知"""
        alert_message = f"""
        自动回滚触发:
        - 应用: {deployment.app_name}
        - 版本: {deployment.version}
        - 环境: {deployment.environment}
        - 原因: {reason}
        - 时间: {datetime.now().isoformat()}
        
        请立即检查相关服务。
        """
        
        # 发送到Slack/邮件/钉钉等
        await self._notify_channels(alert_message)
    
    async def _emergency_recovery(self, deployment: DeploymentStatus):
        """紧急恢复"""
        self.logger.critical(f"执行紧急恢复: {deployment.app_name}")
        
        # 回退到上一个稳定版本
        try:
            await self.k8s.rollback_to_previous_version(
                namespace=deployment.environment,
                deployment_name=deployment.app_name
            )
            
            # 启用维护模式
            await self.k8s.enable_maintenance_mode(
                namespace=deployment.environment,
                service_name=deployment.app_name
            )
            
        except Exception as e:
            self.logger.critical(f"紧急恢复失败: {str(e)}")
            # 通知运维团队
            await self._notify_oncall_team(deployment, str(e))
```

### 4.2 审计与合规检查

```python
# compliance_checker.py - 合规检查工具
import json
from datetime import datetime
from typing import List, Dict
from enum import Enum

class ComplianceStandard(Enum):
    PCI_DSS = "pci_dss"
    HIPAA = "hipaa"
    GDPR = "gdpr"
    SOC2 = "soc2"

class ComplianceChecker:
    def __init__(self, k8s_client, audit_logger):
        self.k8s = k8s_client
        self.audit = audit_logger
        self.checks = self._load_checks()
    
    def _load_checks(self) -> Dict:
        """加载合规检查规则"""
        return {
            'kubernetes_security': [
                self.check_pod_security_policy,
                self.check_rbac_configuration,
                self.check_network_policies,
                self.check_secret_encryption,
                self.check_resource_limits
            ],
            'application_security': [
                self.check_dependency_vulnerabilities,
                self.check_container_security,
                self.check_api_security,
                self.check_data_encryption
            ],
            'operational_security': [
                self.check_access_controls,
                self.check_audit_logging,
                self.check_backup_recovery,
                self.check_monitoring_alerting
            ]
        }
    
    async def run_compliance_checks(
        self, 
        environment: str, 
        standards: List[ComplianceStandard]
    ) -> Dict:
        """运行合规检查"""
        results = {}
        
        for standard in standards:
            results[standard.value] = {
                'status': 'PASS',
                'findings': [],
                'timestamp': datetime.now().isoformat()
            }
            
            # 运行对应的检查
            checks = self.checks.get(standard.value, [])
            for check_func in checks:
                try:
                    check_result = await check_func(environment)
                    if not check_result['passed']:
                        results[standard.value]['status'] = 'FAIL'
                        results[standard.value]['findings'].append(check_result)
                except Exception as e:
                    results[standard.value]['status'] = 'ERROR'
                    results[standard.value]['findings'].append({
                        'check': check_func.__name__,
                        'error': str(e)
                    })
            
            # 记录审计日志
            await self.audit.log_compliance_check(
                standard=standard.value,
                environment=environment,
                results=results[standard.value]
            )
        
        return results
    
    async def check_pod_security_policy(self, environment: str) -> Dict:
        """检查Pod安全策略"""
        try:
            psp_list = await self.k8s.get_pod_security_policies()
            
            required_policies = [
                'no-privileged-containers',
                'no-host-network',
                'no-host-pid',
                'no-host-ipc'
            ]
            
            missing_policies = []
            for policy in required_policies:
                if not any(p.metadata.name == policy for p in psp_list):
                    missing_policies.append(policy)
            
            return {
                'check': 'pod_security_policy',
                'passed': len(missing_policies) == 0,
                'details': f"缺失的策略: {missing_policies}" if missing_policies else "所有必需策略已配置",
                'severity': 'HIGH' if missing_policies else 'LOW'
            }
            
        except Exception as e:
            return {
                'check': 'pod_security_policy',
                'passed': False,
                'error': str(e),
                'severity': 'CRITICAL'
            }
    
    async def check_rbac_configuration(self, environment: str) -> Dict:
        """检查RBAC配置"""
        try:
            roles = await self.k8s.get_cluster_roles()
            
            # 检查是否有过于宽松的规则
            overly_permissive_roles = []
            for role in roles:
                for rule in role.rules:
                    if '*' in rule.verbs and '*' in rule.resources:
                        overly_permissive_roles.append(role.metadata.name)
            
            return {
                'check': 'rbac_configuration',
                'passed': len(overly_permissive_roles) == 0,
                'details': f"过于宽松的角色: {overly_permissive_roles}" if overly_permissive_roles else "RBAC配置合理",
                'severity': 'HIGH' if overly_permissive_roles else 'LOW'
            }
            
        except Exception as e:
            return {
                'check': 'rbac_configuration',
                'passed': False,
                'error': str(e),
                'severity': 'CRITICAL'
            }
```
