# 并发原语

## 1. 概述

并发原语是并发编程的基础构建块，它们提供了线程之间协调、同步和通信的基本机制。本章将详细探讨各种并发原语，包括其原理、使用场景和最佳实践。

## 2. 原子操作

### 2.1 定义与原理

原子操作是指不可被中断的操作序列，在执行过程中不会被其他线程打断。这是实现无锁编程的基础。

```cpp
#include <atomic>
#include <iostream>
#include <thread>

std::atomic<int> counter(0);

void increment() {
    for (int i = 0; i < 100000; ++i) {
        counter.fetch_add(1, std::memory_order_relaxed);
    }
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);
    
    t1.join();
    t2.join();
    
    std::cout << "Final counter value: " << counter << std::endl;
    return 0;
}
```

### 2.2 内存序（Memory Order）

内存序定义了原子操作之间的顺序约束：

```cpp
// 不同的内存序选项
counter.fetch_add(1, std::memory_order_relaxed);    // 无顺序保证
counter.fetch_add(1, std::memory_order_acquire);    // 获取语义
counter.fetch_add(1, std::memory_order_release);    // 释放语义
counter.fetch_add(1, std::memory_order_acq_rel);    // 获取-释放语义
counter.fetch_add(1, std::memory_order_seq_cst);    // 顺序一致性（默认）
```

### 2.3 CAS操作（Compare-and-Swap）

```cpp
// 无锁栈实现示例
template<typename T>
class LockFreeStack {
private:
    struct Node {
        T data;
        Node* next;
        Node(T const& data) : data(data), next(nullptr) {}
    };
    
    std::atomic<Node*> head;
    
public:
    void push(T const& data) {
        Node* new_node = new Node(data);
        new_node->next = head.load(std::memory_order_relaxed);
        while (!head.compare_exchange_weak(
            new_node->next, 
            new_node,
            std::memory_order_release,
            std::memory_order_relaxed
        ));
    }
    
    bool pop(T& result) {
        Node* old_head = head.load(std::memory_order_relaxed);
        while (old_head && !head.compare_exchange_weak(
            old_head,
            old_head->next,
            std::memory_order_acquire,
            std::memory_order_relaxed
        ));
        
        if (old_head) {
            result = old_head->data;
            delete old_head;
            return true;
        }
        return false;
    }
};
```

## 3. 互斥锁

### 3.1 基本互斥锁

```cpp
#include <mutex>
#include <thread>
#include <vector>

class ThreadSafeQueue {
private:
    std::queue<int> queue;
    mutable std::mutex mutex;
    
public:
    void push(int value) {
        std::lock_guard<std::mutex> lock(mutex);
        queue.push(value);
    }
    
    bool pop(int& value) {
        std::lock_guard<std::mutex> lock(mutex);
        if (queue.empty()) return false;
        
        value = queue.front();
        queue.pop();
        return true;
    }
    
    size_t size() const {
        std::lock_guard<std::mutex> lock(mutex);
        return queue.size();
    }
};
```

#include <chrono>

bool tryLockWithTimeout(std::mutex& mutex, int timeout_ms) {
    auto start = std::chrono::steady_clock::now();
    while (!mutex.try_lock()) {
        auto elapsed = std::chrono::steady_clock::now() - start;
        if (std::chrono::duration_cast<std::chrono::milliseconds>(elapsed).count() > timeout_ms) {
            return false;
        }
        std::this_thread::sleep_for(std::chrono::milliseconds(1));
    }
    return true;
}

## 4. 条件变量

### 4.1 基本使用

```cpp
#include <condition_variable>

class BoundedBuffer {
private:
    std::queue<int> buffer;
    std::mutex mutex;
    std::condition_variable not_full;
    std::condition_variable not_empty;
    size_t capacity;
    
public:
    BoundedBuffer(size_t cap) : capacity(cap) {}
    
    void produce(int value) {
        std::unique_lock<std::mutex> lock(mutex);
        not_full.wait(lock, [this]{ return buffer.size() < capacity; });
        
        buffer.push(value);
        not_empty.notify_one();
    }
    
    int consume() {
        std::unique_lock<std::mutex> lock(mutex);
        not_empty.wait(lock, [this]{ return !buffer.empty(); });
        
        int value = buffer.front();
        buffer.pop();
        not_full.notify_one();
        return value;
    }
};
```

### 4.2 虚假唤醒处理

```cpp
// 错误的方式
while (!condition) {
    cv.wait(lock);  // 可能发生虚假唤醒
}

// 正确的方式
while (!condition) {
    cv.wait(lock, [&]{ return condition; });
}
```

### 4.3 通知策略

```cpp
cv.notify_one();  // 唤醒一个等待线程
cv.notify_all();  // 唤醒所有等待线程
```

## 5. 读写锁

### 5.1 基本实现

```cpp
#include <shared_mutex>

class ThreadSafeMap {
private:
    std::map<std::string, std::string> data;
    mutable std::shared_mutex mutex;
    
public:
    // 读操作：多个线程可以同时读取
    std::string read(const std::string& key) {
        std::shared_lock<std::shared_mutex> lock(mutex);
        auto it = data.find(key);
        return it != data.end() ? it->second : "";
    }
    
    // 写操作：独占访问
    void write(const std::string& key, const std::string& value) {
        std::unique_lock<std::shared_mutex> lock(mutex);
        data[key] = value;
    }
    
    // 删除操作
    bool remove(const std::string& key) {
        std::unique_lock<std::shared_mutex> lock(mutex);
        return data.erase(key) > 0;
    }
};
```

### 5.2 优先级策略

```cpp
// 写优先级实现
class WritePriorityRWLock {
private:
    std::shared_mutex mutex;
    std::condition_variable cv;
    int active_readers = 0;
    bool active_writer = false;
    int waiting_writers = 0;
    
public:
    void lock_shared() {
        std::unique_lock<std::shared_mutex> lock(mutex);
        cv.wait(lock, [this]{ 
            return !active_writer && waiting_writers == 0; 
        });
        active_readers++;
    }
    
    void unlock_shared() {
        std::unique_lock<std::shared_mutex> lock(mutex);
        active_readers--;
        if (active_readers == 0) {
            cv.notify_all();
        }
    }
    
    void lock() {
        std::unique_lock<std::shared_mutex> lock(mutex);
        waiting_writers++;
        cv.wait(lock, [this]{ 
            return !active_writer && active_readers == 0; 
        });
        waiting_writers--;
        active_writer = true;
    }
    
    void unlock() {
        std::unique_lock<std::shared_mutex> lock(mutex);
        active_writer = false;
        cv.notify_all();
    }
};
```

## 7. 屏障

### 7.1 基本屏障

```cpp
#include <barrier>
#include <vector>
#include <thread>

void parallel_computation() {
    const int num_threads = 4;
    std::barrier sync_point(num_threads, []() noexcept {
        // 所有线程到达屏障时执行
        std::cout << "All threads synchronized" << std::endl;
    });
    
    std::vector<std::thread> threads;
    for (int i = 0; i < num_threads; ++i) {
        threads.emplace_back([i, &sync_point]() {
            // 第一阶段计算
            std::cout << "Thread " << i << " completing phase 1" << std::endl;
            
            sync_point.arrive_and_wait();  // 同步点
            
            // 第二阶段计算
            std::cout << "Thread " << i << " completing phase 2" << std::endl;
            
            sync_point.arrive_and_wait();  // 另一个同步点
        });
    }
    
    for (auto& t : threads) {
        t.join();
    }
}
```

## 8. 自旋锁

### 8.1 简单自旋锁

```cpp
#include <atomic>

class SpinLock {
private:
    std::atomic_flag flag = ATOMIC_FLAG_INIT;
    
public:
    void lock() {
        while (flag.test_and_set(std::memory_order_acquire)) {
            // 自旋等待
            // 可以添加CPU暂停指令提高性能
            #if defined(__x86_64__) || defined(_M_X64)
                __asm__ __volatile__("pause");
            #endif
        }
    }
    
    void unlock() {
        flag.clear(std::memory_order_release);
    }
    
    bool try_lock() {
        return !flag.test_and_set(std::memory_order_acquire);
    }
};
```

### 8.2 适应性自旋锁

```cpp
class AdaptiveSpinLock {
private:
    std::atomic_flag flag = ATOMIC_FLAG_INIT;
    int spin_count = 0;
    const int max_spin_count = 1000;
    
public:
    void lock() {
        while (flag.test_and_set(std::memory_order_acquire)) {
            if (++spin_count < max_spin_count) {
                // 短暂自旋
                continue;
            }
            
            // 自旋次数过多，让出CPU
            std::this_thread::yield();
            spin_count = 0;
        }
    }
    
    void unlock() {
        spin_count = 0;
        flag.clear(std::memory_order_release);
    }
};
```

#include <future>

void producer(std::promise<int> promise) {

## 10. 选择并发原语的指南

### 10.1 选择标准

1. **性能需求**：
   - 低争用：互斥锁通常足够
   - 高争用：考虑读写锁或无锁数据结构
   - 极低延迟：自旋锁

2. **使用场景**：
   - 互斥访问：互斥锁
   - 生产者-消费者：条件变量或信号量
   - 并行计算同步：屏障
   - 资源池：信号量

3. **公平性要求**：
   - 不关心公平性：普通互斥锁
   - 需要公平性：公平锁或读写锁

### 10.2 性能比较

| 原语 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 互斥锁 | 简单易用 | 可能造成上下文切换 | 通用互斥访问 |
| 读写锁 | 提高读性能 | 写者可能饥饿 | 读多写少 |
| 自旋锁 | 无上下文切换开销 | 忙等待浪费CPU | 临界区很短 |
| 条件变量 | 精确通知 | 需要配合锁使用 | 线程协调 |
| 信号量 | 资源计数 | 难以正确使用 | 资源池管理 |
| 原子操作 | 无锁高性能 | 复杂场景难以实现 | 计数器、标志位 |

## 11. 最佳实践

### 11.1 避免死锁

1. **锁顺序**：所有线程按相同顺序获取多个锁
2. **超时机制**：使用超时锁
3. **RAII模式**：使用lock_guard或unique_lock

### 11.2 性能优化

1. **最小化临界区**：只保护必要的代码
2. **减少锁争用**：使用细粒度锁或读写锁
3. **无锁编程**：在适当场景使用原子操作

### 11.3 测试策略

1. **压力测试**：高并发下测试
2. **时序测试**：使用ThreadSanitizer检测数据竞争
3. **死锁检测**：使用工具检测潜在死锁

### 12.2 Actor模型

```cpp
#include <queue>
#include <thread>
#include <functional>

class Actor {
private:
    std::queue<std::function<void()>> message_queue;
    std::mutex queue_mutex;
    std::condition_variable cv;
    std::thread actor_thread;
    bool running = true;
    
public:
    Actor() {
        actor_thread = std::thread([this]() {
            while (running) {
                std::function<void()> message;
                {
                    std::unique_lock<std::mutex> lock(queue_mutex);
                    cv.wait(lock, [this]{ 
                        return !message_queue.empty() || !running; 
                    });
                    
                    if (!running) break;
                    
                    message = std::move(message_queue.front());
                    message_queue.pop();
                }
                message();
            }
        });
    }
    
    template<typename F, typename... Args>
    void send(F&& f, Args&&... args) {
        std::lock_guard<std::mutex> lock(queue_mutex);
        message_queue.push([f = std::forward<F>(f), 
                           args = std::make_tuple(std::forward<Args>(args)...)]() {
            std::apply(f, args);
        });
        cv.notify_one();
    }
    
    ~Actor() {
        {
            std::lock_guard<std::mutex> lock(queue_mutex);
            running = false;
        }
        cv.notify_all();
        actor_thread.join();
    }
};
```
