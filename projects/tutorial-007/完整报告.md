## 1. 内存模型概述

### 1.1 什么是内存模型

内存模型（Memory Model）是计算机系统中定义内存访问行为的一组规则和约束。它规定了在多线程环境下，内存操作（读/写）如何对其他线程可见，以及这些操作可以被如何重排序。

内存模型的核心作用是在**性能优化**和**正确性保证**之间寻找平衡：

- **性能角度**：允许硬件和编译器进行指令重排序、缓存优化等操作
- **正确性角度**：确保程序员编写的并发程序能按预期工作

### 1.2 为什么需要理解内存模型

```cpp
// 没有正确理解内存模型可能导致的问题示例
int data = 0;
bool ready = false;

// 线程1
void producer() {
    data = 42;          // A: 写数据
    ready = true;       // B: 设置标志
}

// 线程2
void consumer() {
    while (!ready);     // C: 等待标志
    int value = data;   // D: 读取数据
    // 程序员期望 value = 42，但实际可能为 0
}
```

在不正确的内存模型理解下，上述代码可能：
1. 编译器重排序A和B
2. CPU缓存导致B对线程2立即可见，但A不可见
3. 最终导致`value = 0`

## 2. 硬件内存架构基础

### 2.1 现代CPU缓存架构

现代处理器采用多级缓存架构：

```
┌─────────────┐
│  CPU Core 0 │──── L1 Cache (私有，最快)
└──────┬──────┘
       │
┌──────┴──────┐
│  CPU Core 1 │──── L1 Cache (私有)
└──────┬──────┘
       │
┌──────┴──────┐
│  L2 Cache   │──── 每个核心共享（较慢）
└──────┬──────┘
       │
┌──────┴──────┐
│  L3 Cache   │──── 所有核心共享（更慢）
└──────┬──────┘
       │
┌──────┴──────┐
│   主内存     │──── 最慢
└─────────────┘
```

### 2.2 缓存一致性协议

为解决多核CPU缓存一致性问题，硬件实现了缓存一致性协议：

#### MESI协议（Modified, Exclusive, Shared, Invalid）

状态转换：
```
         Invalid ──────┐
            ↑          │
            │          ▼
          Shared ──── Exclusive
            ↑          │
            │          ▼
         Modified ─────┘
```

工作流程示例：
```c
// 两个核心同时修改同一个缓存行
// 核心0: 写x=1
// 核心1: 写x=2

// MESI协议执行过程：
1. 核心0读取x → 状态: Exclusive
2. 核心1读取x → 状态变为Shared（两个核心都有缓存）
3. 核心0写x=1 → 发送Invalidate消息，核心1缓存失效，状态: Modified
4. 核心1写x=2 → 必须等待核心0将数据写回，获取最新值后写入，状态: Modified
```

### 2.3 存储缓冲区与失效队列

现代CPU使用两个重要优化机制：

#### 存储缓冲区（Store Buffer）
```assembly
; CPU核心A执行：
mov [x], 1      ; 写入存储缓冲区
mov eax, [y]    ; 可能先于写x执行

; CPU核心B执行：
mov [y], 1
mov eax, [x]    ; 可能读取到旧值0
```

#### 失效队列（Invalidation Queue）
```c
// 核心A收到Invalidate消息但未立即处理
// 核心B读取数据可能看到过期值
```

### 2.4 TSO（Total Store Order）与PSO（Partial Store Order）

不同架构的内存模型强度：

| 架构 | 内存模型 | 特点 |
|------|----------|------|
| x86/x64 | TSO（强内存模型） | 写-写不重排序，读-读不重排序 |
| ARM/PowerPC | 弱内存模型 | 几乎所有操作都可能重排序 |
| MIPS | PSO | 部分存储顺序 |

## 3. 编程语言内存模型

### 3.1 C++11内存模型

C++11引入了标准化的内存模型，定义在`<atomic>`头文件中。

#### 3.1.1 内存顺序（Memory Order）

```cpp
#include <atomic>
#include <thread>

std::atomic<int> x{0};
std::atomic<int> y{0};
std::atomic<int> z{0};
int r1, r2, r3;

void thread1() {
    x.store(1, std::memory_order_relaxed);  // A
    y.store(1, std::memory_order_release);  // B
}

void thread2() {
    r1 = y.load(std::memory_order_acquire); // C
    r2 = x.load(std::memory_order_relaxed); // D
}

void thread3() {
    z.store(1, std::memory_order_seq_cst);  // E
}
```

#### 3.1.2 六种内存顺序详解

```cpp
// 1. memory_order_relaxed
//    - 最弱的顺序，只保证原子性
//    - 不提供同步或顺序保证
atomic_store_explicit(&x, 1, memory_order_relaxed);

// 2. memory_order_consume
//    - 提供数据依赖同步（很少使用，通常退化为acquire）
//    - 适用于读取由另一线程发布的指针数据

// 3. memory_order_acquire
//    - 用于load操作
//    - 后续的读写操作不会重排序到该load之前

// 4. memory_order_release
//    - 用于store操作
//    - 前面的读写操作不会重排序到该store之后

// 5. memory_order_acq_rel
//    - 同时具有acquire和release语义
//    - 用于read-modify-write操作

// 6. memory_order_seq_cst
//    - 最强的顺序，提供顺序一致性
//    - 所有线程看到相同的操作顺序（默认）
```

#### 3.1.3 happens-before关系

C++内存模型基于happens-before关系：

```cpp
// 单线程中的顺序性
// 1. 程序顺序规则
int a = 1;      // A happens-before B
int b = a + 1;  // B happens-before C

// 2. 传递性
// 如果A happens-before B，B happens-before C，
// 则A happens-before C

// 3. 释放-获取同步
std::atomic<int> flag{0};
int data = 0;

// 线程1
data = 42;                              // A
flag.store(1, memory_order_release);    // B

// 线程2
while (flag.load(memory_order_acquire) != 1); // C
int val = data;                         // D

// A happens-before B (程序顺序)
// B happens-before C (释放-获取同步)
// C happens-before D (程序顺序)
// 因此 A happens-before D，保证val=42
```

### 3.2 Java内存模型（JMM）

Java内存模型是语言内存模型的典范，定义在Java Language Specification中。

#### 3.2.1 JMM的基本概念

```java
public class JMMExample {
    // 共享变量
    private int value;
    private boolean ready;
    
    // volatile保证可见性
    private volatile boolean volatileReady;
    
    // synchronized提供互斥和内存可见性
    public synchronized void setValue(int v) {
        this.value = v;
    }
    
    public synchronized int getValue() {
        return value;
    }
}
```

#### 3.2.2 JMM中的happens-before规则

1. **程序顺序规则**：同一线程中的每个操作happens-before后续操作
2. **监视器锁规则**：解锁happens-before后续的加锁
3. **volatile变量规则**：volatile写happens-before后续volatile读
4. **线程启动规则**：Thread.start() happens-before线程中的每个操作
5. **线程终止规则**：线程中的所有操作happens-before Thread.join()返回
6. **中断规则**：调用interrupt() happens-before检测到中断
7. **终结器规则**：构造函数结束happens-before终结器开始
8. **传递性规则**

#### 3.2.3 final字段语义

```java
public class FinalFieldExample {
    final int x;
    int y;
    
    public FinalFieldExample() {
        x = 1;  // final字段初始化
        y = 2;  // 普通字段初始化
    }
}

// 其他线程如果能看到该对象的引用：
// - 保证看到x=1（final字段）
// - 不保证看到y=2（普通字段可能被重排序）
```

### 3.3 Go语言内存模型

Go的内存模型在Go 1.19中进行了正式定义：

```go
package main

import (
    "sync"
    "sync/atomic"
)

var (
    mu    sync.Mutex
    cond  = sync.NewCond(&mu)
    ready = false
    data  = 0
)

func producer() {
    mu.Lock()
    defer mu.Unlock()
    
    data = 42           // A
    ready = true        // B
    cond.Signal()       // 通知消费者
}

func consumer() {
    mu.Lock()
    defer mu.Unlock()
    
    for !ready {        // 等待信号
        cond.Wait()
    }
    
    // 此处保证data = 42
    fmt.Println(data)   // C
}
```

## 4. 内存一致性模型详解

### 4.1 顺序一致性（Sequential Consistency）

Lamport在1979年定义的顺序一致性：

> 一个系统是顺序一致的，如果任何执行的结果都与所有处理器的操作按照某种顺序执行相同，并且每个处理器内部的操作按照其程序指定的顺序出现。

```cpp
// 顺序一致性示例
std::atomic<int> x{0}, y{0};

// 线程1
x.store(1, memory_order_seq_cst);
int r1 = y.load(memory_order_seq_cst);

// 线程2
y.store(1, memory_order_seq_cst);
int r2 = x.load(memory_order_seq_cst);

// 顺序一致性保证：r1和r2不能同时为0
// 因为所有线程看到相同的操作顺序
```

### 4.2 完全存储顺序（TSO）

x86/x64架构采用的TSO模型：

```
TSO保证：
1. 每个处理器内的操作按程序顺序执行
2. 存储（写）操作对所有处理器立即可见
3. 读取操作可能看到自己处理器的最新写入（但可能看到其他处理器的旧写入）
```

### 4.3 部分存储顺序（PSO）

更弱的内存模型，允许：
1. 写-写重排序
2. 读-写重排序
3. 写-读重排序

### 4.4 因果一致性（Causal Consistency）

比顺序一致性更弱，但保持因果关系：

```cpp
// 因果一致性示例
int x = 0, y = 0, z = 0;

// 线程1
x = 1;
y = 1;

// 线程2
if (y == 1) {
    z = 1;
}

// 线程3
if (z == 1) {
    assert(x == 1);  // 因果一致性保证此断言成立
}
```

### 4.5 最终一致性（Eventual Consistency）

最弱的一致性模型，仅保证最终会一致：

- 适用于分布式系统
- 不保证何时一致
- 实现难度低，性能好

## 5. 内存屏障与栅栏机制

### 5.1 内存屏障的作用

内存屏障（Memory Barrier/Fence）用于：
1. 阻止特定类型的重排序
2. 强制缓存一致性
3. 确保内存操作的可见性

### 5.2 硬件内存屏障

```cpp
// x86/x64 架构内存屏障
__asm__ __volatile__ (
    "mfence" : : : "memory"  // 全屏障
    "lfence" : : : "memory"  // 读屏障
    "sfence" : : : "memory"  // 写屏障
);

// ARM架构内存屏障
__asm__ __volatile__ (
    "dmb" : : : "memory"     // 数据内存屏障
    "dsb" : : : "memory"     // 数据同步屏障
    "isb" : : : "memory"     // 指令同步屏障
);
```

### 5.3 C++标准库中的内存屏障

```cpp
#include <atomic>
#include <iostream>

std::atomic<int> a{0}, b{0};

void thread1() {
    a.store(1, std::memory_order_relaxed);
    // 插入发布屏障
    std::atomic_thread_fence(std::memory_order_release);
    b.store(1, std::memory_order_relaxed);
}

void thread2() {
    while (b.load(std::memory_order_relaxed) != 1);
    // 插入获取屏障
    std::atomic_thread_fence(std::memory_order_acquire);
    int value = a.load(std::memory_order_relaxed);
    std::cout << value << std::endl;  // 保证输出1
}
```

### 5.4 Linux内核中的屏障

```c
// Linux内核内存屏障宏
#define mb()    __asm__ __volatile__ ("lock; addl $0,0(%%esp)" : : : "memory")
#define rmb()   __asm__ __volatile__ ("lock; addl $0,0(%%esp)" : : : "memory")
#define wmb()   __asm__ __volatile__ ("" : : : "memory")

// 使用示例
void producer() {
    data = 42;           // 写数据
    wmb();               // 写屏障，确保数据写在标志之前
    ready = 1;           // 设置标志
}

void consumer() {
    while (!ready);      // 等待标志
    rmb();               // 读屏障，确保读到最新数据
    int value = data;    // 读数据
    // value保证是42
}
```

## 6. 数据竞争与同步原语

### 6.1 数据竞争（Data Race）

当满足以下条件时发生数据竞争：
1. 两个或更多线程并发访问同一内存位置
2. 至少一个访问是写操作
3. 访问之间没有同步

```cpp
// 数据竞争示例
int shared = 0;

void increment() {
    shared++;  // 非原子操作，实际包含读-修改-写
}

// 多个线程调用increment()会导致数据竞争
```

### 6.2 同步原语

#### 6.2.1 互斥锁（Mutex）

```cpp
#include <mutex>

class ThreadSafeCounter {
private:
    mutable std::mutex mutex_;
    int count_ = 0;
    
public:
    void increment() {
        std::lock_guard<std::mutex> lock(mutex_);
        count_++;
    }
    
    int get() const {
        std::lock_guard<std::mutex> lock(mutex_);
        return count_;
    }
};
```

#### 6.2.2 读写锁（Read-Write Lock）

```cpp
#include <shared_mutex>

class Cache {
private:
    mutable std::shared_mutex mutex_;
    std::map<int, std::string> cache_;
    
public:
    std::string get(int key) const {
        std::shared_lock<std::shared_mutex> lock(mutex_);  // 读锁
        auto it = cache_.find(key);
        if (it != cache_.end()) {
            return it->second;
        }
        return "";
    }
    
    void put(int key, const std::string& value) {
        std::unique_lock<std::shared_mutex> lock(mutex_);  // 写锁
        cache_[key] = value;
    }
};
```

#### 6.2.3 原子操作

```cpp
#include <atomic>

class AtomicCounter {
private:
    std::atomic<int> count_{0};
    
public:
    void increment() {
        count_.fetch_add(1, std::memory_order_relaxed);
    }
    
    int get() const {
        return count_.load(std::memory_order_relaxed);
    }
    
    // 复杂的原子操作
    bool compare_and_swap(int expected, int desired) {
        return count_.compare_exchange_strong(
            expected, 
            desired,
            std::memory_order_acq_rel
        );
    }
};
```

#### 6.2.4 条件变量

```cpp
#include <condition_variable>
#include <queue>

template<typename T>
class ThreadSafeQueue {
private:
    mutable std::mutex mutex_;
    std::condition_variable cond_;
    std::queue<T> queue_;
    
public:
    void push(T value) {
        std::lock_guard<std::mutex> lock(mutex_);
        queue_.push(std::move(value));
        cond_.notify_one();
    }
    
    T pop() {
        std::unique_lock<std::mutex> lock(mutex_);
        cond_.wait(lock, [this] { return !queue_.empty(); });
        T value = std::move(queue_.front());
        queue_.pop();
        return value;
    }
};
```

## 7. 内存模型在实践中的应用

### 7.1 双重检查锁定（Double-Checked Locking）

经典实现及其问题：

```cpp
// 错误的实现（在Java 1.5之前和某些C++实现中）
class Singleton {
private:
    static Singleton* instance;
    static std::mutex mutex_;
    
public:
    static Singleton* getInstance() {
        if (instance == nullptr) {              // 第一次检查
            std::lock_guard<std::mutex> lock(mutex_);
            if (instance == nullptr) {          // 第二次检查
                instance = new Singleton();     // 可能被重排序！
            }
        }
        return instance;
    }
};

// 问题：new Singleton() 可能被重排序为：
// 1. 分配内存
// 2. 返回指针给instance
// 3. 调用构造函数初始化
// 其他线程可能在步骤3之前访问instance，得到未初始化的对象
```

正确实现（C++11及以后）：

```cpp
class Singleton {
private:
    static std::atomic<Singleton*> instance;
    static std::mutex mutex_;
    
public:
    static Singleton* getInstance() {
        Singleton* tmp = instance.load(std::memory_order_acquire);
        if (tmp == nullptr) {
            std::lock_guard<std::mutex> lock(mutex_);
            tmp = instance.load(std::memory_order_relaxed);
            if (tmp == nullptr) {
                tmp = new Singleton();
                instance.store(tmp, std::memory_order_release);
            }
        }
        return tmp;
    }
};
```

### 7.2 生产者-消费者模式

```cpp
#include <atomic>
#include <memory>

template<typename T>
class LockFreeQueue {
private:
    struct Node {
        std::shared_ptr<T> data;
        std::atomic<Node*> next;
        Node() : next(nullptr) {}
    };
    
    std::atomic<Node*> head;
    std::atomic<Node*> tail;
    
public:
    LockFreeQueue() {
        Node* dummy = new Node();
        head.store(dummy);
        tail.store(dummy);
    }
    
    void enqueue(T value) {
        Node* new_node = new Node();
        new_node->data = std::make_shared<T>(std::move(value));
        
        Node* old_tail = tail.load(std::memory_order_relaxed);
        old_tail->next.store(new_node, std::memory_order_release);
        tail.store(new_node, std::memory_order_release);
    }
    
    std::shared_ptr<T> dequeue() {
        Node* old_head = head.load(std::memory_order_relaxed);
        Node* new_head = old_head->next.load(std::memory_order_acquire);
        
        if (new_head == nullptr) {
            return nullptr;
        }
        
        T result = *new_head->data;
        head.store(new_head, std::memory_order_release);
        delete old_head;
        return std::make_shared<T>(std::move(result));
    }
};
```

### 7.3 无锁数据结构设计原则

```cpp
// 无锁栈示例
template<typename T>
class LockFreeStack {
private:
    struct Node {
        T data;
        Node* next;
        Node(const T& data) : data(data), next(nullptr) {}
    };
    
    std::atomic<Node*> head{nullptr};
    
public:
    void push(const T& data) {
        Node* new_node = new Node(data);
        Node* old_head = head.load(std::memory_order_relaxed);
        do {
            new_node->next = old_head;
        } while (!head.compare_exchange_weak(
            old_head, 
            new_node,
            std::memory_order_release,
            std::memory_order_relaxed
        ));
    }
    
    std::shared_ptr<T> pop() {
        Node* old_head = head.load(std::memory_order_acquire);
        while (old_head && !head.compare_exchange_weak(
            old_head,
            old_head->next,
            std::memory_order_acq_rel,
            std::memory_order_acquire
        ));
        
        if (old_head) {
            std::shared_ptr<T> res = std::make_shared<T>(std::move(old_head->data));
            delete old_head;
            return res;
        }
        return nullptr;
    }
};
```

```cpp
// 使用宽松内存顺序进行批量操作
template<typename T>
class BatchProcessor {
private:
    std::vector<T> buffer;
    std::atomic<size_t> count{0};
    const size_t batch_size;
    
public:
    BatchProcessor(size_t batch_size) : batch_size(batch_size) {
        buffer.reserve(batch_size);
    }
    
    void add(const T& item) {
        buffer.push_back(item);
        size_t current = count.fetch_add(1, std::memory_order_relaxed);
        
        if (current + 1 >= batch_size) {
            process_batch();
            count.store(0, std::memory_order_relaxed);
        }
    }
    
    void process_batch() {
        // 批量处理，减少内存屏障开销
        for (const auto& item : buffer) {
            process_item(item);
        }
        buffer.clear();
    }
};
```

## 9. 常见陷阱与最佳实践

### 9.1 常见错误

```cpp
// 错误1：过度使用seq_cst
std::atomic<int> flag{0};

void worker() {
    while (flag.load(std::memory_order_seq_cst) != 1) {
        // 过度同步，性能下降
    }
}

// 正确做法：根据需求选择内存顺序
void worker_optimized() {
    while (flag.load(std::memory_order_acquire) != 1) {
        // 使用适当的内存顺序
    }
}
```

```cpp
// 错误2：混合使用锁和原子操作
std::mutex mutex;
std::atomic<int> shared{0};

void incorrect_increment() {
    // 错误：没有统一的同步机制
    mutex.lock();
    shared.fetch_add(1, std::memory_order_relaxed);
    mutex.unlock();
}

// 正确做法：选择一种同步机制
void correct_increment() {
    // 方案1：只使用原子操作
    shared.fetch_add(1, std::memory_order_acq_rel);
    
    // 方案2：只使用锁
    std::lock_guard<std::mutex> lock(mutex);
    shared.fetch_add(1, std::memory_order_relaxed);
}
```

### 9.2 最佳实践清单

1. **默认使用顺序一致性**，除非有明确性能需求
2. **理解数据依赖**，利用依赖关系减少同步
3. **避免伪共享**，合理对齐数据
4. **选择合适的同步粒度**，平衡性能和复杂性

```python
#!/usr/bin/env python3
"""
文件下载管理器 - 并发编程实战项目
支持多线程下载、异步IO、任务队列等并发技术
"""

import argparse
import sys
import os
from typing import List, Dict, Any
from concurrent.futures import ThreadPoolExecutor, as_completed

from core.downloader import FileDownloader
from core.task_manager import TaskManager
from core.async_downloader import AsyncDownloader
from utils.progress import ProgressTracker
from config.settings import Config
from utils.logger import setup_logger

# 设置日志
logger = setup_logger(__name__)

class FileDownloadManager:
    """文件下载管理器 - 协调多个下载任务"""
    
    def __init__(self, max_workers: int = 5, use_async: bool = False):
        """
        初始化下载管理器
        
        Args:
            max_workers: 最大并发线程数
            use_async: 是否使用异步IO
        """
        self.max_workers = max_workers
        self.use_async = use_async
        self.task_manager = TaskManager(max_workers)
        self.downloader = FileDownloader()
        self.async_downloader = AsyncDownloader()
        self.progress_tracker = ProgressTracker()
        
        logger.info(f"下载管理器初始化完成，最大并发数: {max_workers}")
    
    def add_download_task(self, url: str, output_path: str, **kwargs) -> bool:
        """添加单个下载任务"""
        try:
            task_id = self.task_manager.add_task(
                url=url,
                output_path=output_path,
                **kwargs
            )
            logger.info(f"任务已添加: {task_id} - {url}")
            return True
        except Exception as e:
            logger.error(f"添加任务失败: {e}")
            return False
    
    def add_batch_tasks(self, download_list: List[Dict[str, Any]]) -> List[str]:
        """批量添加下载任务"""
        task_ids = []
        for item in download_list:
            url = item.get('url')
            output_path = item.get('output_path')
            
            if not url or not output_path:
                logger.warning(f"无效的下载项: {item}")
                continue
            
            task_id = self.task_manager.add_task(url, output_path, **item)
            task_ids.append(task_id)
        
        logger.info(f"已批量添加 {len(task_ids)} 个下载任务")
        return task_ids
    
    def start_downloads(self) -> Dict[str, bool]:
        """
        开始所有下载任务
        
        Returns:
            任务ID到下载结果的映射
        """
        results = {}
        
        if self.use_async:
            # 使用异步下载器
            logger.info("使用异步IO进行下载")
            results = self._run_async_downloads()
        else:
            # 使用线程池下载器
            logger.info("使用多线程进行下载")
            results = self._run_threaded_downloads()
        
        return results
    
    def _run_threaded_downloads(self) -> Dict[str, bool]:
        """使用线程池执行下载任务"""
        results = {}
        pending_tasks = self.task_manager.get_pending_tasks()
        
        if not pending_tasks:
            logger.info("没有待处理的下载任务")
            return results
        
        logger.info(f"开始处理 {len(pending_tasks)} 个下载任务")
        
        # 使用线程池执行下载任务
        with ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            # 提交所有任务
            future_to_task = {}
            for task_id, task_info in pending_tasks.items():
                future = executor.submit(
                    self.downloader.download_file,
                    task_info['url'],
                    task_info['output_path'],
                    **task_info.get('params', {})
                )
                future_to_task[future] = task_id
                self.task_manager.update_task_status(task_id, 'running')
            
            # 处理完成的任务
            for future in as_completed(future_to_task):
                task_id = future_to_task[future]
                try:
                    success = future.result()
                    results[task_id] = success
                    
                    if success:
                        self.task_manager.update_task_status(task_id, 'completed')
                        self.progress_tracker.update_progress(task_id, 100)
                        logger.info(f"任务完成: {task_id}")
                    else:
                        self.task_manager.update_task_status(task_id, 'failed')
                        logger.warning(f"任务失败: {task_id}")
                        
                except Exception as e:
                    results[task_id] = False
                    self.task_manager.update_task_status(task_id, 'failed')
                    logger.error(f"任务异常 {task_id}: {e}")
        
        return results
    
    def _run_async_downloads(self) -> Dict[str, bool]:
        """使用异步IO执行下载任务"""
        import asyncio
        
        pending_tasks = self.task_manager.get_pending_tasks()
        if not pending_tasks:
            return {}
        
        # 创建任务列表
        tasks = []
        task_ids = []
        
        for task_id, task_info in pending_tasks.items():
            coroutine = self.async_downloader.async_download(
                task_info['url'],
                task_info['output_path'],
                **task_info.get('params', {})
            )
            tasks.append(coroutine)
            task_ids.append(task_id)
            
            # 更新任务状态
            self.task_manager.update_task_status(task_id, 'running')
        
        # 执行所有异步任务
        logger.info(f"启动异步下载任务，数量: {len(tasks)}")
        results_list = asyncio.run(self._run_coroutines(tasks))
        
        # 映射结果
        results = {}
        for task_id, result in zip(task_ids, results_list):
            results[task_id] = result
            
            status = 'completed' if result else 'failed'
            self.task_manager.update_task_status(task_id, status)
            
            if result:
                self.progress_tracker.update_progress(task_id, 100)
        
        return results
    
    async def _run_coroutines(self, coroutines):
        """运行协程任务"""
        import aiohttp
        
        connector = aiohttp.TCPConnector(limit=self.max_workers)
        async with aiohttp.ClientSession(connector=connector) as session:
            tasks = [coro for coro in coroutines]
            return await asyncio.gather(*tasks, return_exceptions=True)
    
    def get_download_progress(self) -> Dict[str, int]:
        """获取所有任务的下载进度"""
        return self.progress_tracker.get_all_progress()
    
    def cancel_task(self, task_id: str) -> bool:
        """取消指定任务"""
        return self.task_manager.cancel_task(task_id)
    
    def cleanup(self):
        """清理资源"""
        self.task_manager.cleanup()
        logger.info("下载管理器已清理")

def main():
    """主函数"""
    parser = argparse.ArgumentParser(description="并发文件下载管理器")
    parser.add_argument("--urls", nargs="+", help="要下载的URL列表")
    parser.add_argument("--output-dir", default="./downloads", help="输出目录")
    parser.add_argument("--max-workers", type=int, default=5, help="最大并发数")
    parser.add_argument("--async", action="store_true", help="使用异步IO")
    parser.add_argument("--config", help="配置文件路径")
    
    args = parser.parse_args()
    
    # 确保输出目录存在
    os.makedirs(args.output_dir, exist_ok=True)
    
    # 创建下载管理器
    manager = FileDownloadManager(
        max_workers=args.max_workers,
        use_async=getattr(args, 'async', False)
    )
    
    # 添加下载任务
    download_list = []
    for url in args.urls:
        filename = url.split('/')[-1] or "download"
        output_path = os.path.join(args.output_dir, filename)
        download_list.append({
            'url': url,
            'output_path': output_path
        })
    
    # 批量添加任务
    task_ids = manager.add_batch_tasks(download_list)
    
    if not task_ids:
        logger.error("没有有效的下载任务")
        sys.exit(1)
    
    # 开始下载
    logger.info("开始下载任务...")
    results = manager.start_downloads()
    
    # 统计结果
    success_count = sum(1 for v in results.values() if v)
    total_count = len(results)
    
    logger.info(f"下载完成: {success_count}/{total_count} 成功")
    
    # 显示进度
    progress = manager.get_download_progress()
    for task_id, prog in progress.items():
        logger.info(f"任务 {task_id} 进度: {prog}%")
    
    # 清理资源
    manager.cleanup()
    
    return 0 if success_count == total_count else 1

if __name__ == "__main__":
    sys.exit(main())
```

```python
"""
文件下载器核心实现
支持断点续传、并发下载、重试机制
"""

import os
import time
import requests
from typing import Optional, Tuple, Dict, Any
from urllib.parse import urlparse
from concurrent.futures import ThreadPoolExecutor
import threading
from threading import Lock, Condition, Event

from utils.file_helper import FileHelper
from utils.logger import setup_logger

logger = setup_logger(__name__)

class DownloadChunk:
    """下载块，用于分片下载"""
    
    def __init__(self, start: int, end: int, chunk_size: int = 8192):
        self.start = start
        self.end = end
        self.chunk_size = chunk_size
        self.downloaded = 0
        self.data = bytearray()
        self.completed = False
    
    @property
    def remaining(self) -> int:
        return (self.end - self.start + 1) - self.downloaded
    
    def add_data(self, data: bytes):
        """添加下载的数据"""
        self.data.extend(data)
        self.downloaded += len(data)
        if self.downloaded >= (self.end - self.start + 1):
            self.completed = True
    
    def get_data(self) -> bytes:
        """获取下载的数据"""
        return bytes(self.data)

class FileDownloader:
    """文件下载器，支持多线程分片下载"""
    
    def __init__(self, max_retries: int = 3, timeout: int = 30, chunk_size: int = 8192):
        """
        初始化下载器
        
        Args:
            max_retries: 最大重试次数
            timeout: 请求超时时间(秒)
            chunk_size: 下载块大小(字节)
        """
        self.max_retries = max_retries
        self.timeout = timeout
        self.chunk_size = chunk_size
        self.session = self._create_session()
        self._lock = Lock()
        self._stats = {
            'total_downloaded': 0,
            'active_threads': 0,
            'failed_chunks': 0
        }
        
        logger.info("文件下载器初始化完成")
    
    def _create_session(self) -> requests.Session:
        """创建HTTP会话"""
        session = requests.Session()
        
        # 设置默认headers
        session.headers.update({
            'User-Agent': 'FileDownloader/1.0 (Python Concurrent Download)',
            'Accept-Encoding': 'gzip, deflate',
            'Connection': 'keep-alive'
        })
        
        # 设置重试策略
        from requests.adapters import HTTPAdapter
        from urllib3.util.retry import Retry
        
        retry_strategy = Retry(
            total=3,
            backoff_factor=1,
            status_forcelist=[429, 500, 502, 503, 504],
            allowed_methods=["HEAD", "GET", "OPTIONS"]
        )
        
        adapter = HTTPAdapter(max_retries=retry_strategy)
        session.mount("http://", adapter)
        session.mount("https://", adapter)
        
        return session
    
    def download_file(self, url: str, output_path: str, 
                     use_multithreading: bool = True, 
                     num_threads: int = 4,
                     **kwargs) -> bool:
        """
        下载文件
        
        Args:
            url: 下载URL
            output_path: 输出文件路径
            use_multithreading: 是否使用多线程
            num_threads: 线程数
            **kwargs: 其他参数
            
        Returns:
            是否下载成功
        """
        logger.info(f"开始下载: {url}")
        logger.info(f"保存到: {output_path}")
        
        # 确保输出目录存在
        FileHelper.ensure_dir(output_path)
        
        for attempt in range(self.max_retries + 1):
            try:
                if use_multithreading:
                    success = self._multithreaded_download(
                        url, output_path, num_threads, **kwargs
                    )
                else:
                    success = self._single_threaded_download(url, output_path, **kwargs)
                
                if success:
                    logger.info(f"下载成功: {url}")
                    return True
                else:
                    logger.warning(f"下载失败，重试中... (尝试 {attempt + 1}/{self.max_retries + 1})")
                    time.sleep(2 ** attempt)  # 指数退避
                    
            except Exception as e:
                logger.error(f"下载异常 (尝试 {attempt + 1}): {e}")
                if attempt == self.max_retries:
                    logger.error(f"下载最终失败: {url}")
                    return False
                time.sleep(2 ** attempt)
        
        return False
    
    def _multithreaded_download(self, url: str, output_path: str, 
                              num_threads: int = 4, **kwargs) -> bool:
        """多线程下载实现"""
        try:
            # 获取文件大小和是否支持范围请求
            file_size, supports_range = self._get_file_info(url)
            
            if file_size is None:
                logger.warning("无法获取文件大小，使用单线程下载")
                return self._single_threaded_download(url, output_path, **kwargs)
            
            if not supports_range or file_size < 1024 * 1024:  # 小于1MB用单线程
                logger.info("文件较小或不支持范围请求，使用单线程下载")
                return self._single_threaded_download(url, output_path, **kwargs)
            
            logger.info(f"文件大小: {FileHelper.format_size(file_size)}")
            logger.info(f"使用 {num_threads} 个线程下载")
            
            # 计算每个线程下载的块
            chunk_size = file_size // num_threads
            chunks = []
            
            for i in range(num_threads):
                start = i * chunk_size
                end = start + chunk_size - 1 if i < num_threads - 1 else file_size - 1
                chunks.append(DownloadChunk(start, end, self.chunk_size))
            
            # 使用线程池下载各块
            thread_results = []
            with ThreadPoolExecutor(max_workers=num_threads) as executor:
                futures = []
                for i, chunk in enumerate(chunks):
                    future = executor.submit(
                        self._download_chunk,
                        url, chunk, i + 1
                    )
                    futures.append(future)
                
                # 等待所有线程完成
                for future in futures:
                    success, data = future.result()
                    if not success:
                        logger.error("一个下载块失败")
                        return False
                    thread_results.append(data)
            
            # 合并下载的数据
            with open(output_path, 'wb') as f:
                for data in thread_results:
                    f.write(data)
            
            # 验证文件大小
            downloaded_size = os.path.getsize(output_path)
            if downloaded_size != file_size:
                logger.error(f"文件大小不匹配: 期望 {file_size}, 实际 {downloaded_size}")
                return False
            
            return True
            
        except Exception as e:
            logger.error(f"多线程下载失败: {e}")
            return False
    
    def _single_threaded_download(self, url: str, output_path: str, **kwargs) -> bool:
        """单线程下载实现"""
        try:
            response = self.session.get(url, stream=True, timeout=self.timeout, **kwargs)
            response.raise_for_status()
            
            total_size = int(response.headers.get('content-length', 0))
            downloaded = 0
            
            with open(output_path, 'wb') as f:
                for chunk in response.iter_content(chunk_size=self.chunk_size):
                    if chunk:
                        f.write(chunk)
                        downloaded += len(chunk)
                        
                        # 更新统计信息
                        with self._lock:
                            self._stats['total_downloaded'] += len(chunk)
                        
                        # 每1MB输出一次进度
                        if downloaded % (1024 * 1024) == 0:
                            progress = (downloaded / total_size * 100) if total_size else 0
                            logger.debug(f"下载进度: {progress:.1f}%")
            
            return True
            
        except requests.RequestException as e:
            logger.error(f"HTTP请求失败: {e}")
            return False
        except IOError as e:
            logger.error(f"文件写入失败: {e}")
            return False
    
    def _download_chunk(self, url: str, chunk: DownloadChunk, thread_id: int) -> Tuple[bool, bytes]:
        """下载一个数据块"""
        try:
            headers = {
                'Range': f'bytes={chunk.start}-{chunk.end}'
            }
            
            logger.debug(f"线程 {thread_id} 开始下载: {chunk.start}-{chunk.end}")
            
            response = self.session.get(
                url, 
                headers=headers, 
                stream=True, 
                timeout=self.timeout
            )
            response.raise_for_status()
            
            # 检查服务器是否支持范围请求
            if response.status_code != 206:
                logger.warning(f"线程 {thread_id}: 服务器返回 {response.status_code}，不支持范围请求")
                return False, b''
            
            # 下载数据
            for data in response.iter_content(chunk_size=self.chunk_size):
                if data:
                    chunk.add_data(data)
                    
                    # 更新统计信息
                    with self._lock:
                        self._stats['total_downloaded'] += len(data)
            
            logger.debug(f"线程 {thread_id} 下载完成")
            return True, chunk.get_data()
            
        except Exception as e:
            logger.error(f"线程 {thread_id} 下载失败: {e}")
            with self._lock:
                self._stats['failed_chunks'] += 1
            return False, b''
    
    def _get_file_info(self, url: str) -> Tuple[Optional[int], bool]:
        """获取文件信息（大小和是否支持范围请求）"""
        try:
            response = self.session.head(url, timeout=self.timeout)
            response.raise_for_status()
            
            # 获取文件大小
            content_length = response.headers.get('Content-Length')
            file_size = int(content_length) if content_length else None
            
            # 检查是否支持范围请求
            accept_ranges = response.headers.get('Accept-Ranges', 'none')
            supports_range = accept_ranges.lower() == 'bytes'
            
            return file_size, supports_range
            
        except requests.RequestException as e:
            logger.error(f"获取文件信息失败: {e}")
            return None, False
    
    def get_stats(self) -> Dict[str, int]:
        """获取下载统计信息"""
        with self._lock:
            return self._stats.copy()
    
    def download_with_resume(self, url: str, output_path: str, **kwargs) -> bool:
        """支持断点续传的下载"""
        temp_path = output_path + '.tmp'
        
        # 检查是否有未完成的下载
        existing_size = 0
        if os.path.exists(temp_path):
            existing_size = os.path.getsize(temp_path)
            logger.info(f"发现未完成的下载，大小: {FileHelper.format_size(existing_size)}")
        
        try:
            # 发送带范围请求的HTTP请求
            headers = {}
            if existing_size > 0:
                headers['Range'] = f'bytes={existing_size}-'
            
            response = self.session.get(url, headers=headers, stream=True, **kwargs)
            response.raise_for_status()
            
            # 检查是否支持范围请求
            if existing_size > 0 and response.status_code != 206:
                logger.warning("服务器不支持范围请求，重新开始下载")
                existing_size = 0
                response = self.session.get(url, stream=True, **kwargs)
            
            # 打开文件并追加数据
            mode = 'ab' if existing_size > 0 else 'wb'
            with open(temp_path, mode) as f:
                for chunk in response.iter_content(chunk_size=self.chunk_size):
                    if chunk:
                        f.write(chunk)
                        with self._lock:
                            self._stats['total_downloaded'] += len(chunk)
            
            # 重命名临时文件
            if os.path.exists(output_path):
                os.remove(output_path)
            os.rename(temp_path, output_path)
            
            logger.info(f"下载完成（断点续传）: {output_path}")
            return True
            
        except Exception as e:
            logger.error(f"断点续传下载失败: {e}")
            return False
```

```python
"""
任务管理器
实现生产者-消费者模式，管理下载任务队列
"""

import uuid
import time
from typing import Dict, List, Optional, Any
from collections import deque
from threading import Thread, Lock, Condition, Event, Semaphore

from utils.logger import setup_logger

logger = setup_logger(__name__)

class TaskPriority:
    """任务优先级"""
    LOW = 0
    NORMAL = 1
    HIGH = 2
    URGENT = 3

class DownloadTask:
    """下载任务"""
    
    def __init__(self, url: str, output_path: str, **kwargs):
        self.task_id = str(uuid.uuid4())[:8]
        self.url = url
        self.output_path = output_path
        self.params = kwargs

    def __lt__(self, other):
        """用于优先级队列的比较"""
        return self.priority > other.priority  # 高优先级先出队
    
    def update_status(self, status: str):
        """更新任务状态"""
        self.status = status
        
        if status == 'running' and not self.started_at:
            self.started_at = time.time()
        elif status in ('completed', 'failed', 'cancelled'):
            self.completed_at = time.time()
    
    def to_dict(self) -> Dict[str, Any]:

            'url': self.url,
            'output_path': self.output_path,
            'status': self.status,

            'progress': self.progress,
            'created_at': self.created_at,
            'started_at': self.started_at,
            'completed_at': self.completed_at,
            'error': self.error
        }

class TaskManager:
    """任务管理器 - 实现生产者-消费者模式"""
    
    def __init__(self, max_workers: int = 5):
        """
        初始化任务管理器
        
        Args:
            max_workers: 最大工作线程数
        """
        self.max_workers = max_workers
        
        # 任务队列 - 使用优先级队列
        self.task_queue = []  # 最小堆
        self.task_map = {}  # 任务ID到任务的映射
        
        # 同步原语
        self.lock = Lock()
        self.not_empty = Condition(self.lock)
        self.not_full = Condition(self.lock)
        self.shutdown_event = Event()
        
        # 信号量控制并发
        self.semaphore = Semaphore(max_workers)
        
        # 工作线程
        self.workers = []
        self._start_workers()
        
        logger.info(f"任务管理器初始化完成，工作线程数: {max_workers}")
    
    def _start_workers(self):
        """启动工作线程"""
        for i in range(self.max_workers):
            worker = Thread(target=self._worker, args=(i,), daemon=True)
            worker.start()
            self.workers.append(worker)
            logger.debug(f"工作线程 {i} 已启动")
    
    def _worker(self, worker_id: int):
        """工作线程主函数"""
        logger.debug(f"工作线程 {worker_id} 开始运行")
        
        while not self.shutdown_event.is_set():
            task = None
            
            # 获取任务
            with self.not_empty:
                while not self.task_queue and not self.shutdown_event.is_set():
                    self.not_empty.wait(timeout=1.0)
                
                if self.shutdown_event.is_set():
                    break
                
                if self.task_queue:
                    task = heapq.heappop(self.task_queue)
                    task.update_status('running')
                    logger.debug(f"工作线程 {worker_id} 获取任务: {task.task_id}")
            
            if task:
                # 使用信号量控制并发
                with self.semaphore:
                    try:
                        self._process_task(task)
                    except Exception as e:
                        logger.error(f"任务处理异常 {task.task_id}: {e}")
                        task.error = str(e)
                        task.update_status('failed')
                        
                        # 如果还有重试次数，重新入队
                        if task.retries < task.max_retries:
                            task.retries += 1
                            self.requeue_task(task)
        
        logger.debug(f"工作线程 {worker_id} 停止运行")
    
    def _process_task(self, task: DownloadTask):
        """处理单个任务"""
        logger.info(f"开始处理任务: {task.task_id}")
        
        # 模拟任务处理过程
        import random
        processing_time = random.uniform(1, 5)
        
        # 模拟进度更新
        for progress in range(0, 101, 10):
            if task.status == 'cancelled':
                logger.info(f"任务被取消: {task.task_id}")
                return
            
            task.progress = progress
            time.sleep(processing_time / 10)
        
        # 模拟随机失败
        if random.random() < 0.1:  # 10%概率失败
            raise Exception("随机模拟失败")
        
        task.update_status('completed')
        logger.info(f"任务完成: {task.task_id}")
    
    def add_task(self, url: str, output_path: str, **kwargs) -> str:
        """
        添加新任务
        
        Args:
            url: 下载URL
            output_path: 输出路径
            **kwargs: 其他参数
            
        Returns:
            任务ID
        """
        task = DownloadTask(url, output_path, **kwargs)
        
        with self.lock:
            # 检查是否已存在相同任务
            for existing_task in self.task_map.values():
                if existing_task.url == url and existing_task.status in ('pending', 'queued', 'running'):
                    logger.warning(f"重复任务已存在: {existing_task.task_id}")
                    return existing_task.task_id
            
            # 添加到队列和映射
            heapq.heappush(self.task_queue, task)
            self.task_map[task.task_id] = task
            task.update_status('queued')
            
            # 通知等待的线程
            self.not_empty.notify()
        
        logger.info(f"任务已添加: {task.task_id}")
        return task.task_id
    
    def requeue_task(self, task: DownloadTask):
        """重新排队任务"""
        with self.lock:
            task.update_status('queued')
            heapq.heappush(self.task_queue, task)
            self.not_empty.notify()
        
        logger.info(f"任务重新排队: {task.task_id}")
    
    def get_task(self, task_id: str) -> Optional[DownloadTask]:
        """获取任务信息"""
        with self.lock:
            return self.task_map.get(task_id)
    
    def get_pending_tasks(self) -> Dict[str, Dict[str, Any]]:
        """获取所有待处理的任务"""
        with self.lock:
            return {
                task.task_id: task.to_dict()
                for task in self.task_map.values()
                if task.status in ('pending', 'queued')
            }
    
    def update_task_status(self, task_id: str, status: str):
        """更新任务状态"""
        with self.lock:
            if task_id in self.task_map:
                self.task_map[task_id].update_status(status)
    
    def cancel_task(self, task_id: str) -> bool:
        """取消任务"""
        with self.lock:
            if task_id in self.task_map:
                task = self.task_map[task_id]
                if task.status in ('pending', 'queued'):
                    task.update_status('cancelled')
                    logger.info(f"任务已取消: {task_id}")
                    return True
                elif task.status == 'running':
                    task.update_status('cancelled')
                    logger.info(f"正在取消任务: {task_id}")
                    return True
        return False
    
    def get_task_stats(self) -> Dict[str, int]:
        """获取任务统计信息"""
        with self.lock:
            stats = {
                'total': len(self.task_map),
                'pending': 0,
                'running': 0,
                'completed': 0,
                'failed': 0,
                'cancelled': 0
            }
            
            for task in self.task_map.values():
                stats[task.status] = stats.get(task.status, 0) + 1
            
            return stats
    
    def cleanup(self):
        """清理资源"""
        logger.info("任务管理器正在关闭...")
        
        # 设置关闭事件
        self.shutdown_event.set()
        
        # 唤醒所有等待的线程
        with self.not_empty:
            self.not_empty.notify_all()
        
        # 等待工作线程结束
        for worker in self.workers:
            worker.join(timeout=5.0)
        
        logger.info("任务管理器已关闭")
```

### 2.1 定义与原理

```cpp
// 无锁栈实现示例
template<typename T>
class LockFreeStack {
private:
    struct Node {
        T data;
        Node* next;
        Node(T const& data) : data(data), next(nullptr) {}
    };
    
    std::atomic<Node*> head;
    
public:
    void push(T const& data) {
        Node* new_node = new Node(data);
        new_node->next = head.load(std::memory_order_relaxed);
        while (!head.compare_exchange_weak(
            new_node->next, 
            new_node,
            std::memory_order_release,
            std::memory_order_relaxed
        ));
    }
    
    bool pop(T& result) {
        Node* old_head = head.load(std::memory_order_relaxed);
        while (old_head && !head.compare_exchange_weak(
            old_head,
            old_head->next,
            std::memory_order_acquire,
            std::memory_order_relaxed
        ));
        
        if (old_head) {
            result = old_head->data;
            delete old_head;
            return true;
        }
        return false;
    }
};
```

```cpp
class WritePriorityRWLock {
private:
    std::shared_mutex mutex;
    std::condition_variable cv;
    int active_readers = 0;
    bool active_writer = false;
    int waiting_writers = 0;
    
public:
    void lock_shared() {
        std::unique_lock<std::shared_mutex> lock(mutex);
        cv.wait(lock, [this]{ 
            return !active_writer && waiting_writers == 0; 
        });
        active_readers++;
    }
    
    void unlock_shared() {
        std::unique_lock<std::shared_mutex> lock(mutex);
        active_readers--;
        if (active_readers == 0) {
            cv.notify_all();
        }
    }
    
    void lock() {
        std::unique_lock<std::shared_mutex> lock(mutex);
        waiting_writers++;
        cv.wait(lock, [this]{ 
            return !active_writer && active_readers == 0; 
        });
        waiting_writers--;
        active_writer = true;
    }
    
    void unlock() {
        std::unique_lock<std::shared_mutex> lock(mutex);
        active_writer = false;
        cv.notify_all();
    }
```

## 10. 选择并发原语的指南

### 10.1 选择标准

1. **性能需求**：
   - 低争用：互斥锁通常足够
   - 高争用：考虑读写锁或无锁数据结构
   - 极低延迟：自旋锁

2. **使用场景**：
   - 互斥访问：互斥锁
   - 生产者-消费者：条件变量或信号量
   - 并行计算同步：屏障
   - 资源池：信号量

3. **公平性要求**：
   - 不关心公平性：普通互斥锁
   - 需要公平性：公平锁或读写锁

### 10.2 性能比较

| 原语 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 互斥锁 | 简单易用 | 可能造成上下文切换 | 通用互斥访问 |
| 读写锁 | 提高读性能 | 写者可能饥饿 | 读多写少 |
| 自旋锁 | 无上下文切换开销 | 忙等待浪费CPU | 临界区很短 |
| 条件变量 | 精确通知 | 需要配合锁使用 | 线程协调 |
| 信号量 | 资源计数 | 难以正确使用 | 资源池管理 |
| 原子操作 | 无锁高性能 | 复杂场景难以实现 | 计数器、标志位 |

```cpp
class Actor {

    std::thread actor_thread;

                    message_queue.pop();
                }
                message();
            }
        });

        std::lock_guard<std::mutex> lock(queue_mutex);
        message_queue.push([f = std::forward<F>(f), 
                           args = std::make_tuple(std::forward<Args>(args)...)]() {
            std::apply(f, args);
        });
        cv.notify_one();
    }
    
    ~Actor() {
        {
            std::lock_guard<std::mutex> lock(queue_mutex);
            running = false;
        }
        cv.notify_all();
        actor_thread.join();
    }
};
```

## 1. 生产者-消费者模式

### 1.1 模式概述
生产者-消费者模式是并发编程中最基础且最重要的模式之一。它通过分离数据的生成（生产者）和处理（消费者）过程，实现解耦和并发处理。

### 1.2 核心组件
- **生产者**：生成数据并放入缓冲区
- **消费者**：从缓冲区取出数据并处理
- **缓冲区**：线程安全的数据容器

### 1.3 实现方式

```java
// 线程安全的缓冲队列实现
public class BoundedBuffer<T> {
    private final Queue<T> queue = new LinkedList<>();
    private final int capacity;
    private final Lock lock = new ReentrantLock();
    private final Condition notFull = lock.newCondition();
    private final Condition notEmpty = lock.newCondition();

    public BoundedBuffer(int capacity) {
        this.capacity = capacity;
    }

    public void put(T item) throws InterruptedException {
        lock.lock();
        try {
            while (queue.size() == capacity) {
                notFull.await(); // 缓冲区满，等待
            }
            queue.add(item);
            notEmpty.signalAll(); // 通知消费者
        } finally {
            lock.unlock();
        }
    }

    public T take() throws InterruptedException {
        lock.lock();
        try {
            while (queue.isEmpty()) {
                notEmpty.await(); // 缓冲区空，等待
            }
            T item = queue.remove();
            notFull.signalAll(); // 通知生产者
            return item;
        } finally {
            lock.unlock();
        }
    }
}

// 生产者线程
```

## 2. 读写锁模式

### 2.1 模式概述
读写锁模式优化了读多写少场景下的并发性能，允许多个读操作并发执行，但写操作独占访问。

### 2.2 实现原理

```java
public class ReadWriteLockPattern {
    private final Map<String, Object> sharedData = new HashMap<>();
    private final ReadWriteLock rwLock = new ReentrantReadWriteLock();
    private final Lock readLock = rwLock.readLock();
    private final Lock writeLock = rwLock.writeLock();

    // 读操作
    public Object read(String key) {
        readLock.lock();
        try {
            // 多个读线程可以同时进入
            return sharedData.get(key);
        } finally {
            readLock.unlock();
        }
    }

    // 写操作
    public void write(String key, Object value) {
        writeLock.lock();
        try {
            // 写操作独占，阻塞所有读操作和写操作
            sharedData.put(key, value);
        } finally {
            writeLock.unlock();
        }
    }

    // 读写混合操作
    public Object readModifyWrite(String key, Function<Object, Object> modifier) {
        writeLock.lock(); // 必须获取写锁，因为会修改数据
        try {
            Object currentValue = sharedData.get(key);
            Object newValue = modifier.apply(currentValue);
            sharedData.put(key, newValue);
            return newValue;
        } finally {
            writeLock.unlock();
        }
    }
}
```

```java
public class SimpleActor<T> {
    private final Queue<T> mailbox = new ConcurrentLinkedQueue<>();
    private final ExecutorService executor;
    private final Consumer<T> handler;
    
    public SimpleActor(Consumer<T> handler) {
        this.handler = handler;
        this.executor = Executors.newSingleThreadExecutor();
        startProcessing();
    }
    
    public void tell(T message) {
        mailbox.offer(message);
    }
    
    private void startProcessing() {
        executor.submit(() -> {
            while (!Thread.currentThread().isInterrupted()) {
                T message = mailbox.poll();
                if (message != null) {
                    handler.accept(message);
                } else {
                    Thread.sleep(10); // 避免忙等待
                }
            }
        });
    }
    
    public void shutdown() {
        executor.shutdownNow();
    }
}
```

```java
public class DataPipeline<T, R> {
    private final List<PipelineStage<?, ?>> stages = new ArrayList<>();
    
    public <V> DataPipeline<T, V> addStage(Function<R, V> stageFunction) {
        stages.add(new PipelineStage<>(stageFunction));
        return (DataPipeline<T, V>) this;
    }
    
    public R execute(T input) {
        Object current = input;
        for (PipelineStage stage : stages) {
            current = stage.process(current);
        }
        return (R) current;
    }
    
    private static class PipelineStage<I, O> {
        private final Function<I, O> function;
        
        public PipelineStage(Function<I, O> function) {
            this.function = function;
        }
        
        public O process(I input) {
            return function.apply(input);
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        DataPipeline<String, Integer> pipeline = new DataPipeline<>();
        
        DataPipeline<String, Integer> result = pipeline
            .addStage((String s) -> s.toUpperCase())
            .addStage((String s) -> s.length());
        
        int length = result.execute("hello");
        System.out.println("字符串长度: " + length);
```

### 8.1 Fork/Join框架

```java
public class ForkJoinDemo extends RecursiveTask<Long> {
    private final long[] numbers;
    private final int start;
    private final int end;
    private static final int THRESHOLD = 10000;
    
    public ForkJoinDemo(long[] numbers, int start, int end) {
        this.numbers = numbers;
        this.start = start;
        this.end = end;
    }
    
    @Override
    protected Long compute() {
        int length = end - start;
        
        if (length <= THRESHOLD) {
            // 直接计算
            long sum = 0;
            for (int i = start; i < end; i++) {
                sum += numbers[i];
            }
            return sum;
        } else {
            // 分解任务
            int mid = start + length / 2;
            
            ForkJoinDemo leftTask = new ForkJoinDemo(numbers, start, mid);
            ForkJoinDemo rightTask = new ForkJoinDemo(numbers, mid, end);
            
            // 异步执行左任务
            leftTask.fork();
            
            // 同步执行右任务
            long rightResult = rightTask.compute();
            
            // 等待左任务完成
            long leftResult = leftTask.join();
            
            return leftResult + rightResult;
        }
    }
    
    // 使用示例
    public static void main(String[] args) {
        long[] numbers = new long[1000000];
        // 初始化数组...
        
        ForkJoinPool pool = new ForkJoinPool();
        ForkJoinDemo task = new ForkJoinDemo(numbers, 0, numbers.length);
        
        long result = pool.invoke(task);
        System.out.println("总和: " + result);
    }
}
```
