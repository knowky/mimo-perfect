# 密码学从古典到量子
## 第四章：量子密码学

### 引言：经典密码学的根本局限

在前几章中，我们探讨了从凯撒密码到现代公钥密码（如RSA、ECC）的演进。这些古典和现代密码体系，无论其设计多么精巧，其安全性都依赖于一个共同的前提：**计算复杂性假设**。例如，RSA的安全性依赖于大整数因子分解的困难性。然而，这一前提面临两大根本性挑战：

1.  **数学突破**：一个天才的算法可能彻底颠覆某个数学难题的计算复杂度。
2.  **计算能力的革命**：尤其是量子计算的出现。1994年，彼得·肖尔提出的“肖尔算法”能在多项式时间内分解大整数和求解离散对数问题，这意味着理论上，一台足够强大的量子计算机将能轻易攻破目前广泛使用的RSA和ECC等公钥密码体系。

为了应对这一“量子威胁”，密码学研究走向了两条路径：后量子密码学（PQC）和**量子密码学**。后量子密码学试图寻找在经典和量子计算机上都难以攻破的数学难题来构建新算法，其核心仍是**计算安全性**。而量子密码学则走上了一条截然不同的道路——它利用量子力学的基本原理，旨在实现**信息论安全性**，即其安全性不依赖于攻击者的计算能力，而是由物理定律本身所保证。

本章将深入探讨量子密码学，特别是其最成功的分支——量子密钥分发（QKD）。

### 第一节：量子密码学的物理基石

量子密码学建立在量子力学的三大核心原理之上，这些原理共同构成了其安全性的基石。

#### 1.1 量子比特与叠加态
在经典信息中，比特（bit）是0或1。在量子信息中，基本单元是**量子比特（qubit）**。一个量子比特可以处于|0⟩态、|1⟩态，或更一般的，**这两个基态的线性叠加态**：|ψ⟩ = α|0⟩ + β|1⟩，其中α和β是复数，满足 |α|² + |β|² = 1。这意味着在测量之前，量子比特同时处于0和1的状态，测量会导致波函数“坍缩”到0或1，其概率分别为|α|²和|β|²。

#### 1.2 海森堡测不准原理
对于一个量子系统，我们无法同时精确测量其所有的共轭物理量（例如位置和动量）。在量子密码学中，这通常表现为对光子**偏振态**的测量。对一个处于叠加态的光子，用不同基矢（如线偏振基+/×或圆偏振基）进行测量会得到不同的结果，并且测量一个基矢会不可避免地扰动另一个基矢的信息。任何窃听者（Eve）对量子信道的测量行为，都会不可避免地引入可检测的扰动。

#### 1.3 量子不可克隆定理
这是量子密码学的“杀手锏”。该定理指出，**不存在一个通用的物理过程可以完美地复制一个未知的量子态**。这与经典信息可以随意复制形成鲜明对比。如果Eve试图截获并复制在通信双方（Alice和Bob）之间传输的量子比特，以期稍后分析，她必然会破坏原始量子态，从而留下痕迹。

**小结**：叠加态使得信息可以编码在单个量子系统中；测不准原理和不可克隆定理确保了任何窃听行为都会引入扰动。Alice和Bob可以通过检验这种扰动来发现窃听，从而保证密钥的绝对安全。

### 第二节：核心协议——量子密钥分发

量子密钥分发是量子密码学最成熟和最具应用前景的领域。其目标是让两个地理上分离的合法用户（Alice和Bob）在公开的量子信道上生成并共享一串绝对安全的随机密钥，随后可以将该密钥用于一次一密或对称加密（如AES）进行安全通信。

#### 2.1 BB84协议：奠基之作
由Charles Bennett和Gilles Brassard于1984年提出，BB84是第一个QKD协议，也是理解其他协议的基础。

**协议流程（理想化版本）**：
1.  **制备与发送**：Alice随机生成一串比特（0和1）。对于每个比特，她再随机选择一个基矢（例如，十字基`+`或叉字基`×`）。根据基矢和比特值，她制备相应的光子偏振态（例如，`+`基下0→|↑⟩， 1→|→⟩； `×`基下0→|↗⟩， 1→|↘⟩），并通过量子信道发送给Bob。
2.  **接收与测量**：Bob收到每个光子后，也独立随机选择一个基矢（`+`或`×`）进行测量，并记录下结果和所用的基矢。
3.  **基矢比对（公开讨论）**：在所有光子发送完成后，Alice和Bob通过一个公开的经典信道（如互联网），对比他们各自使用的基矢序列。他们**只保留那些基矢选择相同的轮次**的数据，并丢弃基矢不同的数据。留下的比特串，理论上应该完全一致，构成了**原始密钥**。
4.  **窃听检测**：为了检查是否有Eve窃听，Alice和Bob从原始密钥中随机抽取一部分子集进行公开比对。如果Eve在量子信道上进行了测量或复制，由于测不准原理和不可克隆定理，她必然会改变部分光子的量子态。这会导致Alice和Bob在比对时发现错误率异常升高。如果错误率低于一个设定的安全阈值（通常由协议的安全性证明给出），则认为信道安全，可以继续；否则，放弃本次生成的密钥。
5.  **保密增强**：即使没有发现窃听，为了消除Eve可能获得的少量信息（例如来自信道的自然损耗），Alice和Bob还会对剩余的原始密钥进行**保密放大**等后处理操作，最终得到一串安全的、完全随机的共享密钥。

**安全性核心**：Eve无法同时获取光子所携带的比特值和基矢信息。如果她猜测的基矢错误，她的测量结果就是随机的，并且她转发给Bob的光子状态也会被改变，从而在步骤4中被发现。

#### 2.2 E91协议：基于量子纠缠
由Artur Ekert于1991年提出，E91协议将安全性建立在更深刻的物理原理——**量子纠缠**之上。

**核心思想**：
1.  一个源产生处于最大纠缠态的光子对（如贝尔态： |Φ⁺⟩ = (|00⟩ + |11⟩)/√2）。
2.  源将光子对中的两个光子分别发送给Alice和Bob。
3.  Alice和Bob各自独立、随机地选择基矢测量自己的光子。
4.  测量后，他们公开比较基矢（仅对一部分数据），并利用贝尔不等式的违背来验证他们共享的确实是纠缠对，且未被窃听干扰。

**安全性优势**：E91的安全性直接源于对贝尔不等式违背的检验。任何试图截获并测量光子的行为（即试图获取“现实”信息的隐变量行为），都会破坏纠缠关联，使贝尔不等式的违背程度下降，从而被Alice和Bob检测到。这为安全性提供了更直接的物理判据。

#### 2.3 其他重要协议
*   **B92协议**：BB84的简化版，只使用两种非正交的量子态，同样利用了态不可精确区分的原理。
*   **连续变量QKD**：使用光的正交分量（如振幅和相位）作为连续变量编码信息，更适合与现有光通信基础设施结合。
*   **设备无关QKD**：一种更先进的范式，其安全性不依赖于对通信设备内部工作原理的信任，仅通过对贝尔不等式的违背来保证，安全性最高，但对实验技术要求极为苛刻。

### 第三节：从理论到现实：挑战与技术

将量子密码学从实验室推向实际应用，面临着一系列工程与技术挑战。

#### 3.1 主要技术挑战
1.  **传输距离与损耗**：光子在光纤中传输会经历指数级衰减。尽管使用了量子中继器概念，但完全实用化的量子中继器（需量子存储和纠缠交换）仍在研发中。目前，地面光纤QKD系统无中继安全距离约在百公里量级。自由空间（卫星）QKD成为更远距离的可行方案。
2.  **码率**：安全密钥生成速率（每秒比特数）通常远低于经典通信速率。提升码率需要更高效的单光子源、探测器和协议。
3.  **器件不完美**：实际设备中，单光子源不纯净、探测器存在暗计数、信道存在背景噪声等，都会为Eve提供潜在的攻击侧信道（如时移攻击、致盲攻击）。安全性证明必须考虑这些现实缺陷。
4.  **成本与集成**：量子设备（如单光子探测器、精密光学系统）成本高昂，且难以与经典电信设备大规模集成。

#### 3.2 应用与发展现状
尽管存在挑战，量子密码学已经走出实验室，进入了特定应用阶段。
*   **点对点QKD链路**：已在中国“墨子号”量子科学实验卫星与地面站之间、欧洲的多个城市间、中国的“京沪干线”等主干网上实现。
*   **量子密钥分发网络**：多个节点通过可信中继或未来量子中继连接，形成城域或广域QKD网络，为中国、欧洲、日本等地的政府、金融和关键基础设施提供试验性安全保障。
*   **与其他技术融合**：QKD与经典密码（如对称加密）结合，为密钥分发这一最脆弱的环节提供物理层保护，形成“混合安全”体系。

### 第四节：量子密码学的边界与展望

必须清醒认识量子密码学的能力边界：
1.  **它解决的是密钥分发问题，而非加密所有问题**。它提供的是一个安全的密钥流，真正的数据加密仍需依赖经典算法。
2.  **它无法抵御所有攻击**。例如，无法防御针对接收端或存储设备的直接物理攻击（中间人攻击的某些变种，若实施在经典信道上则可被认证协议防御，但针对设备本身的攻击则不同）。
3.  **它不是后量子密码的替代品**。两者应对不同层面的安全需求：QKD提供信息论安全，但需要专用硬件；PQC提供计算安全性，但易于软件部署。未来最可能的图景是两者互补共存。

**未来展望**：
*   **技术突破**：实用化的量子中继器和量子存储将彻底改变长距离QKD的格局。
*   **天地一体化网络**：结合低轨卫星和地面光纤，构建覆盖全球的量子通信网络。
*   **量子互联网**：从量子密钥分发到分布式量子计算、盲量子计算，量子密码学是通往更宏伟的量子互联网愿景的第一步。

### 本章总结

量子密码学标志着密码学范式的根本性转变——从依赖计算复杂性到依赖物理定律。它利用量子叠加、测不准原理和不可克隆定理，为密钥分发提供了理论上无条件的安全保障。尽管面临传输距离、码率和工程化等挑战，以BB84和E91为代表的QKD协议已成功从理论走向实践，在特定高安全领域展现出巨大潜力。在未来，它将与后量子密码学一道，共同构筑起应对量子计算时代信息安全威胁的坚固防线。理解量子密码学，不仅是了解一种新技术，更是洞见信息安全未来形态的关键。
