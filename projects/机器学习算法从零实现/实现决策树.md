# 决策树从零实现

## 1. 算法概述

决策树是一种监督学习算法，可用于分类和回归任务。其核心思想是通过递归地将数据集划分为更小的子集来构建树结构。

### 关键概念：
- **信息增益**：用于选择最佳划分特征（ID3算法）
- **基尼不纯度**：用于选择最佳划分特征（CART算法）
- **信息熵**：衡量数据集的不确定性

## 2. 数学原理

### 2.1 信息熵（Entropy）
对于数据集 \(D\)，假设有 \(K\) 个类别，第 \(k\) 类样本的比例为 \(p_k\)：
\[
H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k
\]

### 2.2 信息增益（Information Gain）
特征 \(A\) 对数据集 \(D\) 的信息增益：
\[
IG(D, A) = H(D) - H(D|A)
\]
其中条件熵：
\[
H(D|A) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} H(D^v)
\]
\(V\) 是特征 \(A\) 的可能取值数量，\(D^v\) 是特征 \(A\) 取值为 \(v\) 的子集。

### 2.3 基尼不纯度（Gini Impurity）
\[
Gini(D) = 1 - \sum_{k=1}^{K} p_k^2
\]
特征 \(A\) 对数据集 \(D\) 的基尼指数：
\[
Gini(D, A) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} Gini(D^v)
\]

```python
import numpy as np
from collections import Counter
import matplotlib.pyplot as plt
import os

class TreeNode:
    """决策树节点类"""
    def __init__(self, feature_idx=None, threshold=None, left=None, right=None, value=None):
        self.feature_idx = feature_idx  # 划分特征索引
        self.threshold = threshold      # 划分阈值
        self.left = left                # 左子树
        self.right = right              # 右子树
        self.value = value              # 叶子节点的预测值

class DecisionTree:
    """决策树分类器"""
    
    def __init__(self, max_depth=10, min_samples_split=2, min_samples_leaf=1, 
                 criterion='gini', random_state=None):
        """
        初始化决策树
        
        参数:
        max_depth: 树的最大深度
        min_samples_split: 分裂节点所需的最小样本数
        min_samples_leaf: 叶子节点的最小样本数
        criterion: 划分标准 ('gini' 或 'entropy')
        random_state: 随机种子
        """
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.min_samples_leaf = min_samples_leaf
        self.criterion = criterion
        self.random_state = random_state
        self.root = None
        
    def _gini_impurity(self, y):
        """计算基尼不纯度"""
        n = len(y)
        if n == 0:
            return 0
        
        counts = np.bincount(y)
        probabilities = counts / n
        return 1 - np.sum(probabilities ** 2)
    
    def _entropy(self, y):
        """计算信息熵"""
        n = len(y)
        if n == 0:
            return 0
        
        counts = np.bincount(y)
        probabilities = counts / n
        # 过滤掉概率为0的项
        probabilities = probabilities[probabilities > 0]
        return -np.sum(probabilities * np.log2(probabilities))
    
    def _information_gain(self, y, y_left, y_right, criterion):
        """计算信息增益"""
        if criterion == 'gini':
            parent = self._gini_impurity(y)
            child = (len(y_left) * self._gini_impurity(y_left) + 
                    len(y_right) * self._gini_impurity(y_right)) / len(y)
        else:  # entropy
            parent = self._entropy(y)
            child = (len(y_left) * self._entropy(y_left) + 
                    len(y_right) * self._entropy(y_right)) / len(y)
        
        return parent - child
    
    def _split_dataset(self, X, y, feature_idx, threshold):
        """根据特征和阈值划分数据集"""
        left_mask = X[:, feature_idx] <= threshold
        right_mask = ~left_mask
        
        return (X[left_mask], y[left_mask]), (X[right_mask], y[right_mask])
    
    def _best_split(self, X, y):
        """寻找最佳划分特征和阈值"""
        n_samples, n_features = X.shape
        
        if n_samples < self.min_samples_split:
            return None, None
        
        best_gain = -np.inf
        best_feature = None
        best_threshold = None
        
        # 遍历所有特征
        for feature_idx in range(n_features):
            feature_values = X[:, feature_idx]
            unique_values = np.unique(feature_values)
            
            if len(unique_values) <= 1:
                continue
            
            # 计算可能的阈值（使用中点）
            thresholds = (unique_values[:-1] + unique_values[1:]) / 2
            
            for threshold in thresholds:
                (X_left, y_left), (X_right, y_right) = self._split_dataset(
                    X, y, feature_idx, threshold
                )
                
                # 检查叶子节点样本数约束
                if (len(y_left) < self.min_samples_leaf or 
                    len(y_right) < self.min_samples_leaf):
                    continue
                
                # 计算信息增益
                gain = self._information_gain(y, y_left, y_right, self.criterion)
                
                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature_idx
                    best_threshold = threshold
        
        return best_feature, best_threshold
    
    def _build_tree(self, X, y, depth=0):
        """递归构建决策树"""
        n_samples, n_features = X.shape
        n_classes = len(np.unique(y))
        
        # 停止条件
        if (depth >= self.max_depth or 
            n_classes == 1 or 
            n_samples < self.min_samples_split):
            # 创建叶子节点，选择出现次数最多的类别
            leaf_value = self._most_common_label(y)
            return TreeNode(value=leaf_value)
        
        # 寻找最佳划分
        feature_idx, threshold = self._best_split(X, y)
        
        if feature_idx is None:
            leaf_value = self._most_common_label(y)
            return TreeNode(value=leaf_value)
        
        # 划分数据集
        (X_left, y_left), (X_right, y_right) = self._split_dataset(
            X, y, feature_idx, threshold
        )
        
        # 递归构建子树
        left_subtree = self._build_tree(X_left, y_left, depth + 1)
        right_subtree = self._build_tree(X_right, y_right, depth + 1)
        
        return TreeNode(
            feature_idx=feature_idx,
            threshold=threshold,
            left=left_subtree,
            right=right_subtree
        )
    
    def _most_common_label(self, y):
        """获取最常见的类别标签"""
        counter = Counter(y)
        return counter.most_common(1)[0][0]
    
    def fit(self, X, y):
        """训练决策树"""
        if self.random_state is not None:
            np.random.seed(self.random_state)
        
        # 将数据转换为numpy数组
        X = np.array(X)
        y = np.array(y)
        
        self.root = self._build_tree(X, y)
        return self
    
    def _traverse_tree(self, x, node):
        """遍历树进行预测"""
        if node.value is not None:
            return node.value
        
        if x[node.feature_idx] <= node.threshold:
            return self._traverse_tree(x, node.left)
        return self._traverse_tree(x, node.right)
    
    def predict(self, X):
        """预测新数据"""
        X = np.array(X)
        return np.array([self._traverse_tree(x, self.root) for x in X])
    
    def score(self, X, y):
        """计算准确率"""
        predictions = self.predict(X)
        return np.mean(predictions == y)
    
    def _print_tree(self, node, indent=""):
        """打印树结构"""
        if node.value is not None:
            print(f"{indent}Leaf: {node.value}")
            return
        
        print(f"{indent}Feature {node.feature_idx} <= {node.threshold:.3f}")
        print(f"{indent}├── Left:")
        self._print_tree(node.left, indent + "│   ")
        print(f"{indent}└── Right:")
        self._print_tree(node.right, indent + "    ")
    
    def print_tree(self):
        """打印整个决策树"""
        print("决策树结构:")
        self._print_tree(self.root)
    
    def visualize_tree(self, feature_names=None, class_names=None, filename="decision_tree.png"):
        """可视化决策树（需要matplotlib和graphviz）"""
        try:
            import graphviz
        except ImportError:
            print("需要安装graphviz库: pip install graphviz")
            return
        
        def _add_nodes(node, graph, node_id, counter, feature_names, class_names):
            if node.value is not None:
                label = f"Predict: {class_names[node.value] if class_names else node.value}"
                graph.node(str(node_id), label, shape='box', style='filled', fillcolor='lightblue')
                return
            
            feature_name = (feature_names[node.feature_idx] 
                          if feature_names 
                          else f"Feature {node.feature_idx}")
            label = f"{feature_name} <= {node.threshold:.3f}"
            graph.node(str(node_id), label, shape='ellipse', style='filled', fillcolor='lightyellow')
            
            # 左子树
            left_id = next(counter)
            graph.edge(str(node_id), str(left_id), label="True")
            _add_nodes(node.left, graph, left_id, counter, feature_names, class_names)
            
            # 右子树
            right_id = next(counter)
            graph.edge(str(node_id), str(right_id), label="False")
            _add_nodes(node.right, graph, right_id, counter, feature_names, class_names)
        
        # 创建计数器
        counter = iter(range(1, 1000))
        
        # 创建图
        dot = graphviz.Digraph(comment='Decision Tree')
        dot.attr(rankdir='TB')
        
        # 添加节点
        root_id = next(counter)
        _add_nodes(self.root, dot, root_id, counter, feature_names, class_names)
        
        # 渲染并保存
        dot.render(filename, format='png', cleanup=True)
        print(f"决策树可视化已保存到 {filename}")

# 辅助函数：生成示例数据集
def generate_sample_data(n_samples=100, random_state=42):
    """生成简单的二分类数据集"""
    np.random.seed(random_state)
    
    # 生成两个特征
    X = np.random.randn(n_samples, 2)
    
    # 创建非线性决策边界
    y = ((X[:, 0] ** 2 + X[:, 1] ** 2) < 1.5).astype(int)
    
    return X, y

def plot_decision_boundary(tree, X, y, title="Decision Tree Decision Boundary"):
    """绘制决策边界"""
    h = 0.02  # 网格步长
    
    # 创建网格
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                         np.arange(y_min, y_max, h))
    
    # 预测网格点
    Z = tree.predict(np.c_[xx.ravel(), yy.ravel()])
    Z = Z.reshape(xx.shape)
    
    # 绘制决策边界
    plt.figure(figsize=(10, 8))
    plt.contourf(xx, yy, Z, alpha=0.3, cmap='coolwarm')
    plt.scatter(X[:, 0], X[:, 1], c=y, cmap='coolwarm', edgecolor='k', s=50)
    plt.title(title)
    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.colorbar()
    plt.show()

def create_output_dir():
    """创建输出目录"""
    output_dir = "decision_tree_output"
    if not os.path.exists(output_dir):
        os.makedirs(output_dir)
    return output_dir

# 主函数：演示决策树的使用
def main():
    """主函数：演示决策树的训练和预测"""
    print("=" * 60)
    print("决策树从零实现")
    print("=" * 60)
    
    # 创建输出目录
    output_dir = create_output_dir()
    
    # 1. 生成示例数据
    print("\n1. 生成示例数据...")
    X, y = generate_sample_data(n_samples=200)
    print(f"数据集大小: {X.shape[0]} 样本, {X.shape[1]} 特征")
    print(f"类别分布: {Counter(y)}")
    
    # 2. 划分训练集和测试集
    print("\n2. 划分训练集和测试集...")
    train_size = int(0.8 * len(X))
    indices = np.random.permutation(len(X))
    train_idx, test_idx = indices[:train_size], indices[train_size:]
    
    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = y[train_idx], y[test_idx]
    
    print(f"训练集大小: {len(X_train)}")
    print(f"测试集大小: {len(X_test)}")
    
    # 3. 训练决策树
    print("\n3. 训练决策树...")
    tree = DecisionTree(
        max_depth=5,
        min_samples_split=5,
        min_samples_leaf=2,
        criterion='gini',
        random_state=42
    )
    
    tree.fit(X_train, y_train)
    
    # 4. 评估模型
    print("\n4. 评估模型...")
    train_acc = tree.score(X_train, y_train)
    test_acc = tree.score(X_test, y_test)
    
    print(f"训练集准确率: {train_acc:.4f}")
    print(f"测试集准确率: {test_acc:.4f}")
    
    # 5. 打印决策树结构
    print("\n5. 决策树结构:")
    tree.print_tree()
    
    # 6. 可视化决策边界
    print("\n6. 生成可视化结果...")
    
    # 绘制决策边界
    plt.figure(figsize=(10, 8))
    plot_decision_boundary(tree, X_train, y_train, 
                          "Training Set Decision Boundary")
    plt.savefig(os.path.join(output_dir, "decision_boundary_train.png"), 
                dpi=150, bbox_inches='tight')
    plt.show()
    
    # 测试集决策边界
    plt.figure(figsize=(10, 8))
    plot_decision_boundary(tree, X_test, y_test, 
                          "Test Set Decision Boundary")
    plt.savefig(os.path.join(output_dir, "decision_boundary_test.png"), 
                dpi=150, bbox_inches='tight')
    plt.show()
    
    # 7. 特征重要性分析
    print("\n7. 特征重要性分析:")
    # 由于我们的实现没有直接计算特征重要性，
    # 我们可以通过统计每个特征被选为划分特征的次数来估计
    feature_importance = [0] * X.shape[1]
    
    def count_feature_usage(node, feature_importance):
        if node.value is not None:
            return
        
        feature_importance[node.feature_idx] += 1
        count_feature_usage(node.left, feature_importance)
        count_feature_usage(node.right, feature_importance)
    
    count_feature_usage(tree.root, feature_importance)
    
    # 归一化特征重要性
    total = sum(feature_importance)
    if total > 0:
        feature_importance = [x/total for x in feature_importance]
    
    for i, importance in enumerate(feature_importance):
        print(f"特征 {i}: {importance:.4f}")
    
    # 8. 预测新样本
    print("\n8. 预测新样本:")
    new_samples = np.array([
        [0.5, 0.5],   # 可能在边界内
        [-0.5, -0.5], # 可能在边界外
        [1.5, 1.5]    # 可能在边界外
    ])
    
    predictions = tree.predict(new_samples)
    for i, (sample, pred) in enumerate(zip(new_samples, predictions)):
        print(f"样本 {i+1}: {sample} -> 预测类别: {pred}")
    
    # 9. 保存结果
    print("\n9. 保存结果...")
    
    # 保存模型参数（简化版，实际中应使用序列化）
    model_info = {
        'max_depth': tree.max_depth,
        'min_samples_split': tree.min_samples_split,
        'min_samples_leaf': tree.min_samples_leaf,
        'criterion': tree.criterion,
        'train_accuracy': train_acc,
        'test_accuracy': test_acc,
        'feature_importance': feature_importance
    }
    
    with open(os.path.join(output_dir, "model_info.txt"), "w") as f:
        for key, value in model_info.items():
            f.write(f"{key}: {value}\n")
    
    # 保存决策树可视化
    try:
        tree.visualize_tree(
            feature_names=["Feature 0", "Feature 1"],
            class_names=["Class 0", "Class 1"],
            filename=os.path.join(output_dir, "decision_tree_visualization")
        )
        print("决策树可视化已保存")
    except Exception as e:
        print(f"无法生成graphviz可视化: {e}")
        print("已保存决策边界图作为替代")
    
    print(f"\n所有结果已保存到 {output_dir} 目录")
    print("=" * 60)
    
    return tree

if __name__ == "__main__":
    # 运行主函数
    tree = main()
    
    # 交互式演示
    print("\n" + "=" * 60)
    print("交互式演示")

    while True:
```

## 4. 代码结构说明

### 4.1 核心类设计

1. **`TreeNode`类**：
   - 存储决策树节点信息
   - 包含划分特征、阈值、左右子树和预测值

2. **`DecisionTree`类**：
   - 实现完整的决策树算法
   - 支持多种停止条件和划分标准
   - 提供训练、预测和可视化功能

### 4.2 关键算法实现

1. **不纯度计算**：
   - `gini_impurity()`：计算基尼不纯度
   - `entropy()`：计算信息熵

2. **特征选择**：
   - `best_split()`：寻找最佳划分特征和阈值
   - `information_gain()`：计算信息增益

3. **树构建**：
   - `build_tree()`：递归构建决策树
   - `split_dataset()`：划分数据集

### 4.3 特色功能

1. **可视化**：
   - 决策边界可视化
   - 树结构可视化（需要graphviz）

3. **交互式预测**：
   - 允许用户输入新样本进行预测

## 7. 理论联系实际

### 7.1 算法对比

| 算法 | 划分标准 | 特点 |
|------|----------|------|
| ID3 | 信息增益 | 只能处理离散特征，容易过拟合 |
| C4.5 | 增益率 | 改进了ID3，能处理连续特征 |
| CART | 基尼指数/方差减少 | 二叉树，支持分类和回归 |

### 7.2 超参数影响

1. **max_depth**：
   - 值越小，树越简单，偏差大，方差小
   - 值越大，树越复杂，偏差小，方差大

2. **min_samples_split**：
   - 值越大，树越简单，防止过拟合
   - 值越小，树越复杂，可能过拟合

3. **min_samples_leaf**：
   - 确保叶子节点有足够的样本
   - 提高模型的泛化能力
