# 操作系统内核实现：设备驱动章节

## 1. 设备驱动概述

### 1.1 设备驱动在操作系统中的作用
设备驱动是操作系统内核中负责与硬件设备通信的软件模块，它为上层应用提供统一的访问接口，同时屏蔽底层硬件的差异性。

```
┌─────────────────────────────────────────┐
│              应用程序层                    │
├─────────────────────────────────────────┤
│              系统调用层                    │
├─────────────────────────────────────────┤
│           虚拟文件系统(VFS)                │
├─────────────────────────────────────────┤
│           设备驱动层                       │
├─────────────────────────────────────────┤
│             硬件抽象层                     │
├─────────────────────────────────────────┤
│             物理硬件                       │
└─────────────────────────────────────────┘
```

### 1.2 设备分类
1. **字符设备**：以字节为单位进行读写，如串口、键盘、鼠标
2. **块设备**：以数据块为单位进行读写，支持随机访问，如硬盘、SSD
3. **网络设备**：处理网络数据包，如网卡、WiFi适配器

## 4. 设备驱动实现示例

### 4.1 简单字符设备驱动
```c
#include <linux/module.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/uaccess.h>

#define DEVICE_NAME "mychardev"
#define DEVICE_COUNT 1

static dev_t dev_num;
static struct cdev my_cdev;
static char device_buffer[1024];
static size_t buffer_size = 0;

// 文件打开操作
static int my_open(struct inode *inode, struct file *file) {
    printk(KERN_INFO "Device opened\n");
    return 0;
}

// 文件释放操作
static int my_release(struct inode *inode, struct file *file) {
    printk(KERN_INFO "Device closed\n");
    return 0;
}

// 读操作
static ssize_t my_read(struct file *file, char __user *buf, size_t count, loff_t *pos) {
    size_t to_read;
    
    if (*pos >= buffer_size)
        return 0;
    
    to_read = min(count, buffer_size - *pos);
    
    if (copy_to_user(buf, device_buffer + *pos, to_read))
        return -EFAULT;
    
    *pos += to_read;
    return to_read;
}

// 写操作
static ssize_t my_write(struct file *file, const char __user *buf, size_t count, loff_t *pos) {
    size_t to_write;
    
    if (*pos >= sizeof(device_buffer))
        return -ENOSPC;
    
    to_write = min(count, sizeof(device_buffer) - *pos);
    
    if (copy_from_user(device_buffer + *pos, buf, to_write))
        return -EFAULT;
    
    *pos += to_write;
    buffer_size = max(buffer_size, *pos);
    return to_write;
}

// 文件操作表
static const struct file_operations my_fops = {
    .owner = THIS_MODULE,
    .open = my_open,
    .release = my_release,
    .read = my_read,
    .write = my_write,
};

// 模块初始化
static int __init my_init(void) {
    int ret;
    
    // 动态分配设备号
    ret = alloc_chrdev_region(&dev_num, 0, DEVICE_COUNT, DEVICE_NAME);
    if (ret < 0) {
        printk(KERN_ERR "Failed to allocate device number\n");
        return ret;
    }
    
    // 初始化字符设备
    cdev_init(&my_cdev, &my_fops);
    my_cdev.owner = THIS_MODULE;
    
    // 添加字符设备到系统
    ret = cdev_add(&my_cdev, dev_num, DEVICE_COUNT);
    if (ret < 0) {
        unregister_chrdev_region(dev_num, DEVICE_COUNT);
        printk(KERN_ERR "Failed to add cdev\n");
        return ret;
    }
    
    printk(KERN_INFO "Device registered with major=%d, minor=%d\n", 
           MAJOR(dev_num), MINOR(dev_num));
    return 0;
}

// 模块退出
static void __exit my_exit(void) {
    cdev_del(&my_cdev);
    unregister_chrdev_region(dev_num, DEVICE_COUNT);
    printk(KERN_INFO "Device unregistered\n");
}

module_init(my_init);
module_exit(my_exit);

MODULE_LICENSE("GPL");
MODULE_AUTHOR("OS Kernel");
MODULE_DESCRIPTION("Simple character device driver");
```

### 13.2 Makefile模板
```makefile
# 设备驱动Makefile模板
obj-m += my_driver.o

# 驱动源文件
my_driver-objs := main.o device.o interrupt.o power.o

# 内核源码路径
KERNEL_SRC := /lib/modules/$(shell uname -r)/build

# 编译选项
EXTRA_CFLAGS := -Wall -Werror -O2

.PHONY: all clean install uninstall

all:
    $(MAKE) -C $(KERNEL_SRC) M=$(PWD) modules

clean:
    $(MAKE) -C $(KERNEL_SRC) M=$(PWD) clean

install:
    $(MAKE) -C $(KERNEL_SRC) M=$(PWD) modules_install
    depmod -a

uninstall:
    rm -f /lib/modules/$(shell uname -r)/extra/my_driver.ko
    depmod -a
```

## 14. 总结与展望

### 14.1 设备驱动发展趋势
1. **现代硬件支持**：支持新的硬件标准（如PCIe 4.0/5.0、USB4、NVMe 2.0）
