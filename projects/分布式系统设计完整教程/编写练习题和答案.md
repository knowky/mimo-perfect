# 分布式系统设计练习题答案

## 第一部分：基础概念

### 1. 答案：D
**解析：** CAP定理指出分布式系统最多只能同时满足以下三项中的两项：一致性(Consistency)、可用性(Availability)、分区容忍性(Partition tolerance)。选项A和B都是在特定条件下做出的权衡选择，但都不是"可行"的通用解决方案，因为系统设计必须在三者之间做出权衡。选项C错误，因为分区容忍性是分布式系统的基本要求，不能放弃。

### 2. 答案：
- **线性一致性(Linearizability)**：最强的一致性模型，所有操作看起来都是原子执行的，且操作顺序与实际时间顺序一致。实现复杂，性能开销大。
- **顺序一致性(Sequential Consistency)**：所有进程看到的操作顺序是一致的，但不一定与实际时间顺序相同。比线性一致性弱，性能更好。
- **因果一致性(Causal Consistency)**：保证有因果关系的操作顺序，无因果关系的操作可以乱序。适合需要一定顺序但非严格顺序的场景。
- **最终一致性(Eventual Consistency)**：最弱的一致性，保证如果没有新的更新，最终所有副本会达到一致状态。性能最好，但可能读到旧数据。

### 3. 答案：
**物理时钟**：基于真实时间，存在时钟漂移问题。需要NTP等协议同步，但网络延迟会导致误差。

**逻辑时钟**：
- **Lamport时间戳**：通过递增计数和消息传递来建立偏序关系。简单高效，但无法区分并发事件。
- **向量时钟**：每个节点维护一个向量，可以精确判断因果关系和并发关系。空间复杂度较高(O(n))。

### 4. 答案：
| 方面 | Paxos | Raft | ZAB |
|------|-------|------|-----|
| **领导选举** | 多Proposer竞争，可能活锁 | 强Leader，任期机制 | 类似Raft，有Leader和Follower |
| **日复制** | Phase1a/b, 2a/b两阶段 | Leader接收后复制到多数节点 | Leader顺序分发Proposal |
| **故障恢复** | 需要重新选举 | Leader失效后选举新Leader | Leader失效后重新选举 |
| **实现复杂度** | 高，论文难理解 | 中，设计清晰易懂 | 中，专为ZooKeeper设计 |

### 8. 答案：
**Redis分布式锁设计：**
```python
class RedisDistributedLock:
    def __init__(self, redis_client, lock_key, timeout=10):
        self.redis = redis_client
        self.lock_key = lock_key
        self.timeout = timeout
        self.identifier = str(uuid.uuid4())
    
    def acquire(self, retry_count=3):
        end_time = time.time() + self.timeout
        while retry_count > 0 and time.time() < end_time:
            if self.redis.set(self.lock_key, self.identifier, nx=True, ex=self.timeout):
                return True
            retry_count -= 1
            time.sleep(0.1)
        return False
    
    def release(self):
        # 使用Lua脚本保证原子性
        script = """
        if redis.call("GET", KEYS[1]) == ARGV[1] then
            return redis.call("DEL", KEYS[1])
        else
            return 0
        end
        """
        return self.redis.eval(script, 1, self.lock_key, self.identifier)
    
    def extend(self, additional_time):
        # 扩展锁时间，需要检查锁持有者
        script = """
        if redis.call("GET", KEYS[1]) == ARGV[1] then
            return redis.call("EXPIRE", KEYS[1], ARGV[2])
        else
            return 0
        end
        """
        return self.redis.eval(script, 1, self.lock_key, self.identifier, 
                              self.timeout + additional_time)
```

public class RateLimiter {
    // 令牌桶算法核心
    private long lastRefillTime;
    private double tokens;
    private final double refillRate;
    private final double capacity;
    
    public synchronized boolean tryAcquire() {
        refill();
        if (tokens >= 1) {
            tokens -= 1;
            return true;
        }
        return false;
    }
    
    private void refill() {
        long now = System.currentTimeMillis();
        double elapsed = (now - lastRefillTime) / 1000.0;
        tokens = Math.min(capacity, tokens + elapsed * refillRate);
        lastRefillTime = now;
    }
}

```python
class SnapshotNode:
    def __init__(self, node_id, channels):
        self.node_id = node_id
        self.channels = channels
        self.local_state = {}
        self.recorded_channels = {}
        self.snapshot_in_progress = False
        
    def initiate_snapshot(self):
        self.snapshot_in_progress = True
        self.local_state = self.get_current_state()
        
        for channel in self.channels:
            self.recorded_channels[channel] = []
            # 发送标记消息
            self.send_marker(channel)
    
    def receive_marker(self, from_channel):
        if not self.snapshot_in_progress:
            self.initiate_snapshot()
            
        # 标记该通道已记录
        self.recorded_channels[from_channel] = []
        # 检查是否所有通道都已记录
        if len(self.recorded_channels) == len(self.channels):
            self.snapshot_in_progress = False
            self.save_snapshot()
    
    def receive_message(self, from_channel, message):
        if self.snapshot_in_progress:
            # 快照进行中，记录消息
            self.recorded_channels[from_channel].append(message)
        
        # 正常处理消息
        self.process_message(message)
```

### 26. 答案：
**向量时钟实现**：
```python
class VectorClock:
    def __init__(self, node_id, num_nodes):
        self.node_id = node_id
        self.clock = [0] * num_nodes
    
    def increment(self):
        self.clock[self.node_id] += 1
    
    def merge(self, other_clock):
        for i in range(len(self.clock)):
            self.clock[i] = max(self.clock[i], other_clock[i])
    
    def happens_before(self, other):
        dominated = False
        for i in range(len(self.clock)):
            if self.clock[i] > other.clock[i]:
                return False
            if self.clock[i] < other.clock[i]:
                dominated = True
        return dominated
    
    def is_concurrent(self, other):
        return not self.happens_before(other) and not other.happens_before(self)
```
