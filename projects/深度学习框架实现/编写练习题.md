## 练习题

### 第一部分：基础组件（张量与计算图）

#### 练习 1.1：实现一个张量（Tensor）类
**描述**：张量是深度学习框架中最基本的数据结构，代表一个任意维数的数组。请实现一个基础的 `Tensor` 类。
**具体要求**：
1.  属性应包含：`data`（存储实际数据，可以是列表或NumPy数组）、`shape`（张量的形状，如 `(3, 4)`）、`requires_grad`（布尔值，指示是否需要计算梯度）。
2.  实现以下基本方法：
    *   `__init__(self, data, requires_grad=False)`: 初始化。
    *   `__repr__(self)`: 返回友好的字符串表示（如 `Tensor(shape=(3,4), requires_grad=False)`）。
    *   `__len__(self)`: 返回第0维的长度。
3.  **（挑战）** 使用Python的 `property` 装饰器，确保在 `data` 被赋值时，`shape` 属性能自动更新。

**提示**：可以利用 `numpy.ndarray` 来处理底层数据和形状计算。

#### 练习 1.2：实现自动微分（Autograd）机制（前向传播）
**描述**：自动微分是框架的灵魂。让我们先构建计算图，用于记录前向计算过程。
**具体要求**：
1.  扩展 `Tensor` 类，增加 `grad_fn` 属性，它是一个指向“创建此张量的操作”（一个函数对象）的引用。
2.  定义一个 `Function` 基类，它需要实现：
    *   `__init__(self, *tensors)`: 存储输入张量。
    *   `forward(self)`: **抽象方法**，子类必须实现。返回一个包含计算结果的 **新 Tensor**。
    *   `backward(self, grad_output)`: **抽象方法**，子类必须实现。根据上游传回的梯度 `grad_output`，计算关于每个输入张量的梯度。
3.  创建你的第一个操作：`Add` 类（继承自 `Function`），实现两个张量的加法。
    *   `forward`: 计算 `self.input1.data + self.input2.data`，并将新 Tensor 的 `grad_fn` 指向当前 `Add` 实例。
    *   `backward`: 对于加法，梯度会原封不动地传递给两个输入。将 `grad_output` 分别赋值给两个输入张量的 `.grad` 属性（假设输入张量已初始化 `.grad` 为零张量）。

**测试**：创建两个 `requires_grad=True` 的 Tensor `a` 和 `b`，计算 `c = Add()(a, b)`。验证 `c.grad_fn` 是 `Add` 实例。

#### 练习 1.3：实现自动微分（反向传播）
**描述**：实现反向传播（`backward`）方法，这是框架的核心。
**具体要求**：
1.  在 `Tensor` 类中实现 `backward(self, gradient=None)` 方法。
    *   如果 `self` 不是计算图的叶子节点（即它是由某个操作生成的），则调用其 `grad_fn.backward(gradient)`。
    *   如果是叶子节点（用户创建的），则将其 `gradient` 累加到它的 `.grad` 属性中。
    *   需要实现一个**拓扑排序**算法，确保按照从输出到输入的正确顺序调用 `backward`。可以使用栈或队列实现（例如，递归或迭代地遍历计算图）。
2.  为 `Add` 操作的 `backward` 方法写一个完整的、能处理梯度累加的版本。

**测试**：
```python
a = Tensor([2.0, 3.0], requires_grad=True)
b = Tensor([4.0, 5.0], requires_grad=True)
c = Add()(a, b) # c.data = [6.0, 8.0]
loss = c.sum() # 假设实现了一个Sum操作
loss.backward()
print(a.grad) # 应输出 [1.0, 1.0]
print(b.grad) # 应输出 [1.0, 1.0]
```
（你需要自行实现一个简单的 `Sum` 操作或使用一个标量输出）

### 第二部分：神经网络层与优化器

#### 练习 2.1：实现基本层（Layer）抽象和线性层（Linear）
**描述**：神经网络由层构成。创建一个层的抽象接口，并实现最基本的线性层（全连接层）。
**具体要求**：
1.  定义一个 `Module` 基类，作为所有网络组件的父类。它应包含：
    *   `parameters()`: 返回一个列表，包含该模块（及其子模块）中所有需要学习的 `Tensor` 参数。
    *   `zero_grad()`: 将所有参数的梯度重置为零。
    *   `__call__(self, *args, **kwargs)`: 使得模块实例可以像函数一样被调用，并自动调用 `forward` 方法。
2.  实现 `Linear` 层（继承自 `Module`）：
    *   `__init__(self, in_features, out_features)`: 初始化权重 `W` 和偏置 `b`。权重使用随机初始化（例如，从标准正态分布采样），偏置初始化为零。确保它们都是 `requires_grad=True` 的 `Tensor`。
    *   `forward(self, x)`: 计算 `y = x @ W.T + b`。你需要先实现矩阵乘法 (`MatMul`) 和广播加法 (`BroadcastAdd`) 操作，或者直接在张量类中实现 `__matmul__` 和 `__add__` 的魔术方法，并使其支持自动微分。
    *   `parameters()`: 返回 `[self.W, self.b]`。

#### 练习 2.2：实现激活函数（ReLU， Sigmoid）
**描述**：为你的框架添加非线性激活函数。
**具体要求**：
1.  实现 `ReLU` 类（继承自 `Function` 或作为 `Module` 的一部分）。
    *   `forward`: 对输入张量的每个元素，如果大于0则输出原值，否则输出0。
    *   `backward`: 梯度是上游梯度乘以一个掩码（输入 `>0` 的位置为1，否则为0）。
2.  实现 `Sigmoid` 类。
    *   `forward`: 计算 `σ(x) = 1 / (1 + exp(-x))`。
    *   `backward`: 梯度是上游梯度乘以 `σ(x) * (1 - σ(x))`。
**注意**：需要将 `forward` 的结果封装成一个新的 `Tensor`，并设置其 `grad_fn`。

#### 练习 2.3：实现损失函数（MSE Loss）
**描述**：实现一个常用的均方误差损失函数。
**具体要求**：
1.  实现 `MSELoss` 类（继承自 `Function`）。
    *   `forward(self, predictions, targets)`: 计算 `(predictions - targets).pow(2).mean()`。你需要实现 `pow`（幂）操作。
    *   `backward(self, grad_output)`: 计算关于 `predictions` 的梯度，即 `2 * (predictions - targets) / n`，其中 `n` 是元素总数。
2.  **（附加）** 使损失函数返回一个标量 `Tensor`（0维张量），这是反向传播的起点。

#### 练习 2.4：实现简单的优化器（SGD）
**描述**：优化器根据梯度更新网络参数。
**具体要求**：
1.  定义 `Optimizer` 基类。
    *   `__init__(self, parameters, lr)`: 存储参数列表和学习率。
    *   `step()`: **抽象方法**，执行一步参数更新。
    *   `zero_grad()`: 调用每个参数的 `zero_grad()` 方法。
2.  实现 `SGD`（随机梯度下降）优化器。
    *   `step()`: 对于每一个参数 `param`，执行 `param.data = param.data - lr * param.grad`。

### 第三部分：整合与完整训练循环

#### 练习 3.1：构建一个完整的神经网络模型
**描述**：使用之前实现的组件，构建一个多层感知机（MLP）。
**具体要求**：
1.  创建一个 `MLP` 类，继承自 `Module`。
2.  在其 `__init__` 中，实例化两个 `Linear` 层和一个 `ReLU` 激活层。
    *   例如：`self.linear1 = Linear(2, 10)`, `self.relu = ReLU()`, `self.linear2 = Linear(10, 1)`。
3.  实现 `forward(self, x)` 方法：将输入依次通过这些层。
4.  实现 `parameters()` 方法，收集所有子层的参数。

#### 练习 3.2：编写完整的训练循环
**描述**：将所有组件串联起来，训练一个简单的模型来拟合数据。
**具体要求**：
1.  **生成数据**：创建一个简单的数据集，例如学习 `y = 2*x1 + 3*x2` 的线性关系。生成100个样本的输入（2个特征）和输出。
2.  **初始化**：实例化你的 `MLP` 模型、`MSELoss` 损失函数和 `SGD` 优化器。
3.  **训练循环**：编写一个循环，重复以下步骤（例如1000次）：
    *   前向传播：用模型计算预测值。
    *   计算损失。
    *   清零梯度（`optimizer.zero_grad()`）。
    *   反向传播（`loss.backward()`）。
    *   更新参数（`optimizer.step()`）。
    *   每隔一定次数打印当前损失。
4.  **验证**：训练结束后，用一些测试数据验证模型的预测是否接近真实值。

#### 练习 3.3：（高级挑战）实现卷积层（Conv2d）
**描述**：为你的框架添加最重要的视觉层之一。
**具体要求**：
1.  实现一个支持2D卷积的 `Conv2d` 层。
2.  参数：`in_channels`, `out_channels`, `kernel_size`, `stride`, `padding`。
3.  实现 `forward`：对输入特征图（形状 `[batch, in_channels, height, width]`）应用卷积核（形状 `[out_channels, in_channels, kernel_h, kernel_w]`）。
4.  **关键挑战**：实现对应的 `backward` 方法，即计算卷积的梯度。这通常需要实现**转置卷积**（或称为反卷积）的计算逻辑来传递梯度。
**提示**：这是最复杂的部分，可以从一个非常简单的（无填充、步长为1的）版本开始。
