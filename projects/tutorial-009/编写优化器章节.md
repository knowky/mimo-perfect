## 1. 引言：优化器在深度学习中的作用 <a name="1-引言"></a>

优化器是深度学习训练过程中的核心组件，负责根据损失函数的梯度更新模型参数。其目标是通过迭代优化，最小化损失函数，使模型能够从数据中学习有效的特征表示。

### 1.1 优化的基本框架

```
θ_{t+1} = θ_t - η * ∇J(θ_t)
```

其中：
- θ_t：时刻 t 的参数
- η：学习率
- ∇J(θ_t)：损失函数关于参数的梯度

### 1.2 优化器需要考虑的关键问题
- **收敛速度**：如何快速达到最优解
- **泛化能力**：避免过拟合，保证在测试集上的表现
- **稳定性**：防止训练过程中的数值不稳定
- **内存效率**：优化器状态的内存开销

## 2. 基础：随机梯度下降及其变体 <a name="2-基础"></a>

### 2.1 批量梯度下降 (BGD)

```python
def batch_gradient_descent(params, gradients, lr):
    """
    批量梯度下降
    使用全部训练数据的梯度更新参数
    """
    for param, grad in zip(params, gradients):
        param.data -= lr * grad
```

**优点**：收敛方向稳定
**缺点**：计算开销大，内存需求高

### 2.2 随机梯度下降 (SGD)

```python
def stochastic_gradient_descent(params, gradients, lr):
    """
    随机梯度下降
    使用单个样本的梯度更新参数
    """
    for param, grad in zip(params, gradients):
        param.data -= lr * grad
```

**优点**：计算效率高，能跳出局部最优
**缺点**：收敛过程不稳定，可能震荡

### 2.3 小批量梯度下降 (Mini-batch SGD)

实际应用中最常用的变体，平衡了BGD和SGD的优缺点：

```python
class MiniBatchSGD:
    def __init__(self, params, lr=0.01, batch_size=32):
        self.params = params
        self.lr = lr
        self.batch_size = batch_size
    
    def step(self, gradients):
        for param, grad in zip(self.params, gradients):
            param.data -= self.lr * grad
```

### 2.4 动量SGD (Momentum SGD)

引入动量项，加速收敛并减少震荡：

```
v_t = μ * v_{t-1} + η * ∇J(θ_t)
θ_{t+1} = θ_t - v_t
```

```python
class MomentumSGD:
    def __init__(self, params, lr=0.01, momentum=0.9):
        self.params = params
        self.lr = lr
        self.momentum = momentum
        self.velocities = [np.zeros_like(p.data) for p in params]
    
    def step(self, gradients):
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 更新动量
            self.velocities[i] = (self.momentum * self.velocities[i] + 
                                 self.lr * grad)
            # 更新参数
            param.data -= self.velocities[i]
```

### 2.5 Nesterov动量SGD

预判梯度方向，提前修正：

```
v_t = μ * v_{t-1} + η * ∇J(θ_t - μ * v_{t-1})
θ_{t+1} = θ_t - v_t
```

```python
class NesterovSGD:
    def __init__(self, params, lr=0.01, momentum=0.9):
        self.params = params
        self.lr = lr
        self.momentum = momentum
        self.velocities = [np.zeros_like(p.data) for p in params]
    
    def step(self, gradients):
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 保存当前速度
            v_prev = self.velocities[i].copy()
            # 更新动量
            self.velocities[i] = (self.momentum * self.velocities[i] + 
                                 self.lr * grad)
            # Nesterov更新：使用预测位置的梯度
            param.data += (-self.momentum * v_prev + 
                          (1 + self.momentum) * self.velocities[i])
```

## 3. 进阶：自适应学习率优化器 <a name="3-进阶"></a>

### 3.1 AdaGrad

自适应调整每个参数的学习率，稀疏特征上表现良好：

```
G_t = G_{t-1} + (∇J(θ_t))^2
θ_{t+1} = θ_t - (η / √(G_t + ε)) * ∇J(θ_t)
```

```python
class AdaGrad:
    def __init__(self, params, lr=0.01, epsilon=1e-8):
        self.params = params
        self.lr = lr
        self.epsilon = epsilon
        self.accumulators = [np.zeros_like(p.data) for p in params]
    
    def step(self, gradients):
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 累积梯度平方
            self.accumulators[i] += grad ** 2
            # 自适应学习率更新
            adjusted_lr = self.lr / (np.sqrt(self.accumulators[i]) + self.epsilon)
            param.data -= adjusted_lr * grad
```

**缺点**：学习率单调递减，后期可能停止学习

### 3.2 RMSProp

解决AdaGrad学习率衰减问题，使用指数移动平均：

```
E[g^2]_t = γ * E[g^2]_{t-1} + (1 - γ) * (∇J(θ_t))^2
θ_{t+1} = θ_t - (η / √(E[g^2]_t + ε)) * ∇J(θ_t)
```

```python
class RMSProp:
    def __init__(self, params, lr=0.001, rho=0.9, epsilon=1e-8):
        self.params = params
        self.lr = lr
        self.rho = rho
        self.epsilon = epsilon
        self.square_avgs = [np.zeros_like(p.data) for p in params]
    
    def step(self, gradients):
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 更新梯度平方的指数移动平均
            self.square_avgs[i] = (self.rho * self.square_avgs[i] + 
                                  (1 - self.rho) * (grad ** 2))
            # 自适应学习率更新
            adjusted_lr = self.lr / (np.sqrt(self.square_avgs[i]) + self.epsilon)
            param.data -= adjusted_lr * grad
```

### 3.3 Adam (Adaptive Moment Estimation)

结合动量和自适应学习率，当前最流行的优化器之一：

```
m_t = β1 * m_{t-1} + (1 - β1) * ∇J(θ_t)  # 一阶矩估计（动量）
v_t = β2 * v_{t-1} + (1 - β2) * (∇J(θ_t))^2  # 二阶矩估计（自适应学习率）
m̂_t = m_t / (1 - β1^t)  # 偏差校正
v̂_t = v_t / (1 - β2^t)  # 偏差校正
θ_{t+1} = θ_t - (η / (√v̂_t + ε)) * m̂_t
```

```python
class Adam:
    def __init__(self, params, lr=0.001, betas=(0.9, 0.999), epsilon=1e-8):
        self.params = params
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.epsilon = epsilon
        self.t = 0
        self.ms = [np.zeros_like(p.data) for p in params]  # 一阶矩
        self.vs = [np.zeros_like(p.data) for p in params]  # 二阶矩
    
    def step(self, gradients):
        self.t += 1
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 更新有偏一阶矩估计
            self.ms[i] = self.beta1 * self.ms[i] + (1 - self.beta1) * grad
            # 更新有偏二阶矩估计
            self.vs[i] = self.beta2 * self.vs[i] + (1 - self.beta2) * (grad ** 2)
            
            # 偏差校正的一阶矩估计
            m_corrected = self.ms[i] / (1 - self.beta1 ** self.t)
            # 偏差校正的二阶矩估计
            v_corrected = self.vs[i] / (1 - self.beta2 ** self.t)
            
            # 参数更新
            param.data -= self.lr * m_corrected / (np.sqrt(v_corrected) + self.epsilon)
```

### 3.4 AdamW (Adam with Weight Decay)

解耦权重衰减，提高泛化性能：

```
θ_{t+1} = θ_t - η * [m̂_t / (√v̂_t + ε) + λ * θ_t]
```

```python
class AdamW:
    def __init__(self, params, lr=0.001, betas=(0.9, 0.999), 
                 epsilon=1e-8, weight_decay=0.01):
        self.params = params
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.epsilon = epsilon
        self.weight_decay = weight_decay
        self.t = 0
        self.ms = [np.zeros_like(p.data) for p in params]
        self.vs = [np.zeros_like(p.data) for p in params]
    
    def step(self, gradients):
        self.t += 1
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 权重衰减（解耦）
            param.data *= (1 - self.lr * self.weight_decay)
            
            # 更新矩估计
            self.ms[i] = self.beta1 * self.ms[i] + (1 - self.beta1) * grad
            self.vs[i] = self.beta2 * self.vs[i] + (1 - self.beta2) * (grad ** 2)
            
            # 偏差校正
            m_corrected = self.ms[i] / (1 - self.beta1 ** self.t)
            v_corrected = self.vs[i] / (1 - self.beta2 ** self.t)
            
            # 参数更新
            param.data -= self.lr * m_corrected / (np.sqrt(v_corrected) + self.epsilon)
```

### 3.5 Adamax

Adam的无穷范数变体，对梯度有界的情况更稳定：

```
u_t = max(β2 * u_{t-1}, |∇J(θ_t)|)
θ_{t+1} = θ_t - (η / ((1 - β1^t) * (u_t + ε))) * m̂_t
```

```python
class Adamax:
    def __init__(self, params, lr=0.002, betas=(0.9, 0.999), epsilon=1e-8):
        self.params = params
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.epsilon = epsilon
        self.t = 0
        self.ms = [np.zeros_like(p.data) for p in params]
        self.us = [np.zeros_like(p.data) for p in params]  # 无穷范数
    
    def step(self, gradients):
        self.t += 1
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 更新一阶矩
            self.ms[i] = self.beta1 * self.ms[i] + (1 - self.beta1) * grad
            
            # 更新无穷范数
            self.us[i] = np.maximum(self.beta2 * self.us[i], np.abs(grad))
            
            # 偏差校正的一阶矩
            m_corrected = self.ms[i] / (1 - self.beta1 ** self.t)
            
            # 参数更新
            param.data -= self.lr * m_corrected / (self.us[i] + self.epsilon)
```

## 4. 实践：优化器代码实现 <a name="4-实践"></a>

### 4.1 完整的优化器框架实现

```python
import numpy as np
from abc import ABC, abstractmethod

class Optimizer(ABC):
    """优化器基类"""
    
    def __init__(self, params, lr=0.01):
        self.params = params
        self.lr = lr
    
    @abstractmethod
    def step(self, gradients):
        """执行一步参数更新"""
        pass
    
    def zero_grad(self):
        """将所有参数的梯度清零"""
        for param in self.params:
            if hasattr(param, 'grad'):
                param.grad = np.zeros_like(param.grad)


class SGD(Optimizer):
    """带动量的随机梯度下降"""
    
    def __init__(self, params, lr=0.01, momentum=0.0, weight_decay=0.0):
        super().__init__(params, lr)
        self.momentum = momentum
        self.weight_decay = weight_decay
        self.velocities = [np.zeros_like(p.data) for p in params]
    
    def step(self, gradients):
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 权重衰减
            if self.weight_decay != 0:
                grad = grad + self.weight_decay * param.data
            
            # 更新动量
            self.velocities[i] = self.momentum * self.velocities[i] + grad
            
            # 参数更新
            param.data -= self.lr * self.velocities[i]


class Adam(Optimizer):
    """Adam优化器"""
    
    def __init__(self, params, lr=0.001, betas=(0.9, 0.999), 
                 epsilon=1e-8, weight_decay=0.0):
        super().__init__(params, lr)
        self.beta1, self.beta2 = betas
        self.epsilon = epsilon
        self.weight_decay = weight_decay
        self.t = 0
        self.ms = [np.zeros_like(p.data) for p in params]
        self.vs = [np.zeros_like(p.data) for p in params]
    
    def step(self, gradients):
        self.t += 1
        for i, (param, grad) in enumerate(zip(self.params, gradients)):
            # 权重衰减
            if self.weight_decay != 0:
                grad = grad + self.weight_decay * param.data
            
            # 更新矩估计
            self.ms[i] = self.beta1 * self.ms[i] + (1 - self.beta1) * grad
            self.vs[i] = self.beta2 * self.vs[i] + (1 - self.beta2) * (grad ** 2)
            
            # 偏差校正
            m_corrected = self.ms[i] / (1 - self.beta1 ** self.t)
            v_corrected = self.vs[i] / (1 - self.beta2 ** self.t)
            
            # 参数更新
            param.data -= self.lr * m_corrected / (np.sqrt(v_corrected) + self.epsilon)
```

### 4.2 学习率调度器

```python
class LRScheduler:
    """学习率调度器基类"""
    
    def __init__(self, optimizer):
        self.optimizer = optimizer
        self.base_lr = optimizer.lr
    
    def step(self):
        """更新学习率"""
        pass


class StepLR(LRScheduler):
    """阶梯式学习率衰减"""
    
    def __init__(self, optimizer, step_size=30, gamma=0.1):
        super().__init__(optimizer)
        self.step_size = step_size
        self.gamma = gamma
        self.last_epoch = 0
    
    def step(self):
        self.last_epoch += 1
        if self.last_epoch % self.step_size == 0:
            self.optimizer.lr *= self.gamma


class CosineAnnealingLR(LRScheduler):
    """余弦退火学习率调度"""
    
    def __init__(self, optimizer, T_max, eta_min=0):
        super().__init__(optimizer)
        self.T_max = T_max
        self.eta_min = eta_min
        self.last_epoch = 0
    
    def step(self):
        self.last_epoch += 1
        self.optimizer.lr = (self.eta_min + 0.5 * (self.base_lr - self.eta_min) * 
                            (1 + np.cos(np.pi * self.last_epoch / self.T_max)))
```

### 4.3 梯度裁剪实现

```python
def clip_grad_norm(params, max_norm=1.0):
    """
    梯度范数裁剪
    防止梯度爆炸
    """
    total_norm = 0
    for param in params:
        if param.grad is not None:
            param_norm = np.linalg.norm(param.grad)
            total_norm += param_norm ** 2
    
    total_norm = np.sqrt(total_norm)
    clip_coef = max_norm / (total_norm + 1e-6)
    
    if clip_coef < 1:
        for param in params:
            if param.grad is not None:
                param.grad *= clip_coef
```

## 5. 总结与对比 <a name="5-总结"></a>

### 5.1 优化器特性对比

| 优化器 | 自适应学习率 | 动量 | 内存开销 | 适用场景 |
|--------|--------------|------|----------|----------|
| SGD | ✗ | 可选 | 低 | 简单问题，需要精细调参 |
| Momentum SGD | ✗ | ✓ | 低 | 一般问题，比SGD收敛更快 |
| AdaGrad | ✓ | ✗ | 中 | 稀疏数据，NLP任务 |
| RMSProp | ✓ | ✗ | 中 | 非平稳目标，RNN训练 |
| Adam | ✓ | ✓ | 中 | 大多数深度学习任务 |
| AdamW | ✓ | ✓ | 中 | 需要权重正则化的任务 |

### 5.2 超参数选择建议

1. **学习率**：
   - SGD: 0.01 - 0.1
   - Adam: 0.001（默认值）
   - 建议使用学习率查找器确定初始学习率

2. **动量**：
   - 一般设为0.9
   - 对于噪声较大的梯度，可适当降低

3. **Adam的β参数**：
   - β1 = 0.9（一阶矩衰减率）
   - β2 = 0.999（二阶矩衰减率）
   - 对于稀疏梯度，可降低β2至0.99

### 5.3 最佳实践

1. **默认选择**：从Adam开始，因为它通常对超参数不敏感
2. **精细调优**：对于最终性能要求高的任务，使用带动量的SGD
3. **正则化**：结合权重衰减（L2正则化）或Dropout
4. **学习率调度**：使用余弦退火或阶梯衰减
5. **梯度监控**：定期检查梯度范数，防止梯度爆炸/消失

### 5.4 高级主题

#### 5.4.1 梯度累积
对于大批量训练，内存受限时可使用梯度累积：

```python
class GradientAccumulator:
    def __init__(self, optimizer, accumulation_steps=4):
        self.optimizer = optimizer
        self.accumulation_steps = accumulation_steps
        self.accumulated_gradients = [np.zeros_like(p.data) for p in optimizer.params]
        self.step_count = 0
    
    def accumulate(self, gradients):
        for i, grad in enumerate(gradients):
            self.accumulated_gradients[i] += grad
        self.step_count += 1
        
        if self.step_count % self.accumulation_steps == 0:
            # 取平均并更新
            averaged_grads = [g / self.accumulation_steps 
                             for g in self.accumulated_gradients]
            self.optimizer.step(averaged_grads)
            self.reset()
    
    def reset(self):
        self.accumulated_gradients = [np.zeros_like(g) 
                                     for g in self.accumulated_gradients]
        self.step_count = 0
```
