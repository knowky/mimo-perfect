# 自动微分章节

## 1. 自动微分概述

自动微分（Automatic Differentiation，AD）是深度学习框架的核心组件，它能够高效、精确地计算函数的导数。与数值微分和符号微分不同，自动微分结合了二者的优点：

- **数值微分**：近似计算，但存在截断误差和舍入误差
- **符号微分**：精确计算，但可能产生表达式膨胀
- **自动微分**：精确计算，计算复杂度与原函数相同

## 2. 自动微分的数学基础

### 2.1 链式法则
对于复合函数 $y = f(g(x))$，其导数为：
$$
\frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dx}
$$

### 2.2 计算图表示
将计算过程表示为有向无环图（DAG）：
- 节点：表示变量或操作
- 边：表示数据流方向
- 叶子节点：输入变量
- 输出节点：最终结果

## 3. 自动微分的两种模式

### 3.1 前向模式（Forward Mode）

**原理**：从输入向输出传播导数

**实现**：对每个变量携带导数值（称为tangent vector）

**数学表示**：
- 对于变量 $v_i$，同时计算 $v_i$ 和 $\dot{v}_i = \frac{\partial v_i}{\partial x}$
- 初始条件：$\dot{x} = 1$（对自变量）

**计算复杂度**：$O(n)$ 其中 $n$ 是输入维度

### 3.2 反向模式（Reverse Mode）

**原理**：从输出向输入传播梯度

**实现**：先正向计算所有变量，再反向传播梯度

**数学表示**：
- 定义伴随变量 $\bar{v}_i = \frac{\partial y}{\partial v_i}$
- 初始条件：$\bar{y} = 1$（对输出）

**计算复杂度**：$O(m)$ 其中 $m$ 是输出维度

### 3.3 模式选择
- 前向模式：适合输入维度少、输出维度多的情况
- 反向模式：适合输入维度多、输出维度少的情况（深度学习中的典型情况）

### 4.2 基本运算实现

```python
class Value:
    def __init__(self, data, _children=(), _op=''):
        self.data = data
        self.grad = 0.0
        self._backward = lambda: None
        self._prev = set(_children)
        self._op = _op
        
    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), '+')
        
        def _backward():
            self.grad += out.grad
            other.grad += out.grad
        out._backward = _backward
        
        return out
    
    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), '*')
        
        def _backward():
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = _backward
        
        return out
    
    def __pow__(self, other):
        assert isinstance(other, (int, float))
        out = Value(self.data ** other, (self,), f'**{other}')
        
        def _backward():
            self.grad += (other * self.data ** (other - 1)) * out.grad
        out._backward = _backward
        
        return out
    
    def relu(self):
        out = Value(0 if self.data < 0 else self.data, (self,), 'ReLU')
        
        def _backward():
            self.grad += (out.data > 0) * out.grad
        out._backward = _backward
        
        return out
    
    def backward(self):
        # 拓扑排序
        topo = []
        visited = set()
        
        def build_topo(v):
            if v not in visited:
                visited.add(v)
                for child in v._prev:
                    build_topo(child)
                topo.append(v)
        
        build_topo(self)
        
        # 反向传播
        self.grad = 1.0
        for node in reversed(topo):
            node._backward()
```

## 5. 反向传播算法实现

### 5.1 反向传播的数学原理

给定损失函数 $L$，对参数 $w$ 的梯度：
$$
\frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial w}
$$

### 5.2 反向传播的实现

```python
class BackwardPass:
    def __init__(self, graph):
        self.graph = graph
        self.grads = {}
        
    def compute_gradients(self, loss):
        # 初始化输出梯度
        loss.grad = 1.0
        
        # 拓扑排序
        topo_order = self._topological_sort()
        
        # 反向传播
        for node in reversed(topo_order):
            if node.grad_fn:
                grads = node.grad_fn(node.grad)
                
                # 累积梯度到子节点
                for child, grad in zip(node.children, grads):
                    child.grad += grad
    
    def _topological_sort(self):
        visited = set()
        order = []
        
        def dfs(node):
            if node not in visited:
                visited.add(node)
                for child in node.children:
                    dfs(child)
                order.append(node)
        
        dfs(self.graph.output)
        return order
```

```python
class GradientCheckpointing:
    def __init__(self, model, segments=2):
        self.model = model
        self.segments = segments
        
    def forward(self, x):
        # 将计算图分成多个段
        segments = self._split_graph()
        
        # 只保存每段的输入和输出
        saved_inputs = []
        for segment in segments:
            x = segment(x)
            saved_inputs.append(x.detach())
        
        return x
    
    def backward(self, grad_output):
        # 重新计算每段的中间结果
        for segment, saved_input in zip(reversed(self.segments), 
                                        reversed(self.saved_inputs)):
            grad_output = segment.backward(grad_output, saved_input)
```

## 7. 常见函数的梯度计算

### 7.1 基本函数梯度表

| 函数 | 表达式 | 导数 |
|------|--------|------|
| 加法 | $f(x,y) = x + y$ | $\frac{\partial f}{\partial x} = 1$, $\frac{\partial f}{\partial y} = 1$ |
| 乘法 | $f(x,y) = x \cdot y$ | $\frac{\partial f}{\partial x} = y$, $\frac{\partial f}{\partial y} = x$ |
| 指数 | $f(x) = e^x$ | $\frac{\partial f}{\partial x} = e^x$ |
| 对数 | $f(x) = \log x$ | $\frac{\partial f}{\partial x} = \frac{1}{x}$ |
| 幂 | $f(x) = x^n$ | $\frac{\partial f}{\partial x} = n \cdot x^{n-1}$ |
| Sigmoid | $f(x) = \frac{1}{1+e^{-x}}$ | $\frac{\partial f}{\partial x} = f(x)(1-f(x))$ |
| ReLU | $f(x) = \max(0, x)$ | $\frac{\partial f}{\partial x} = \begin{cases} 1 & x > 0 \\ 0 & x \leq 0 \end{cases}$ |

### 7.2 复杂函数梯度实现

```python
class GradientFunctions:
    @staticmethod
    def sigmoid_grad(grad_output, output):
        return grad_output * output * (1 - output)
    
    @staticmethod
    def softmax_grad(grad_output, output):
        # Jacobian矩阵乘法
        n = output.shape[0]
        jacobian = np.diag(output) - np.outer(output, output)
        return np.dot(grad_output, jacobian)
    
    @staticmethod
    def cross_entropy_grad(grad_output, predicted, target):
        return grad_output * (predicted - target) / predicted.shape[0]
    
    @staticmethod
    def batch_norm_grad(grad_output, input, mean, var, gamma, eps=1e-5):
        # 批量归一化的梯度计算
        n = input.shape[0]
        
        # 计算中间变量
        input_centered = input - mean
        std_inv = 1.0 / np.sqrt(var + eps)
        
        # 计算梯度
        dgamma = np.sum(grad_output * input_centered * std_inv, axis=0)
        dbeta = np.sum(grad_output, axis=0)
        
        # 计算输入的梯度
        dinput = (1.0 / n) * gamma * std_inv * (
            n * grad_output - 
            np.sum(grad_output, axis=0) - 
            input_centered * std_inv**2 * np.sum(grad_output * input_centered, axis=0)
        )
        
        return dinput, dgamma, dbeta
```

## 8. 高级自动微分技术

### 8.1 高阶导数
通过多次应用反向传播计算高阶导数：

```python
def higher_order_grads(func, inputs, order=2):
    # 计算高阶导数
    current_grads = inputs
    
    for i in range(order):
        # 创建计算图
        with GradientTape(persistent=True) as tape:
            tape.watch(current_grads)
            output = func(*current_grads)
        
        # 计算梯度
        grads = tape.gradient(output, current_grads)
        current_grads = grads
        
        # 释放资源
        del tape
    
    return current_grads
```

```python
class MixedPrecisionAD:
    def __init__(self, dtype='float32'):
        self.dtype = dtype
        
    def forward(self, *inputs):
        # 将输入转换为指定精度
        inputs = [tf.cast(x, self.dtype) for x in inputs]
        
        # 前向计算
        outputs = self._forward_pass(*inputs)
        
        return outputs
    
    def _forward_pass(self, *inputs):
        # 混合精度计算：前向用float16，反向用float32
        with tf.device('/GPU:0'):
            # 前向计算（float16）
            outputs = self._compute_forward(*inputs)
            
            # 保存高精度版本用于反向传播
            outputs_f32 = tf.cast(outputs, 'float32')
            
        return outputs_f32
```

## 9. 性能优化策略

### 9.1 梯度累积

```python
class GradientAccumulator:
    def __init__(self, optimizer, accumulation_steps=4):
        self.optimizer = optimizer
        self.accumulation_steps = accumulation_steps
        self.accumulated_grads = []
        self.current_step = 0
        
    def accumulate_gradients(self, loss):
        # 计算梯度
        gradients = tape.gradient(loss, model.trainable_variables)
        
        # 累积梯度
        if not self.accumulated_grads:
            self.accumulated_grads = gradients
        else:
            self.accumulated_grads = [
                acc_grad + grad 
                for acc_grad, grad in zip(self.accumulated_grads, gradients)
            ]
        
        self.current_step += 1
        
        # 每隔一定步数更新参数
        if self.current_step % self.accumulation_steps == 0:
            # 平均梯度
            avg_grads = [
                grad / self.accumulation_steps 
                for grad in self.accumulated_grads
            ]
            
            # 应用梯度
            self.optimizer.apply_gradients(
                zip(avg_grads, model.trainable_variables)
            )
            
            # 重置累积
            self.accumulated_grads = []
```

### 9.2 梯度裁剪

```python
def clip_gradients(gradients, max_norm=1.0):
    # 计算梯度范数
    total_norm = 0.0
    for grad in gradients:
        if grad is not None:
            total_norm += tf.reduce_sum(grad ** 2)
    total_norm = tf.sqrt(total_norm)
    
    # 裁剪梯度
    clip_coef = max_norm / (total_norm + 1e-6)
    clip_coef = tf.minimum(clip_coef, 1.0)
    
    clipped_gradients = []
    for grad in gradients:
        if grad is not None:
            clipped_gradients.append(grad * clip_coef)
        else:
            clipped_gradients.append(grad)
    
    return clipped_gradients
```

## 10. 实际应用示例

### 10.1 简单神经网络实现

```python
class SimpleNN:
    def __init__(self, input_size, hidden_size, output_size):
        # 初始化参数
        self.W1 = Value(np.random.randn(input_size, hidden_size) * 0.01)
        self.b1 = Value(np.zeros(hidden_size))
        self.W2 = Value(np.random.randn(hidden_size, output_size) * 0.01)
        self.b2 = Value(np.zeros(output_size))
    
    def forward(self, x):
        # 前向传播
        h = x @ self.W1 + self.b1
        h = h.relu()
        out = h @ self.W2 + self.b2
        return out
    
    def loss(self, x, y):
        # 计算损失
        pred = self.forward(x)
        return ((pred - y) ** 2).mean()
    
    def train(self, x, y, lr=0.01):
        # 前向传播
        loss = self.loss(x, y)
        
        # 反向传播
        loss.backward()
        
        # 更新参数
        self.W1.data -= lr * self.W1.grad
        self.b1.data -= lr * self.b1.grad
        self.W2.data -= lr * self.W2.grad
        self.b2.data -= lr * self.b2.grad
        
        # 梯度清零
        self.W1.grad = 0.0
        self.b1.grad = 0.0
        self.W2.grad = 0.0
        self.b2.grad = 0.0
        
        return loss.data
```

### 10.2 卷积层自动微分实现

```python
class Convolution:
    def __init__(self, in_channels, out_channels, kernel_size):
        self.weight = Value(np.random.randn(out_channels, in_channels, 
                                          kernel_size, kernel_size) * 0.01)
        self.bias = Value(np.zeros(out_channels))
        self.kernel_size = kernel_size
        
    def forward(self, x):
        # 简化的卷积实现
        batch_size, in_channels, height, width = x.shape
        out_height = height - self.kernel_size + 1
        out_width = width - self.kernel_size + 1
        
        output = Value(np.zeros((batch_size, self.weight.shape[0], 
                                out_height, out_width)))
        
        # 实际的卷积计算（简化版）
        for b in range(batch_size):
            for f in range(self.weight.shape[0]):
                for i in range(out_height):
                    for j in range(out_width):
                        # 提取输入 patch
                        patch = x[b, :, i:i+self.kernel_size, 
                                 j:j+self.kernel_size]
                        
                        # 计算卷积
                        conv = (patch * self.weight[f]).sum() + self.bias[f]
                        output.data[b, f, i, j] = conv.data
        
        # 设置反向传播函数
        def backward(grad_output):
            # 计算权重梯度
            grad_weight = np.zeros_like(self.weight.data)
            grad_bias = np.zeros_like(self.bias.data)
            
            for b in range(batch_size):
                for f in range(self.weight.shape[0]):
                    for i in range(out_height):
                        for j in range(out_width):
                            patch = x[b, :, i:i+self.kernel_size, 
                                     j:j+self.kernel_size]
                            
                            grad_weight[f] += grad_output[b, f, i, j] * patch
                            grad_bias[f] += grad_output[b, f, i, j]
            
            return grad_weight, grad_bias
        
        output._backward = backward
        return output
```

## 11. 调试与验证

### 11.1 梯度检验

```python
def gradient_check(func, x, eps=1e-5):
    # 解析梯度
    with GradientTape() as tape:
        tape.watch(x)
        y = func(x)
    
    analytic_grad = tape.gradient(y, x)
    
    # 数值梯度
    numerical_grad = np.zeros_like(x)
    
    for i in range(x.shape[0]):
        # 前向扰动
        x_plus = x.numpy().copy()
        x_plus[i] += eps
        y_plus = func(x_plus)
        
        # 后向扰动
        x_minus = x.numpy().copy()
        x_minus[i] -= eps
        y_minus = func(x_minus)
        
        # 数值梯度
        numerical_grad[i] = (y_plus - y_minus) / (2 * eps)
    
    # 计算相对误差
    relative_error = np.abs(analytic_grad - numerical_grad) / (
        np.abs(analytic_grad) + np.abs(numerical_grad) + 1e-8
    )
    
    return np.max(relative_error) < 1e-5
```
