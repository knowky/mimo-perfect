## 1. 概述

### 1.1 平台简介
任务调度平台（TaskScheduler）是一个分布式任务调度系统，旨在提供可靠、高效、可扩展的任务调度解决方案。平台支持多种任务类型，包括但不限于：
- 定时任务（Cron表达式）
- 一次性任务
- 依赖任务（DAG工作流）
- 延迟任务

### 1.2 主要特性
- **高可用性**：基于主从架构，支持故障自动转移
- **水平扩展**：支持动态增减Worker节点
- **任务监控**：实时监控任务状态和性能指标
- **失败重试**：支持自动重试和手动重试机制
- **任务依赖**：支持复杂的任务依赖关系（DAG）
- **多语言支持**：提供Java、Python、Go等SDK
- **Web管理界面**：直观的任务管理和监控面板

### 1.3 适用场景
- 批处理作业调度
- 数据处理流水线
- 业务流程自动化
- 系统维护任务
- 消息队列消费者调度

### 1.4 技术栈
- **调度器**：Quartz Scheduler
- **消息中间件**：Apache Kafka / RabbitMQ
- **数据存储**：MySQL / PostgreSQL + Redis
- **服务注册**：Zookeeper / etcd
- **监控**：Prometheus + Grafana
- **容器化**：Docker + Kubernetes

### 2.2 核心组件

#### 2.2.1 调度器（Scheduler）
- 负责解析任务调度配置，生成触发器
- 维护任务调度状态，触发任务执行
- 管理任务依赖关系，执行DAG调度
- 提供故障转移和负载均衡机制

#### 2.2.2 Worker节点
- 接收并执行具体任务
- 向调度器报告任务执行状态
- 支持动态扩缩容
- 提供任务执行环境隔离

#### 2.2.3 任务存储服务
- 持久化任务定义和配置
- 记录任务执行历史和日志
- 提供任务查询和统计接口

#### 2.2.4 消息队列
- 解耦调度器和Worker节点
- 实现异步任务分发
- 支持任务优先级和重试队列
- 保证消息可靠传递

#### 2.2.5 Web管理界面
- 任务创建、编辑、删除
- 实时监控任务执行状态
- 系统配置和参数调整
- 用户权限管理

### 2.3 数据流

1. **任务提交**：用户通过API或Web界面创建任务
2. **任务存储**：任务定义持久化到数据库
3. **调度触发**：调度器根据触发器生成执行计划
4. **任务分发**：调度器将任务信息发送到消息队列
5. **任务执行**：Worker从队列获取任务并执行
6. **状态更新**：Worker将执行结果上报给调度器
7. **结果存储**：执行结果持久化到数据库
8. **监控展示**：Web界面展示实时状态和统计信息

## 3. 安装与部署

- **调度器服务器**：2核CPU，4GB内存，50GB磁盘
- **Worker节点**：4核CPU，8GB内存，100GB磁盘（可根据任务资源需求调整）

- **操作系统**：CentOS 7.x+ / Ubuntu 18.04+

- **消息中间件**：RabbitMQ 3.8+ / Kafka 2.8+
- **容器运行时**：Docker 19.03+（可选）

## 5. 核心概念

### 5.1 任务（Task）
任务是调度平台的基本单元，代表一个可执行的工作单元。任务包含以下属性：
- **任务ID**：唯一标识符
- **任务名称**：任务描述性名称
- **任务类型**：SHELL、JAVA、PYTHON、HTTP等
- **任务内容**：具体的执行脚本或代码
- **调度配置**：执行时间、频率、触发条件
- **执行参数**：环境变量、输入参数
- **资源需求**：CPU、内存、磁盘需求
- **超时设置**：最大执行时间
- **重试策略**：失败后的重试配置

### 5.2 触发器（Trigger）
触发器定义任务的执行时机，支持以下类型：

#### 5.2.1 Cron触发器
使用Cron表达式定义周期性执行：
```json
{
  "type": "CRON",
  "expression": "0 0/15 9-17 * * ?",  // 工作日9:00-17:00每15分钟执行
  "timezone": "Asia/Shanghai"
}
```

#### 5.2.2 固定间隔触发器
```json
{
  "type": "FIXED_RATE",
  "interval": 60000,  // 每60秒执行一次
  "initialDelay": 0
}
```

#### 5.2.3 一次性触发器
```json
{
  "type": "ONCE",
  "scheduledTime": "2024-01-01T00:00:00Z"
}
```

#### 5.2.4 事件触发器
```json
{
  "type": "EVENT",
  "eventType": "DATA_ARRIVAL",
  "eventSource": "kafka://topic1",
  "filter": "payload.size > 1000"
}
```

### 5.3 工作流（Workflow/DAG）
工作流是一组相互依赖的任务集合，以有向无环图（DAG）形式组织：
```json
{
  "workflowId": "data-pipeline",
  "name": "数据处理流水线",
  "tasks": [
    {
      "taskId": "extract",
      "name": "数据抽取",
      "dependencies": []
    },
    {
      "taskId": "transform",
      "name": "数据转换",
      "dependencies": ["extract"]
    },
    {
      "taskId": "load",
      "name": "数据加载",
      "dependencies": ["transform"]
    }
  ]
}
```

### 5.4 任务实例（TaskInstance）
任务实例是任务的具体执行记录，每次执行生成一个新的实例，包含：
- **实例ID**：唯一执行标识
- **执行状态**：RUNNING、SUCCESS、FAILED、TIMEOUT等
- **开始时间**、**结束时间**
- **执行日志**和**执行结果**
- **重试次数**和**失败原因**

### 5.5 Worker节点
Worker是实际执行任务的计算节点，具有以下特性：
- **节点标识**：唯一ID和分组
- **资源能力**：CPU、内存、磁盘等
- **执行能力**：支持的任务类型
- **健康状态**：正常、离线、高负载等

## 6. 使用指南

### 6.1 通过Web界面管理任务

#### 6.1.1 创建简单任务
1. 登录Web管理界面（默认地址：http://localhost:8080）
2. 进入"任务管理" → "创建任务"
3. 填写任务信息：
   ```yaml
   任务名称: 每日数据备份
   任务类型: SHELL
   任务内容: |
     #!/bin/bash
     DATE=$(date +%Y%m%d)
     mysqldump -u root -p${DB_PASSWORD} task_scheduler > backup_${DATE}.sql
     gzip backup_${DATE}.sql
     scp backup_${DATE}.sql.gz backup-server:/backups/
   调度配置:
     类型: CRON
     表达式: 0 2 * * *  # 每天凌晨2点
     时区: Asia/Shanghai
   执行参数:
     DB_PASSWORD: yourpassword
   资源需求:
     CPU: 1核
     内存: 512MB
     磁盘: 1GB
   超时设置: 3600秒
   ```

#### 6.1.2 创建DAG工作流
1. 进入"工作流管理" → "创建工作流"
2. 可视化编辑DAG：
   - 添加任务节点
   - 设置节点间依赖关系
   - 配置分支条件（可选）
3. 配置工作流触发条件
4. 设置工作流参数和变量

### 6.2 使用API管理任务

#### 6.2.1 创建任务
```bash
curl -X POST http://localhost:8080/api/v1/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "name": "数据清洗任务",
    "type": "PYTHON",
    "content": "import pandas as pd\n\ndef clean_data():\n    # 数据清洗逻辑\n    pass",
    "trigger": {
      "type": "CRON",
      "expression": "0 3 * * *"
    },
    "parameters": {
      "input_file": "/data/raw/input.csv",
      "output_file": "/data/processed/output.csv"
    },
    "resources": {
      "cpu": 2,
      "memory": 1024,
      "disk": 5120
    }
  }'
```

#### 6.2.2 查询任务状态
```bash
# 查询特定任务状态
curl -X GET http://localhost:8080/api/v1/tasks/{taskId}/status \
  -H "Authorization: Bearer <token>"

# 查询任务执行历史
curl -X GET http://localhost:8080/api/v1/tasks/{taskId}/instances \
  -H "Authorization: Bearer <token>" \
```

```java
@Service
@Transactional
@Slf4j
public class TaskManagementService {
    
    @Autowired
    private TaskDefinitionRepository taskRepository;
    
    @Autowired
    private TaskExecutionRepository executionRepository;
    
    @Autowired
    private TaskProcessorFactory processorFactory;
    
    @Autowired
    private Validator validator;
    
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    /**
     * 创建任务
     */
    public TaskDefinition createTask(TaskCreateRequest request, Long userId) {
        log.info("创建任务: {}", request.getTaskCode());
        
        // 1. 验证任务编码唯一性
        if (taskRepository.existsByTaskCode(request.getTaskCode())) {
            throw new BusinessException("任务编码已存在");
        }
        
        // 2. 验证参数
        ValidationResult validation = validateTaskRequest(request);
        if (!validation.isValid()) {
            throw new BusinessException("参数验证失败: " + validation.getMessage());
        }
        
        // 3. 构建任务实体
        TaskDefinition task = new TaskDefinition();
        BeanUtils.copyProperties(request, task);
        task.setCreatedBy(userId);
        task.setCreatedAt(LocalDateTime.now());
        task.setUpdatedBy(userId);
        task.setUpdatedAt(LocalDateTime.now());
        task.setStatus(TaskStatus.DRAFT);
        
        // 4. 保存任务
        task = taskRepository.save(task);
        
        // 5. 发布任务创建事件
        eventPublisher.publishEvent(new TaskCreatedEvent(this, task));
        
        log.info("任务创建成功: {}", task.getTaskCode());
        return task;
    }
    
    /**
     * 更新任务
     */
    public TaskDefinition updateTask(Long taskId, TaskUpdateRequest request, Long userId) {
        log.info("更新任务: {}", taskId);
        
        // 1. 获取现有任务
        TaskDefinition existingTask = taskRepository.findById(taskId)
            .orElseThrow(() -> new NotFoundException("任务不存在"));
        
        // 2. 检查状态约束
        if (existingTask.getStatus() == TaskStatus.ACTIVE) {
            throw new BusinessException("激活状态的任务不能直接修改");
        }
        
        // 3. 验证参数
        TaskCreateRequest validateRequest = convertToCreateRequest(request);
        ValidationResult validation = validateTaskRequest(validateRequest);
        if (!validation.isValid()) {
            throw new BusinessException("参数验证失败: " + validation.getMessage());
        }
        
        // 4. 更新字段
        updateTaskFields(existingTask, request);
        existingTask.setUpdatedBy(userId);
        existingTask.setUpdatedAt(LocalDateTime.now());
        existingTask.setVersion(existingTask.getVersion() + 1);
        
        // 5. 保存更新
        existingTask = taskRepository.save(existingTask);
        
        // 6. 发布更新事件
        eventPublisher.publishEvent(new TaskUpdatedEvent(this, existingTask));
        
        log.info("任务更新成功: {}", taskId);
        return existingTask;
    }
    
    /**
     * 激活任务
     */
    public TaskDefinition activateTask(Long taskId, Long userId) {
        TaskDefinition task = taskRepository.findById(taskId)
            .orElseThrow(() -> new NotFoundException("任务不存在"));
        
        if (task.getStatus() != TaskStatus.DRAFT && task.getStatus() != TaskStatus.PAUSED) {
            throw new BusinessException("只有草稿或暂停状态的任务可以激活");
        }
        
        // 验证任务完整性
        validateTaskForActivation(task);
        
        task.setStatus(TaskStatus.ACTIVE);
        task.setUpdatedBy(userId);
        task.setUpdatedAt(LocalDateTime.now());
        
        task = taskRepository.save(task);
        
        // 通知调度器任务已激活
        eventPublisher.publishEvent(new TaskActivatedEvent(this, task));
        
        return task;
    }
    
    /**
     * 暂停任务
     */
    public TaskDefinition pauseTask(Long taskId, Long userId) {
        TaskDefinition task = taskRepository.findById(taskId)
            .orElseThrow(() -> new NotFoundException("任务不存在"));
        
        if (task.getStatus() != TaskStatus.ACTIVE) {
            throw new BusinessException("只有激活状态的任务可以暂停");
        }
        
        task.setStatus(TaskStatus.PAUSED);
        task.setUpdatedBy(userId);
        task.setUpdatedAt(LocalDateTime.now());
        
        task = taskRepository.save(task);
        
        // 通知调度器任务已暂停
        eventPublisher.publishEvent(new TaskPausedEvent(this, task));
        
        return task;
    }
    
    /**
     * 删除任务（逻辑删除）
     */
    public void deleteTask(Long taskId, Long userId) {
        TaskDefinition task = taskRepository.findById(taskId)
            .orElseThrow(() -> new NotFoundException("任务不存在"));
        
        if (task.getStatus() == TaskStatus.ACTIVE) {
            throw new BusinessException("激活状态的任务不能删除，请先暂停或禁用");
        }
        
        // 检查是否有正在执行的实例
        boolean hasRunningExecution = executionRepository.existsByTaskIdAndStatus(
            taskId, ExecutionStatus.RUNNING);
        if (hasRunningExecution) {
            throw new BusinessException("任务正在执行中，不能删除");
        }
        
        task.setStatus(TaskStatus.DISABLED);
        task.setUpdatedBy(userId);
        task.setUpdatedAt(LocalDateTime.now());
        
        taskRepository.save(task);
        
        eventPublisher.publishEvent(new TaskDisabledEvent(this, task));
    }

     * 查询任务列表
     */
    public Page<TaskDefinition> listTasks(TaskQueryRequest query, Pageable pageable) {
        Specification<TaskDefinition> spec = buildQuerySpecification(query);
        return taskRepository.findAll(spec, pageable);
    }
    
    /**
     * 任务参数验证
     */
    private ValidationResult validateTaskRequest(TaskCreateRequest request) {
        ValidationResult result = new ValidationResult();
        
        // 基础验证
        Set<ConstraintViolation<TaskCreateRequest>> violations = validator.validate(request);
        if (!violations.isEmpty()) {
            violations.forEach(v -> result.addError(v.getPropertyPath().toString(), v.getMessage()));
            return result;
        }
        
        // 根据任务类型进行特定验证
        TaskProcessor processor = processorFactory.getProcessor(request.getTaskType());
        if (processor != null) {
            ValidationResult typeValidation = processor.validateParameters(request.getParametersMap());
            if (!typeValidation.isValid()) {
                result.merge(typeValidation);
            }
        }
        
        // Cron表达式验证
        if (request.getTriggerType() == TriggerType.CRON) {
            try {
                CronExpression.parse(request.getCronExpression());
            } catch (IllegalArgumentException e) {
                result.addError("cronExpression", "Cron表达式格式无效");
            }
        }
        
        return result;
    }
```

```java
            return new ObjectMapper().readValue(json, new TypeReference<Map<String, Object>>() {});

        // 实现AES加密逻辑
        Cipher cipher = Cipher.getInstance(algorithm);
        SecretKeySpec keySpec = new SecretKeySpec(encryptionKey.getBytes(), "AES");
        cipher.init(Cipher.ENCRYPT_MODE, keySpec);
        byte[] encrypted = cipher.doFinal(data.getBytes());
        return Base64.getEncoder().encodeToString(encrypted);
    }

        Cipher cipher = Cipher.getInstance(algorithm);
        SecretKeySpec keySpec = new SecretKeySpec(encryptionKey.getBytes(), "AES");
        cipher.init(Cipher.DECRYPT_MODE, keySpec);
        byte[] decoded = Base64.getDecoder().decode(encryptedData);
        byte[] decrypted = cipher.doFinal(decoded);
        return new String(decrypted);
    }
```

# 任务调度平台 - 失败重试实现

## 1. 概述

失败重试是任务调度平台中的关键特性，当任务执行失败时自动重新执行，提高任务成功率。本文实现一个支持失败重试的任务调度器，具有可配置的重试次数、重试间隔（支持指数退避和固定间隔）、错误日志和状态跟踪。

## 2. 设计思路

- **任务抽象**：任务被封装为可调用对象（函数或类），执行时可能抛出异常。
- **重试策略**：支持立即重试、固定间隔重试、指数退避重试。
- **任务状态**：跟踪每个任务的执行状态（等待、运行中、成功、失败、重试中）。
- **调度器**：管理任务队列，执行任务，并根据重试策略决定是否重试。

## 3. 实现细节

```python
import time
import logging
from dataclasses import dataclass, field
from typing import Callable, Any, Optional, List, Dict
from enum import Enum

class TaskStatus(Enum):
    PENDING = "pending"
    RUNNING = "running"
    SUCCESS = "success"
    FAILED = "failed"
    RETRYING = "retrying"

@dataclass
class Task:
    task_id: str
    func: Callable[..., Any]
    args: tuple = ()
    kwargs: dict = field(default_factory=dict)
    max_retries: int = 3
    retry_strategy: RetryStrategy = RetryStrategy.FIXED_DELAY
    retry_delay: float = 1.0  # 秒，用于固定延迟
    status: TaskStatus = TaskStatus.PENDING
    retry_count: int = 0
    last_error: Optional[Exception] = None
    created_at: float = field(default_factory=time.time)
    completed_at: Optional[float] = None

    def execute(self) -> Any:
        """执行任务，返回结果"""
        self.status = TaskStatus.RUNNING
        try:
            result = self.func(*self.args, **self.kwargs)
            self.status = TaskStatus.SUCCESS
            self.completed_at = time.time()
            return result
        except Exception as e:
            self.last_error = e
            self.status = TaskStatus.FAILED
            raise e

    def should_retry(self) -> bool:
        """判断是否应该重试"""
        return self.retry_count < self.max_retries

    def prepare_retry(self):
        """准备重试：更新重试次数，设置延迟，重置状态"""
        self.retry_count += 1
        self.status = TaskStatus.RETRYING
        # 计算延迟
        if self.retry_strategy == RetryStrategy.IMMEDIATE:
            delay = 0
        elif self.retry_strategy == RetryStrategy.FIXED_DELAY:
            delay = self.retry_delay
        elif self.retry_strategy == RetryStrategy.EXPONENTIAL_BACKOFF:
            delay = self.retry_delay * (2 ** (self.retry_count - 1))  # 指数退避
        else:
            delay = self.retry_delay
        time.sleep(delay)

    def reset(self):
        """重置任务状态，用于重新入队"""
        self.status = TaskStatus.PENDING
        self.last_error = None
```

```python
        self.logger.info(f"Task added: {task.task_id}")
        return task.task_id

    def _execute_task(self, task: Task) -> Any:
        """执行单个任务，包含重试逻辑"""
        while True:
            try:
                result = task.execute()
                self.logger.info(f"Task {task.task_id} succeeded.")
                return result
            except Exception as e:
                self.logger.warning(f"Task {task.task_id} failed: {e}. Retry count: {task.retry_count}/{task.max_retries}")
                if task.should_retry():
                    task.prepare_retry()
                    self.logger.info(f"Retrying task {task.task_id}...")
                    continue
                else:
                    self.logger.error(f"Task {task.task_id} permanently failed after {task.max_retries} retries.")
                    task.status = TaskStatus.FAILED
                    task.completed_at = time.time()
                    raise e

    def _worker_loop(self):
        """工作线程主循环，从队列取任务执行"""
        while not self._shutdown:
            try:
                task = self.task_queue.get(timeout=1.0)
                if task is None:  # 哨兵值，用于停止
                    break
                self.logger.debug(f"Processing task: {task.task_id}")
                try:
                    future = self.executor.submit(self._execute_task, task)
                    self.futures[task.task_id] = future
                    # 可以添加回调来处理完成或异常
                    future.add_done_callback(lambda f: self._task_done_callback(task, f))
                except Exception as e:
                    self.logger.error(f"Error submitting task {task.task_id}: {e}")
            except queue.Empty:
                continue

    def _task_done_callback(self, task: Task, future: Future):
        """任务完成回调"""
        try:
            result = future.result()
            self.logger.info(f"Task {task.task_id} completed with result: {result}")
        except Exception as e:
            self.logger.error(f"Task {task.task_id} raised exception: {e}")

    def start(self):
        """启动调度器"""
        self._shutdown = False
        # 启动工作线程
        self.worker_thread = threading.Thread(target=self._worker_loop, daemon=True)
        self.worker_thread.start()
        self.logger.info("Task scheduler started.")

    def stop(self, wait: bool = True):
        """停止调度器"""
        self._shutdown = True
        # 放置哨兵值使工作线程退出
        self.task_queue.put(None)
        if wait:
            self.worker_thread.join()
        self.executor.shutdown(wait=wait)
        self.logger.info("Task scheduler stopped.")

    def get_task_status(self, task_id: str) -> Optional[TaskStatus]:
        """获取任务状态"""
        # 这里简化：实际应维护一个任务字典
        # 在实际实现中，可以将任务保存在字典中，根据task_id查找
        pass

    def wait_for_all(self):
        """等待所有任务完成"""
        for future in self.futures.values():
            try:
                future.result()
            except Exception:
                pass
```

```python
"""
规则引擎模块
职责：加载配置中的告警规则，并对采集到的指标进行评估，判断是否触发告警。
这是一个简化的评估引擎，实际生产中可集成Prometheus的查询能力。
"""
import yaml
import loguru
from typing import List, Dict, Any, Optional
from dataclasses import dataclass
from datetime import datetime, timedelta
from .collector import MetricPoint

@dataclass
class AlertRule:
    name: str
    description: str
    metric: str
    condition: str  # 此演示中使用简单阈值，生产环境应为表达式
    severity: str
    channels: List[str]
    labels: Dict[str, str]
    annotations: Dict[str, str]
    for_duration: Optional[timedelta] = None # 用于`for`字段
    # 存储用于`for`判断的状态
    _first_trigger_time: Optional[datetime] = None
    _last_alert_time: Optional[datetime] = None

@dataclass
class AlertInstance:
    """一个具体的告警实例"""
    rule_name: str
    labels: Dict[str, str]  # 从规则和触发数据中合并
    annotations: Dict[str, str]
    severity: str
    value: float
    triggered_at: datetime
    channels: List[str]

class RulesEngine:
    def __init__(self, config_path: str):
        self.rules: List[AlertRule] = []
        self._load_config(config_path)
        loguru.logger.info(f"Rules Engine loaded {len(self.rules)} alert rules.")

    def _load_config(self, config_path: str):
        """从YAML文件加载告警规则"""
        try:
            with open(config_path, 'r', encoding='utf-8') as f:
                config = yaml.safe_load(f)
            
            global_config = config.get('global', {})
            self.default_channels = [global_config.get('default_channel', 'default')]
            self.inhibit_interval = global_config.get('inhibit_interval', 300)

            for rule_conf in config.get('alert_rules', []):
                # 将YAML配置映射到AlertRule对象
                for_duration = None
                if 'for' in rule_conf:
                    # 简单解析，如 "5m" -> timedelta(minutes=5)
                    val, unit = rule_conf['for'][:-1], rule_conf['for'][-1]
                    if unit == 'm':
                        for_duration = timedelta(minutes=int(val))
                
                channels = rule_conf.get('channels', self.default_channels)
                
                rule = AlertRule(
                    name=rule_conf['name'],
                    description=rule_conf.get('description', ''),
                    metric=rule_conf['metric'],
                    condition=rule_conf['condition'], # 注意：这里存的是字符串
                    severity=rule_conf.get('severity', 'warning'),
                    channels=channels,
                    labels=rule_conf.get('labels', {}),
                    annotations=rule_conf.get('annotations', {}),
                    for_duration=for_duration
                )
                self.rules.append(rule)
        except Exception as e:
            loguru.logger.error(f"Failed to load alert rules: {e}")
            raise

    def evaluate(self, metrics: List[MetricPoint]) -> List[AlertInstance]:
        """
        评估所有规则，返回触发的告警实例列表。
        注意：这是一个极度简化的实现，仅用于演示概念。
        实际的`condition`评估需要表达式解析器（如Prometheus的PromQL）。
        此演示中，我们用简单逻辑模拟几个规则。
        """
        alerts = []
        now = datetime.now()

        for rule in self.rules:
            # 1. 过滤出与当前规则相关的指标
            relevant_metrics = [m for m in metrics if m.name == rule.metric]

            if not relevant_metrics:
                continue

            # 2. 简化的规则评估逻辑 (生产环境应替换为表达式求值)
            triggered = False
            trigger_value = 0.0
            trigger_metric = None

            if rule.name == "high_task_failure_rate":
                # 模拟计算失败率（这里简化为单个失败任务即触发）
                failed_metrics = [m for m in relevant_metrics if m.labels.get('status') == 'failed']
                if failed_metrics:
                    triggered = True
                    trigger_value = 100.0 # 模拟失败率
                    trigger_metric = failed_metrics[0]

            elif rule.name == "task_timeout":
                # 模拟检查超时（简化：duration > 10秒则视为超时）
                for m in relevant_metrics:
                    if m.value > 10.0:
                        triggered = True
                        trigger_value = m.value
                        trigger_metric = m
                        break

            elif rule.name == "task_queue_backlog":
                # 模拟检查队列大小
                if relevant_metrics and relevant_metrics[-1].value > 1000:
                    triggered = True
                    trigger_value = relevant_metrics[-1].value
                    trigger_metric = relevant_metrics[-1]

            # 3. 处理`for`持续时长条件
            if triggered and rule.for_duration:
                if rule._first_trigger_time is None:
                    rule._first_trigger_time = now
                    triggered = False # 首次触发，不立即告警，等待`for`时长
                elif (now - rule._first_trigger_time) < rule.for_duration:
                    triggered = False # 持续时间未满足
                # 如果持续时间满足，`triggered`保持True，并重置首次触发时间（由alerter处理）
            elif not triggered:
                rule._first_trigger_time = None # 条件不满足，重置计时

            # 4. 检查抑制间隔（避免告警风暴）
            if triggered and rule._last_alert_time:
                if (now - rule._last_alert_time).total_seconds() < self.inhibit_interval:
                    triggered = False # 在抑制期内，不发送

            # 5. 如果最终触发，生成告警实例
            if triggered and trigger_metric:
                # 合并标签：规则基础标签 + 触发指标的具体标签
                merged_labels = {**rule.labels, **trigger_metric.labels}
                # 格式化注解（简化处理，实际应支持模板替换）
                formatted_annotations = {
                    k: v.replace('{{ $value }}', str(trigger_value))
                       .replace('{{ $labels.job_name }}', merged_labels.get('job_name', 'N/A'))
                    for k, v in rule.annotations.items()
                }

                alert_instance = AlertInstance(
                    rule_name=rule.name,
                    labels=merged_labels,
                    annotations=formatted_annotations,
                    severity=rule.severity,
                    value=trigger_value,
                    triggered_at=now,
                    channels=rule.channels
                )
                alerts.append(alert_instance)
                rule._last_alert_time = now
                rule._first_trigger_time = None # 告警发送后重置状态

        return alerts
```

```python
"""
告警通知服务
职责：接收告警实例，根据配置的渠道发送通知，并记录告警历史。
"""
import yaml
import requests
import loguru
from typing import List, Dict, Any
from datetime import datetime
from dataclasses import dataclass, asdict
from .rules_engine import AlertInstance

@dataclass
class AlertHistory:
    alert_id: str
    rule_name: str
    severity: str
    value: float
    triggered_at: str
    notified_channels: List[str]
    notification_success: bool
    error_message: str = ""

class AlertManager:
    def __init__(self, config_path: str):
        self.channels_config: Dict[str, Any] = {}
        self.alert_history: List[AlertHistory] = []
        self._load_config(config_path)
        loguru.logger.info("Alert Manager initialized.")

    def _load_config(self, config_path: str):
        """加载通知渠道配置"""
        try:
            with open(config_path, 'r', encoding='utf-8') as f:
                config = yaml.safe_load(f)
            self.channels_config = config.get('notification_channels', {})
        except Exception as e:
            loguru.logger.error(f"Failed to load notification channels config: {e}")
            raise

    def send_alerts(self, alert_instances: List[AlertInstance]):
        """处理并发送一批告警"""
        for alert in alert_instances:
            alert_id = f"{alert.rule_name}_{alert.triggered_at.strftime('%Y%m%d%H%M%S')}"
            loguru.logger.warning(f"Processing alert: [{alert.severity.upper()}] {alert.rule_name} - {alert.annotations.get('summary', '')}")

            # 遍历该告警配置的所有通知渠道
            notified_channels = []
            for channel_name in alert.channels:
                channel_config = self.channels_config.get(channel_name)
                if not channel_config:
                    loguru.logger.error(f"Notification channel '{channel_name}' not found in config.")
                    continue

                success = self._send_to_channel(channel_name, channel_config, alert)
                notified_channels.append(channel_name)

                # 记录历史
                history = AlertHistory(
                    alert_id=alert_id,
                    rule_name=alert.rule_name,
                    severity=alert.severity,
                    value=alert.value,
                    triggered_at=alert.triggered_at.isoformat(),
                    notified_channels=notified_channels,
                    notification_success=success,
                    error_message="" if success else "Sending failed"
                )
                self.alert_history.append(history)

    def _send_to_channel(self, name: str, config: Dict, alert: AlertInstance) -> bool:
        """根据渠道类型发送通知"""
        try:
            channel_type = config.get('type', '').lower()

            if channel_type == 'webhook':
                return self._send_webhook(config, alert)
            elif channel_type == 'email':
                return self._send_email(config, alert)
            else:
```

```python
class TaskScheduler:
    """任务调度器"""
    
    def __init__(self, task_manager: 'TaskManager'):
        self.task_manager = task_manager
        self.logger = logging.getLogger('TaskScheduler')
    
    def schedule_tasks(self):
        """调度待处理的任务"""
        try:
            # 获取所有待调度的任务
            pending_tasks = self.task_manager.get_pending_tasks()
            
            for task_instance in pending_tasks:
                self._schedule_single_task(task_instance)
                
            self.logger.debug(f"调度完成，处理了 {len(pending_tasks)} 个任务")
            
        except Exception as e:
            self.logger.error(f"调度任务失败: {e}")
            raise
    
    def _schedule_single_task(self, task_instance: TaskInstance):
        """调度单个任务"""
        task_id = task_instance.task_id
        task_def = self.task_manager.get_task_definition(task_id)
        
        if not task_def:
            self.logger.error(f"找不到任务定义: {task_id}")
            return
        
        # 检查依赖关系
        if not self._check_dependencies(task_def):
            self.logger.info(f"任务 {task_id} 依赖未满足，跳过调度")
            return
        
        # 计算下次执行时间
        next_execution = self._calculate_next_execution(task_def)
        
        if next_execution and next_execution <= datetime.now():
            # 更新任务状态和调度时间
            self.task_manager.update_task_instance(
                task_instance.instance_id,
                {
                    'status': TaskStatus.SCHEDULED,
                    'scheduled_time': next_execution
                }
            )
            
            self.logger.info(f"任务已调度: {task_id} -> {next_execution}")
    
    def _check_dependencies(self, task_def: TaskDefinition) -> bool:
        """检查任务依赖"""
        if not task_def.dependencies:
            return True
        
        for dep_task_id in task_def.dependencies:
            # 检查依赖任务是否成功完成
            last_instance = self.task_manager.get_last_task_instance(dep_task_id)
            if not last_instance or last_instance.status != TaskStatus.SUCCESS:
                return False
        
        return True
    
    def _calculate_next_execution(self, task_def: TaskDefinition) -> Optional[datetime]:
        """计算下次执行时间"""
        if task_def.trigger_type == TriggerType.CRON and task_def.cron_expression:
            # 使用cron表达式计算
            return self._calculate_cron_next(task_def.cron_expression)
        
        elif task_def.trigger_type == TriggerType.INTERVAL and task_def.interval_seconds:
            # 固定间隔
            last_instance = self.task_manager.get_last_task_instance(task_def.task_id)
            if last_instance and last_instance.start_time:
                return last_instance.start_time + timedelta(seconds=task_def.interval_seconds)
            else:
                return datetime.now()
        
        elif task_def.trigger_type == TriggerType.EVENT:
            # 事件触发，由事件处理器触发
            return None
        
        return datetime.now()
    
    def _calculate_cron_next(self, cron_expression: str) -> datetime:
        """计算cron表达式的下次执行时间"""
        # 这里简化实现，实际项目中应使用专业的cron解析库
```

```python
class TaskDispatcher:
    """任务分发器"""
    
    def __init__(self, task_manager: 'TaskManager'):
        self.task_manager = task_manager
        self.logger = logging.getLogger('TaskDispatcher')

            scheduled_tasks = self.task_manager.get_scheduled_tasks()
            
            for task_instance in scheduled_tasks:
                if self._can_dispatch(task_instance):
                    self._dispatch_single_task(task_instance)
            
            self.logger.debug(f"分发完成，处理了 {len(scheduled_tasks)} 个任务")
            
        except Exception as e:
            self.logger.error(f"分发任务失败: {e}")
            raise
    
    def _can_dispatch(self, task_instance: TaskInstance) -> bool:
        """检查任务是否可以分发"""
        # 检查资源是否满足
        resource_manager = ResourceManager()
        task_def = self.task_manager.get_task_definition(task_instance.task_id)
        
        if task_def and task_def.resource_requirements:
            if not resource_manager.check_resources(task_def.resource_requirements):
                self.logger.info(f"资源不足，任务 {task_instance.task_id} 无法分发")
                return False
        
        # 检查是否在允许的时间窗口
        if not self._in_execution_window(task_def):
            return False
        
        return True
    
    def _dispatch_single_task(self, task_instance: TaskInstance):
        """分发单个任务"""
        try:
            # 选择执行节点
            execution_node = self._select_execution_node(task_instance)
```

### 3.4 任务执行器

```python
class TaskExecutor:
    """任务执行器"""
    
    def __init__(self, task_manager: 'TaskManager'):
        self.task_manager = task_manager
        self.logger = logging.getLogger('TaskExecutor')
        self.executor_plugins = {}
        
        # 注册默认执行器
        self._register_default_executors()
    
    def _register_default_executors(self):
        """注册默认执行器"""
        self.executor_plugins['default'] = DefaultTaskExecutor()
        self.executor_plugins['shell'] = ShellTaskExecutor()
        self.executor_plugins['http'] = HttpTaskExecutor()
    
    def execute_task(self, task_instance: TaskInstance) -> Future:
        """
        执行任务
        
        Args:
            task_instance: 任务实例
            
        Returns:
            Future: 执行结果的Future对象
        """
        task_def = self.task_manager.get_task_definition(task_instance.task_id)
        
        if not task_def:
            raise ValueError(f"找不到任务定义: {task_instance.task_id}")
        
        # 选择合适的执行器
        executor = self._select_executor(task_def)
        
        # 提交到线程池执行
        future = executor.submit(
            self._execute_task_wrapper,
            task_instance,
            task_def,
            executor
        )
        
        return future
    
    def _execute_task_wrapper(self, task_instance: TaskInstance, 
                            task_def: TaskDefinition, executor):
        """任务执行包装器"""
        try:
            # 执行前检查
            self._pre_execution_check(task_instance, task_def)
            
            # 执行任务
            start_time = time.time()
            result = executor.execute(task_instance, task_def)
            execution_time = time.time() - start_time
            
            # 更新任务状态为成功
            self.task_manager.update_task_instance(
                task_instance.instance_id,
                {
                    'status': TaskStatus.SUCCESS,
                    'end_time': datetime.now(),
                    'result': result,
                    'execution_log': f"执行成功，耗时: {execution_time:.2f}秒"
                }
            )
            
            self.logger.info(f"任务执行成功: {task_instance.task_id}")
            return result
            
        except Exception as e:
            # 处理执行异常
            self._handle_execution_error(task_instance, task_def, e)
            raise
    
    def _select_executor(self, task_def: TaskDefinition) -> 'BaseTaskExecutor':
        """选择执行器"""
        executor_type = task_def.parameters.get('executor_type', 'default')
        return self.executor_plugins.get(executor_type, self.executor_plugins['default'])
    
    def _pre_execution_check(self, task_instance: TaskInstance, task_def: TaskDefinition):
        """执行前检查"""
        # 检查任务是否被取消
        instance = self.task_manager.get_task_instance(task_instance.instance_id)
        if instance.status == TaskStatus.CANCELLED:
            raise Exception("任务已被取消")
    
    def _handle_execution_error(self, task_instance: TaskInstance, 
                              task_def: TaskDefinition, error: Exception):
        """处理执行错误"""
        # 检查是否需要重试
        if self._should_retry(task_instance, task_def):
            self._retry_task(task_instance, task_def)
        else:
            # 标记为失败
            self.task_manager.update_task_instance(
                task_instance.instance_id,
                {
                    'status': TaskStatus.FAILED,
                    'end_time': datetime.now(),
                    'error_message': str(error),
                    'execution_log': f"执行失败: {str(error)}"
                }
            )
    
    def _should_retry(self, task_instance: TaskInstance, task_def: TaskDefinition) -> bool:
        """是否需要重试"""
        if task_instance.retry_count >= task_def.max_retry_count:
            return False
        
        # 可以添加重试条件判断
        return True
    
    def _retry_task(self, task_instance: TaskInstance, task_def: TaskDefinition):
        """重试任务"""
        # 更新重试次数
        self.task_manager.update_task_instance(
            task_instance.instance_id,
            {
                'status': TaskStatus.RETRY,
                'retry_count': task_instance.retry_count + 1,
                'start_time': None,
                'end_time': None,
                'error_message': None
            }
        )
        
        self.logger.info(f"任务重试: {task_instance.task_id} 第 {task_instance.retry_count + 1} 次")
```

```python
from abc import ABC, abstractmethod
import subprocess
import requests

class BaseTaskExecutor(ABC):
    """任务执行器基类"""
    
    @abstractmethod
    def execute(self, task_instance: TaskInstance, task_def: TaskDefinition) -> Any:
        """执行任务"""
        pass
    
    def submit(self, func, *args, **kwargs) -> Future:
        """提交到线程池"""
        return self.thread_pool.submit(func, *args, **kwargs)

class DefaultTaskExecutor(BaseTaskExecutor):
    """默认任务执行器"""
    
    def __init__(self):
        self.thread_pool = ThreadPoolExecutor(max_workers=5)
    
    def execute(self, task_instance: TaskInstance, task_def: TaskDefinition) -> Dict[str, Any]:
        """执行Python函数任务"""
        try:
            # 获取执行函数
            func_name = task_def.parameters.get('function')
            func_args = task_def.parameters.get('args', [])
            func_kwargs = task_def.parameters.get('kwargs', {})
            
            # 动态加载和执行函数
            module_name, func_name = func_name.rsplit('.', 1)
            import importlib
            module = importlib.import_module(module_name)
            func = getattr(module, func_name)
            
            # 执行函数
            result = func(*func_args, **func_kwargs)
            
            return {
                "status": "success",
                "result": result,
                "message": "函数执行成功"
            }
            
        except Exception as e:
            raise Exception(f"函数执行失败: {str(e)}")

class ShellTaskExecutor(BaseTaskExecutor):
    """Shell命令执行器"""
    
    def __init__(self):
        self.thread_pool = ThreadPoolExecutor(max_workers=5)
    
    def execute(self, task_instance: TaskInstance, task_def: TaskDefinition) -> Dict[str, Any]:
        """执行Shell命令"""
        try:
            command = task_def.parameters.get('command')
            working_dir = task_def.parameters.get('working_dir', '.')
            timeout = task_def.parameters.get('timeout', 3600)
            
            # 执行命令
            result = subprocess.run(
                command,
                shell=True,
                cwd=working_dir,
                capture_output=True,
                text=True,
                timeout=timeout
            )
            
            return {
                "status": "success" if result.returncode == 0 else "failed",
                "return_code": result.returncode,
                "stdout": result.stdout,
                "stderr": result.stderr
            }
            
        except subprocess.TimeoutExpired:
            raise Exception("命令执行超时")
        except Exception as e:
            raise Exception(f"命令执行失败: {str(e)}")

class HttpTaskExecutor(BaseTaskExecutor):
    """HTTP请求执行器"""
    
    def __init__(self):
        self.thread_pool = ThreadPoolExecutor(max_workers=5)
    
    def execute(self, task_instance: TaskInstance, task_def: TaskDefinition) -> Dict[str, Any]:
        """执行HTTP请求"""
        try:
            url = task_def.parameters.get('url')
            method = task_def.parameters.get('method', 'GET')
            headers = task_def.parameters.get('headers', {})
            data = task_def.parameters.get('data')
            timeout = task_def.parameters.get('timeout', 30)
            
            # 发送HTTP请求
            response = requests.request(
                method=method,
                url=url,
                headers=headers,
                data=data,
                timeout=timeout
            )
            
            return {
                "status": "success" if response.status_code < 400 else "failed",
                "status_code": response.status_code,
                "headers": dict(response.headers),
                "body": response.text
            }
            
        except Exception as e:
            raise Exception(f"HTTP请求失败: {str(e)}")
```
