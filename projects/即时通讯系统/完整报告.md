# 即时通讯系统压力测试方案

## 1. 测试概述
本方案旨在对即时通讯系统进行全面的压力测试，以评估系统在高并发场景下的性能、稳定性和可扩展性。通过模拟大量用户同时在线、发送消息等操作，识别系统瓶颈，为优化提供依据。

## 2. 测试目标
- 确定系统最大并发连接数
- 测量消息吞吐量（消息/秒）
- 评估端到端消息延迟
- 监控服务器资源使用情况（CPU、内存、网络、磁盘I/O）
- 验证系统在长时间高负载下的稳定性
- 测试系统自动扩缩容能力（如适用）

## 3. 测试环境
### 3.1 硬件环境
- **服务器**：4核CPU，8GB内存，100Mbps网络带宽
- **客户端**：独立测试机，性能不低于服务器配置
- **网络环境**：内网测试，网络延迟<1ms

### 3.2 软件环境
- **操作系统**：Ubuntu 20.04 LTS
- **即时通讯服务**：基于WebSocket的Node.js服务
- **数据库**：MongoDB 4.4（消息持久化）
- **消息队列**：RabbitMQ 3.8（用于消息分发）
- **压力测试工具**：Locust 2.5

## 4. 测试场景
### 4.1 基础场景
1. **用户连接**：模拟用户建立WebSocket连接
2. **单聊消息**：用户向特定用户发送文字消息
3. **群聊消息**：用户向群组发送文字消息
4. **消息接收**：用户接收来自其他用户或群组的消息
5. **心跳维持**：定期发送心跳包保持连接

### 4.2 高级场景
1. **突发连接**：模拟短时间内大量用户同时连接
2. **消息风暴**：模拟大量用户同时发送消息
3. **混合负载**：连接、消息发送、接收混合操作

```python
# locust_test.py
from locust import User, task, between, events
import websocket
import json
import time
import random
import string

class WebSocketUser(User):
    wait_time = between(0.5, 2)
    
    def on_start(self):
        """用户启动时建立WebSocket连接"""
        self.ws = websocket.WebSocket()
        self.ws.connect("ws://localhost:8080/ws")
        self.user_id = ''.join(random.choices(string.ascii_lowercase, k=8))
        # 发送认证消息
        auth_msg = {
            "type": "auth",
            "user_id": self.user_id,
            "token": "test_token"
        }
        self.ws.send(json.dumps(auth_msg))
        # 启动消息接收线程
        self.receive_messages()
    
    def receive_messages(self):
        """接收消息的循环"""
        while True:
            try:
                message = self.ws.recv()
                if not message:
                    break
                data = json.loads(message)
                # 记录接收消息的延迟
                if 'timestamp' in data:
                    latency = time.time() - data['timestamp']
                    events.request.fire(
                        request_type="WebSocket",
                        name="Message Receive",
                        response_time=latency * 1000,
                        response_length=len(message),
                        exception=None,
                        context={}
                    )
            except Exception as e:
                break
    
    @task(3)
    def send_direct_message(self):
        """发送单聊消息"""
        message = {
            "type": "direct",
            "from": self.user_id,
            "to": f"user_{random.randint(1, 1000)}",
            "content": f"Test message {time.time()}",
            "timestamp": time.time()
        }
        self.ws.send(json.dumps(message))
        events.request.fire(
            request_type="WebSocket",
            name="Direct Message Send",
            response_time=0,  # 发送无响应时间
            response_length=0,
            exception=None,
            context={}
        )
    
    @task(2)
    def send_group_message(self):
        """发送群聊消息"""
        message = {
            "type": "group",
            "from": self.user_id,
            "group_id": f"group_{random.randint(1, 100)}",
            "content": f"Group message {time.time()}",
            "timestamp": time.time()
        }
        self.ws.send(json.dumps(message))
        events.request.fire(
            request_type="WebSocket",
            name="Group Message Send",
            response_time=0,
            response_length=0,
            exception=None,
            context={}
        )
    
    @task(1)
    def send_heartbeat(self):
        """发送心跳包"""
        message = {"type": "heartbeat", "timestamp": time.time()}
        self.ws.send(json.dumps(message))
    
    def on_stop(self):
        """用户停止时关闭连接"""
        self.ws.close()
```

构建一个高可用、高性能、可水平扩展的分布式即时通讯系统，支持单聊、群聊、文件传输、消息推送及实时状态同步等功能。

- 消息已读回执与离线消息

## **2. 系统架构设计**

### **2.1 整体架构图**
```
[客户端层] 
  │
  ▼
[接入层] 
  ├─ WebSocket 长连接网关（主通道）
  ├─ HTTP API 网关（RESTful 接口）
  └─ MQTT 协议适配器（可选，用于物联网场景）
  │
  ▼
[业务服务层]（微服务集群）
  ├─ 用户服务（User Service）
  ├─ 关系服务（Relationship Service）
  ├─ 消息服务（Message Service）
  ├─ 群组服务（Group Service）
  ├─ 会话服务（Session Service）
  └─ 推送服务（Push Service）
  │
  ▼
[数据层]
  ├─ 关系型数据库（MySQL）：用户、群组基础信息
  ├─ NoSQL（MongoDB/Redis）：消息存储、会话列表、在线状态
  ├─ 消息队列（Kafka/RocketMQ）：消息异步分发
  └─ 分布式缓存（Redis Cluster）：热点数据、会话状态
  │
  ▼
[基础设施层]
  ├─ 服务发现与配置中心（Nacos）
  ├─ 链路追踪（SkyWalking）
  ├─ 日志系统（ELK）
  └─ 监控告警（Prometheus + Grafana）
```

### **2.2 通信协议选择**
| 协议       | 适用场景                     | 优点                           | 缺点                     |
|------------|------------------------------|--------------------------------|--------------------------|
| WebSocket  | 主推协议，全双工实时通信     | 低延迟、服务端可主动推送       | 需维护长连接，负载均衡复杂 |
| MQTT       | 移动端、弱网络环境           | 轻量、支持离线消息、QoS等级    | 协议解析复杂，需Broker   |
| HTTP Long Polling | 兼容老旧客户端          | 无需特殊协议支持               | 延迟高、服务端压力大     |

**推荐方案**：主流客户端优先使用 **WebSocket**，移动端备选 **MQTT**，Web端兼容 **SSE（Server-Sent Events）**。

### **3.2 消息模块**
#### **消息存储方案**
```
方案1（写扩散）：
  消息写入后，为每个接收者生成一条消息记录存入其收件箱。
  优点：查询快，支持已读标记
  缺点：存储成本高，群消息写放大严重

方案2（读扩散）：
  消息只存储一份，接收者通过时间线拉取。
  优点：写入简单，存储空间小
  缺点：查询复杂，需合并多时间线

推荐方案：单聊采用写扩散，群聊采用读扩散（结合推拉结合模式）。
```

#### **消息数据结构（MongoDB示例）**
```json
{
  "_id": "msg_20230801120000_abc123",
  "conversation_id": "conv_uid1_uid2",
  "sender_id": "uid_001",
  "type": "text|image|file|audio|video",
  "content": {
    "text": "Hello!",
    "image": { "url": "http://cdn/img.png", "width": 100, "height": 100 },
    "file": { "url": "http://cdn/file.pdf", "size": 1024, "name": "report.pdf" }
  },
  "status": "sent|delivered|read",
  "client_id": "client_abc",
  "server_id": "msg_20230801120000_abc123",
  "timestamp": 1690873200000,
  "mentioned_users": ["uid_002"]
}
```

#### **消息投递流程（单聊示例）**
```
1. 客户端A → 服务器：发送消息（携带client_msg_id）
2. 服务器生成server_msg_id，写入消息存储
3. 服务器查询接收方B的在线状态：
   - 在线：通过WebSocket直接下发消息
   - 离线：推送到离线消息队列，存储到离线箱
4. 服务器向客户端A返回ACK（携带server_msg_id）
5. 客户端A收到ACK后，更新本地消息状态
```

### **3.5 在线状态管理**
```
方案：Redis Bitmap + 心跳机制
Key: online:status:{date} (如 online:status:20230801)
BitOffset: 用户uid的hash值
Value: 1表示在线，0表示离线

心跳间隔：客户端每30秒发送一次心跳包
超时判断：服务端90秒未收到心跳，标记为离线
```

```javascript
// 客户端连接示例
const ws = new WebSocket('wss://im.example.com/ws?token=xxxxx');

// 服务端处理
wss.on('connection', (ws, req) => {
```

#### **连接多设备同步**
```
同一用户多设备登录策略：
1. 允许同平台（如手机+手机）同时在线
2. 消息多端同步投递
3. 会话状态（已读）同步更新
4. 设备管理：可单独下线指定设备
```

### **4.2 消息可靠投递（QoS机制）**
```
客户端 → 服务器：发送消息（带client_msg_id）
服务器 → 客户端：返回ACK（带server_msg_id）

超时重传机制：
1. 客户端设置消息发送超时（如5秒）
2. 超时未收到ACK，客户端重传（相同client_msg_id）
3. 服务端根据client_msg_id去重，保证幂等性

消息顺序性保证：
1. 每个会话内使用单调递增的序列号（sequence）
2. 客户端检测序列号连续性，发现丢序时请求补推
```

### **4.3 离线消息处理**
```python
# 离线消息队列设计（Redis List）
Key: offline:{uid}
Value: 消息ID列表

# 拉取离线消息流程
def fetch_offline_messages(uid, last_msg_id=None):
    # 1. 从离线队列获取消息ID列表
    msg_ids = redis.lrange(f'offline:{uid}', 0, -1)
    
    # 2. 批量获取消息详情
    messages = mongo.message.find({'_id': {'$in': msg_ids}})
    
    # 3. 删除已拉取的离线消息
    redis.delete(f'offline:{uid}')
    
    # 4. 更新会话最后消息
    update_conversations(uid, messages)
    
    return messages
```

## **5. 数据库设计与优化**

### **5.1 分库分表策略**
```
用户表：按uid hash分16个库，每库16个表（共256个分表）
消息表：按conversation_id hash分库，按时间分表（月表）
群组表：按group_id hash分库

分片键选择：
- 用户相关查询：uid
- 会话相关查询：conversation_id
- 群组相关查询：group_id
```

### **5.2 缓存架构**
```
L1缓存（本地缓存）：Guava Cache，缓存用户基本信息、群组信息
L2缓存（分布式缓存）：Redis Cluster
  - 用户在线状态：Bitmap
  - 会话列表：Sorted Set
  - 未读消息数：String (INCR操作)
  - 热点会话：ZSet缓存最近100条消息
```

### **5.3 消息存储归档**
```
热数据：最近3个月消息，存储在SSD MongoDB
温数据：3-12个月消息，存储在HDD MongoDB
冷数据：1年以上消息，归档到对象存储（S3/HDFS）

归档流程：
1. 定时任务扫描过期消息
2. 压缩打包（按会话归档）
3. 上传至对象存储
4. 删除原数据，记录归档索引
```

## 一、概述

推送通知是即时通讯系统的核心功能之一，能够在用户离线或应用未打开时，将新消息、系统通知等信息实时送达用户设备。本方案将详细设计和实现一个完整、可靠、高效的推送通知系统。

## 二、系统架构设计

### 2.1 整体架构

```
客户端 ← 推送通道 ← 推送服务 → 消息队列 → 业务逻辑层
         ↑              ↑
    设备注册服务    通知存储服务
```

### 2.2 核心组件

1. **推送服务网关**：处理设备注册、维护连接、调度推送任务
2. **消息队列**：RabbitMQ/Kafka，解耦业务逻辑和推送
3. **存储服务**：设备信息存储、推送历史记录
4. **多平台适配层**：统一接口，支持不同平台的推送通道

```java
@Service
@Slf4j
public class PushNotificationService {
    
    @Autowired
    private DeviceRepository deviceRepository;
    @Autowired
    private MessageQueueService messageQueueService;
    @Autowired
    private PushHistoryService pushHistoryService;
    @Autowired
    private PlatformPushAdapter platformPushAdapter;
    
    /**
     * 发送推送通知给单个用户
     * @param userId 用户ID
     * @param notification 通知内容
     * @return 推送结果
     */
    public PushResult sendPushToUser(Long userId, Notification notification) {
        try {
            // 1. 获取用户所有活跃设备
            List<Device> devices = deviceRepository.findActiveByUserId(userId);
            
            if (CollectionUtils.isEmpty(devices)) {
                log.warn("用户{}没有活跃设备", userId);
                return PushResult.failure("没有活跃设备");
            }
            
            // 2. 创建推送历史记录
            PushHistory history = PushHistory.builder()
                .userId(userId)
                .messageId(notification.getMessageId())
                .pushType(notification.getType())
                .title(notification.getTitle())
                .content(notification.getContent())
                .extraData(notification.getExtraData())
                .status(PushStatus.PENDING)
                .build();
            
            pushHistoryService.save(history);
            
            // 3. 为每个设备创建推送任务
            List<CompletableFuture<DevicePushResult>> futures = new ArrayList<>();
            for (Device device : devices) {
                CompletableFuture<DevicePushResult> future = CompletableFuture.supplyAsync(() -> {
                    return sendPushToDevice(device, notification, history.getId());
                });
                futures.add(future);
            }
            
            // 4. 等待所有推送完成
            CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
            
            // 5. 统计推送结果
            List<DevicePushResult> results = futures.stream()
                .map(CompletableFuture::join)
                .collect(Collectors.toList());
            
            boolean allSuccess = results.stream().allMatch(DevicePushResult::isSuccess);
            
            // 6. 更新推送历史状态
            if (allSuccess) {
                history.setStatus(PushStatus.SENT);
                history.setSentAt(LocalDateTime.now());
                pushHistoryService.update(history);
            }
            
            return PushResult.success(results);
            
        } catch (Exception e) {
            log.error("发送推送失败，用户ID: {}", userId, e);
            return PushResult.failure(e.getMessage());
        }
    }
    
    /**
     * 发送推送给特定设备
     */
    private DevicePushResult sendPushToDevice(Device device, Notification notification, Long historyId) {
        try {
            // 使用平台适配器发送推送
            PushResponse response = platformPushAdapter.send(device, notification);
            
            // 更新设备推送时间
            device.setLastPushAt(LocalDateTime.now());
            deviceRepository.save(device);
            
            if (response.isSuccess()) {
                return DevicePushResult.success(device.getId(), response.getMessageId());
            } else {
                log.error("设备{}推送失败: {}", device.getId(), response.getErrorMessage());
                
                // 失败重试逻辑
                if (shouldRetry(device, response)) {
                    retryPush(device, notification, historyId, 1);
                }
                
                return DevicePushResult.failure(device.getId(), response.getErrorMessage());
            }
            
        } catch (Exception e) {
            log.error("设备{}推送异常", device.getId(), e);
            return DevicePushResult.failure(device.getId(), e.getMessage());
        }
    }
    
    /**
     * 批量发送推送
     */
    public BatchPushResult sendBatchPush(List<Long> userIds, Notification notification) {
        List<CompletableFuture<PushResult>> futures = userIds.stream()
            .map(userId -> CompletableFuture.supplyAsync(() -> sendPushToUser(userId, notification)))
            .collect(Collectors.toList());
        
        // 等待所有完成
        CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
        
        List<PushResult> results = futures.stream()
            .map(CompletableFuture::join)
            .collect(Collectors.toList());
        
        return new BatchPushResult(results);
    }
}
```

```java
                .build())
```

```java
@Service
public class DeviceRegistrationService {

    private DeviceRepository deviceRepository;
    @Autowired

    public Device registerDevice(Long userId, DeviceRegistrationRequest request) {
        // 1. 检查设备是否已注册
        Device existingDevice = deviceRepository
            .findByUserIdAndDeviceToken(userId, request.getDeviceToken());
        
        if (existingDevice != null) {
            // 更新已有设备信息
            return updateDevice(existingDevice, request);
        }
        
        // 2. 创建新设备记录
        Device device = Device.builder()
            .userId(userId)
            .deviceToken(request.getDeviceToken())
            .platform(request.getPlatform())
            .appVersion(request.getAppVersion())
            .osVersion(request.getOsVersion())
            .deviceModel(request.getDeviceModel())
            .pushChannel(request.getPushChannel())
            .isActive(true)
            .build();
        
        // 3. 保存到数据库
        Device savedDevice = deviceRepository.save(device);
        
        // 4. 缓存设备信息
        cacheDevice(savedDevice);
        
        // 5. 发送设备上线事件
        sendDeviceOnlineEvent(savedDevice);
        
        return savedDevice;
    }
    
    /**
     * 更新设备信息
     */
    private Device updateDevice(Device device, DeviceRegistrationRequest request) {
        device.setAppVersion(request.getAppVersion());
        device.setOsVersion(request.getOsVersion());
        device.setDeviceModel(request.getDeviceModel());
        device.setPushChannel(request.getPushChannel());
        device.setIsActive(true);
        device.setUpdatedAt(LocalDateTime.now());
        
        Device updatedDevice = deviceRepository.save(device);
        
        // 更新缓存
        cacheDevice(updatedDevice);
        
        return updatedDevice;
    }
    
    /**
     * 设备上线时处理
     */
    @EventListener
    @Async
    public void handleDeviceOnline(DeviceOnlineEvent event) {
        Device device = event.getDevice();
        
        // 1. 更新设备最后上线时间
        device.setLastOnlineAt(LocalDateTime.now());
        deviceRepository.save(device);
        
        // 2. 检查是否有未推送的消息
        List<PushHistory> pendingPushes = pushHistoryService
            .findPendingByUserId(device.getUserId());
        
        if (!pendingPushes.isEmpty()) {
            // 3. 推送未送达的消息
            pendingPushes.forEach(push -> {
                Notification notification = Notification.builder()
                    .messageId(push.getMessageId())
                    .title(push.getTitle())
                    .content(push.getContent())
                    .extraData(push.getExtraData())
                    .build();
                
                pushNotificationService.sendPushToDevice(device, notification, push.getId());
            });
        }
        
        // 4. 推送离线期间的新消息摘要
        sendOfflineMessageSummary(device);
    }

        device.setIsOnline(false);
```

```java
            log.info("推送消息处理完成: {}", pushMessage.getMessageId());

        }

    /**
     * 处理单用户推送
     */
    private void handleSingleUserPush(PushMessage pushMessage) {
        Long userId = pushMessage.getUserId();
        Notification notification = pushMessage.getNotification();
        
        PushResult result = pushNotificationService.sendPushToUser(userId, notification);
        
        if (!result.isSuccess()) {
            log.error("用户{}推送失败: {}", userId, result.getErrorMessage());
            // 记录失败日志，可能需要告警
            recordPushFailure(userId, notification, result.getErrorMessage());
        }
    }
    
    /**
     * 处理批量用户推送
     */
    private void handleBatchUserPush(PushMessage pushMessage) {
        List<Long> userIds = pushMessage.getUserIds();
        Notification notification = pushMessage.getNotification();
        
        BatchPushResult result = pushNotificationService.sendBatchPush(userIds, notification);
        
        log.info("批量推送完成，成功: {}, 失败: {}", 
            result.getSuccessCount(), result.getFailureCount());
    }
    
    /**
     * 处理广播推送
     */
    private void handleBroadcastPush(PushMessage pushMessage) {
        Notification notification = pushMessage.getNotification();
        
        // 获取所有活跃用户ID
        List<Long> activeUserIds = deviceRepository.findActiveUserIds();
        
        // 分页处理，避免一次性加载过多数据
        int pageSize = 1000;
        int totalPages = (int) Math.ceil((double) activeUserIds.size() / pageSize);
        
        for (int page = 0; page < totalPages; page++) {
            int start = page * pageSize;
            int end = Math.min(start + pageSize, activeUserIds.size());
            List<Long> pageUserIds = activeUserIds.subList(start, end);
            
            BatchPushResult result = pushNotificationService.sendBatchPush(pageUserIds, notification);
            
            log.info("广播推送进度: {}/{}, 成功: {}, 失败: {}", 
                page + 1, totalPages, result.getSuccessCount(), result.getFailureCount());
            
            // 添加延迟，避免对推送服务造成过大压力
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                log.warn("广播推送被中断");
                break;
            }
        }
    }
```

```java
@Service
public class PushRateLimiter {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    private static final String RATE_LIMIT_KEY = "push_rate_limit:user:%s";
    private static final String DEDUP_KEY = "push_dedup:user:%s:message:%s";
    
    // 每个用户每小时最大推送次数
    private static final int MAX_PUSH_PER_HOUR = 100;
    
    /**
     * 检查是否超过推送限制
     */
    public boolean isRateLimited(Long userId) {
        String key = String.format(RATE_LIMIT_KEY, userId);
        String count = redisTemplate.opsForValue().get(key);
        
        if (count == null) {
            return false;
        }
        
        return Integer.parseInt(count) >= MAX_PUSH_PER_HOUR;
    }
    
    /**
     * 增加推送计数
     */
    public void incrementPushCount(Long userId) {
        String key = String.format(RATE_LIMIT_KEY, userId);
        redisTemplate.opsForValue().increment(key);
        redisTemplate.expire(key, 1, TimeUnit.HOURS);
    }
    
    /**
     * 检查消息是否已发送（去重）
     */
    public boolean isDuplicate(Long userId, String messageId) {
        String key = String.format(DEDUP_KEY, userId, messageId);
        Boolean exists = redisTemplate.hasKey(key);
        
        if (Boolean.TRUE.equals(exists)) {
            return true;
        }
        
        // 设置去重标记，有效期24小时
        redisTemplate.opsForValue().set(key, "1", 24, TimeUnit.HOURS);
        return false;
    }
}
```

```java
@Service
@Slf4j
public class PushRetryService {
    
    @Autowired
    private PushNotificationService pushNotificationService;
    @Autowired
    private PushHistoryService pushHistoryService;
    
    // 最大重试次数
    private static final int MAX_RETRY_COUNT = 3;
    
    // 重试延迟（秒）
    private static final int[] RETRY_DELAYS = {5, 30, 300};
    
    /**
     * 重试失败的推送
     */
    @Scheduled(fixedDelay = 60000) // 每分钟检查一次
    public void retryFailedPushes() {
        List<PushHistory> failedPushes = pushHistoryService
            .findFailedForRetry(MAX_RETRY_COUNT);
        
        if (CollectionUtils.isEmpty(failedPushes)) {
            return;
        }
        
        log.info("开始重试{}条失败推送", failedPushes.size());
        
        for (PushHistory history : failedPushes) {
            retryPush(history);
        }
    }
    
    /**
     * 重试单个推送
     */
    @Async
    public void retryPush(PushHistory history) {
        try {
            // 检查是否超过最大重试次数
            if (history.getRetryCount() >= MAX_RETRY_COUNT) {
                history.setStatus(PushStatus.FAILED);
                pushHistoryService.update(history);
                log.warn("推送{}达到最大重试次数，标记为失败", history.getId());
                return;
            }
            
            // 计算重试延迟
            int delay = RETRY_DELAYS[history.getRetryCount()];
            
            log.info("将在{}秒后重试推送{}", delay, history.getId());
            
            // 延迟执行
            Thread.sleep(delay * 1000);
            
            // 获取设备信息重新发送
            Device device = deviceRepository.findById(history.getDeviceId()).orElse(null);
            
            if (device == null || !device.getIsActive()) {
                history.setStatus(PushStatus.FAILED);
                history.setErrorMessage("设备不存在或已停用");
                pushHistoryService.update(history);
                return;
            }
            
            // 重新构建通知
            Notification notification = Notification.builder()
                .messageId(history.getMessageId())
                .title(history.getTitle())
                .content(history.getContent())
                .extraData(history.getExtraData())
                .build();
            
            // 重新发送
            DevicePushResult result = pushNotificationService
                .sendPushToDevice(device, notification, history.getId());
            
            // 更新重试次数
            history.setRetryCount(history.getRetryCount() + 1);
            
            if (result.isSuccess()) {
                history.setStatus(PushStatus.SENT);
                history.setSentAt(LocalDateTime.now());
                history.setErrorMessage(null);
            } else {
                history.setErrorMessage(result.getErrorMessage());
            }
            
            pushHistoryService.update(history);
            
        } catch (Exception e) {
            log.error("重试推送{}失败", history.getId(), e);
            history.setErrorMessage(e.getMessage());
            pushHistoryService.update(history);
        }
    }
}
```

```python
"""
文件传输协议定义
"""
from enum import Enum
from dataclasses import dataclass
from typing import Optional
import hashlib
import uuid

class FileType(Enum):
    """文件类型枚举"""
    IMAGE = "image"
    DOCUMENT = "document"
    VIDEO = "video"
    AUDIO = "audio"
    ARCHIVE = "archive"
    OTHER = "other"

@dataclass
class FileMetadata:
    """文件元数据"""
    file_id: str
    file_name: str
    file_size: int
    file_type: FileType
    chunk_size: int = 1024 * 1024  # 1MB
    total_chunks: int = 0
    checksum: Optional[str] = None
    
    def __post_init__(self):
        if self.total_chunks == 0:
            self.total_chunks = (self.file_size + self.chunk_size - 1) // self.chunk_size

@dataclass
class FileChunk:
    """文件块"""
    file_id: str
    chunk_index: int
    data: bytes
    checksum: str

class FileTransferProtocol:
    """文件传输协议处理器"""
    
    @staticmethod
    def create_file_metadata(file_path: str, sender_id: str, receiver_id: str) -> FileMetadata:
        """创建文件元数据"""
        import os
        
        file_id = f"{uuid.uuid4()}"
        file_name = os.path.basename(file_path)
        file_size = os.path.getsize(file_path)
        
        # 根据扩展名判断文件类型
        file_ext = os.path.splitext(file_name)[1].lower()
        file_type = FileType.OTHER
        
        type_map = {
            '.jpg': FileType.IMAGE, '.jpeg': FileType.IMAGE, '.png': FileType.IMAGE,
            '.gif': FileType.IMAGE, '.bmp': FileType.IMAGE, '.webp': FileType.IMAGE,
            '.pdf': FileType.DOCUMENT, '.doc': FileType.DOCUMENT, '.docx': FileType.DOCUMENT,
            '.txt': FileType.DOCUMENT, '.rtf': FileType.DOCUMENT,
            '.mp4': FileType.VIDEO, '.avi': FileType.VIDEO, '.mkv': FileType.VIDEO,
            '.mov': FileType.VIDEO, '.wmv': FileType.VIDEO,
            '.mp3': FileType.AUDIO, '.wav': FileType.AUDIO, '.flac': FileType.AUDIO,
            '.zip': FileType.ARCHIVE, '.rar': FileType.ARCHIVE, '.7z': FileType.ARCHIVE,
        }
        
        file_type = type_map.get(file_ext, FileType.OTHER)
        
        return FileMetadata(
            file_id=file_id,
            file_name=file_name,
            file_size=file_size,
            file_type=file_type
        )
    
    @staticmethod
    def calculate_chunk_checksum(chunk_data: bytes) -> str:
        """计算文件块校验和"""
        return hashlib.md5(chunk_data).hexdigest()
    
    @staticmethod
    def calculate_file_checksum(file_path: str) -> str:
        """计算整个文件的校验和"""
        sha256_hash = hashlib.sha256()
        with open(file_path, "rb") as f:
            for chunk in iter(lambda: f.read(4096), b""):
                sha256_hash.update(chunk)
        return sha256_hash.hexdigest()
```

```python
"""

处理文件传输的完整流程

import asyncio
import aiofiles
import logging
from typing import Dict, Callable, Optional
from datetime import datetime

class FileTransferManager:
    """文件传输管理器"""
    
    def __init__(self, storage_path: str = "./file_storage"):
        self.storage_path = storage_path
        self.active_transfers: Dict[str, Dict] = {}
        self.logger = logging.getLogger(__name__)
        
        # 创建存储目录
        import os
        os.makedirs(storage_path, exist_ok=True)
    
    async def initiate_transfer(
        self,
        file_path: str,
        sender_id: str,
        receiver_id: str,
        progress_callback: Optional[Callable] = None
    ) -> str:
        """初始化文件传输"""
        try:
            # 创建文件元数据
            metadata = FileTransferProtocol.create_file_metadata(
                file_path, sender_id, receiver_id
            )
            
            # 存储传输信息
            transfer_id = metadata.file_id
            self.active_transfers[transfer_id] = {
                "metadata": metadata,
                "sender_id": sender_id,
                "receiver_id": receiver_id,
                "status": "pending",
                "progress": 0,
                "started_at": datetime.now(),
                "file_path": file_path,
                "progress_callback": progress_callback
            }
            
            self.logger.info(f"文件传输已初始化: {transfer_id}")
            return transfer_id
            
        except Exception as e:
            self.logger.error(f"初始化文件传输失败: {e}")
            raise
    
    async def send_file(self, transfer_id: str, send_chunk_func: Callable) -> bool:
        """发送文件"""
        if transfer_id not in self.active_transfers:
            raise ValueError(f"传输 {transfer_id} 不存在")
        
        transfer = self.active_transfers[transfer_id]
        metadata = transfer["metadata"]
        file_path = transfer["file_path"]
        
        try:
            async with aiofiles.open(file_path, 'rb') as f:
                for chunk_index in range(metadata.total_chunks):
                    # 读取文件块
                    chunk_data = await f.read(metadata.chunk_size)
                    
                    # 计算校验和
                    checksum = FileTransferProtocol.calculate_chunk_checksum(chunk_data)
                    
                    # 创建文件块对象
                    chunk = FileChunk(
                        file_id=transfer_id,
                        chunk_index=chunk_index,
                        data=chunk_data,
                        checksum=checksum
                    )
                    
                    # 发送文件块
                    success = await send_chunk_func(chunk)
                    
                    if not success:
                        raise Exception(f"发送文件块 {chunk_index} 失败")
                    
                    # 更新进度
                    progress = (chunk_index + 1) / metadata.total_chunks * 100
                    transfer["progress"] = progress
                    
                    # 调用进度回调
                    if transfer.get("progress_callback"):
                        transfer["progress_callback"](progress)
                    
                    # 模拟网络延迟
                    await asyncio.sleep(0.01)
            
            # 更新状态
            transfer["status"] = "completed"
            transfer["completed_at"] = datetime.now()
            
            self.logger.info(f"文件传输完成: {transfer_id}")
            return True
            
        except Exception as e:
            transfer["status"] = "failed"
            self.logger.error(f"文件传输失败: {e}")
            return False
    
    async def receive_chunk(self, chunk: FileChunk, receiver_callback: Callable) -> bool:
        """接收文件块"""
        try:
            # 验证校验和
            expected_checksum = FileTransferProtocol.calculate_chunk_checksum(chunk.data)
            if expected_checksum != chunk.checksum:
                raise Exception(f"文件块校验和不匹配")
            
            # 接收文件块
            success = await receiver_callback(chunk)
            
            if success:
                self.logger.info(f"接收文件块 {chunk.chunk_index} 成功")
            else:
                self.logger.error(f"接收文件块 {chunk.chunk_index} 失败")
            
            return success
            
        except Exception as e:
            self.logger.error(f"接收文件块失败: {e}")
            return False
    
    async def complete_transfer(self, transfer_id: str, received_chunks: Dict[int, bytes]) -> bool:
        """完成文件传输，组装文件"""
        if transfer_id not in self.active_transfers:
            raise ValueError(f"传输 {transfer_id} 不存在")
        
        transfer = self.active_transfers[transfer_id]
        metadata = transfer["metadata"]
        
        try:
            # 组装文件
            output_path = f"{self.storage_path}/{metadata.file_name}"
            
            async with aiofiles.open(output_path, 'wb') as f:
                for chunk_index in range(metadata.total_chunks):
                    if chunk_index not in received_chunks:
                        raise Exception(f"缺少文件块 {chunk_index}")
                    
                    await f.write(received_chunks[chunk_index])
            
            # 验证文件完整性
            file_checksum = FileTransferProtocol.calculate_file_checksum(output_path)
            if metadata.checksum and file_checksum != metadata.checksum:
                raise Exception("文件校验和不匹配")
            
            # 更新状态
            transfer["status"] = "completed"
            transfer["output_path"] = output_path
            
            self.logger.info(f"文件组装完成: {output_path}")
            return True
            
        except Exception as e:
            self.logger.error(f"文件组装失败: {e}")
            return False
    
    def get_transfer_status(self, transfer_id: str) -> Dict:
        """获取传输状态"""
        if transfer_id not in self.active_transfers:
            return {"status": "not_found"}
        
        transfer = self.active_transfers[transfer_id]
        return {
            "transfer_id": transfer_id,
            "status": transfer["status"],
            "progress": transfer["progress"],
            "metadata": transfer["metadata"],
            "started_at": transfer["started_at"].isoformat()
```

```python
    async def handle_client(self, websocket, path):
        """处理客户端连接"""
        client_id = None
        try:
            # 接收注册消息
            async for message in websocket:
                data = json.loads(message)
                
                if data["type"] == "register":
                    client_id = data["client_id"]
                    self.clients[client_id] = websocket
                    self.logger.info(f"客户端注册: {client_id}")
                    
                    # 发送注册确认
                    await websocket.send(json.dumps({
                        "type": "register_ack",
                        "status": "success"
                    }))
                
                elif data["type"] == "send_file":
                    # 处理文件发送请求
                    await self.handle_send_file(websocket, client_id, data)
                
                elif data["type"] == "accept_file":
                    # 处理文件接受请求
                    await self.handle_accept_file(websocket, client_id, data)
                
                elif data["type"] == "file_chunk":
                    # 处理文件块传输
                    await self.handle_file_chunk(websocket, client_id, data)
                
                elif data["type"] == "transfer_complete":
                    # 处理传输完成
                    await self.handle_transfer_complete(websocket, client_id, data)
        
        except websockets.exceptions.ConnectionClosed:
            self.logger.info(f"客户端断开连接: {client_id}")
        except Exception as e:
            self.logger.error(f"处理客户端错误: {e}")
        finally:
            if client_id and client_id in self.clients:
                del self.clients[client_id]

        """处理文件发送请求"""
        try:
            receiver_id = data["receiver_id"]
            file_path = data["file_path"]
            
            # 初始化传输
            transfer_id = await self.file_manager.initiate_transfer(
                file_path, sender_id, receiver_id
            )
            
            # 通知发送方
            await websocket.send(json.dumps({
                "type": "transfer_initiated",
                "transfer_id": transfer_id,
                "status": "pending"
            }))
            
            # 通知接收方
            if receiver_id in self.clients:
                metadata = self.file_manager.active_transfers[transfer_id]["metadata"]
                await self.clients[receiver_id].send(json.dumps({
                    "type": "file_request",
                    "transfer_id": transfer_id,
                    "sender_id": sender_id,
                    "metadata": asdict(metadata)
                }))
            
        except Exception as e:
            await websocket.send(json.dumps({

                raise ValueError("传输不存在")
            
            sender_id = transfer_info["sender_id"]

                await self.clients[sender_id].send(json.dumps({
                    "type": "file_accepted",
                    "transfer_id": transfer_id,

                }))
            
            # 开始传输
            await self.file_manager.send_file(
                transfer_id,
                lambda chunk: self.send_file_chunk(sender_id, receiver_id, chunk)
            )
            
        except Exception as e:
            await websocket.send(json.dumps({
                "type": "error",
```

### 3.3 Elasticsearch 客户端封装
```python
# elasticsearch_client.py
import logging
from typing import Dict, Any, List, Optional
from datetime import datetime
from elasticsearch import Elasticsearch, helpers
from elasticsearch.exceptions import ConnectionError, RequestError

from config import SearchConfig
from models import MessageIndex, SearchRequest, SearchResult

logger = logging.getLogger(__name__)

class ElasticsearchClient:
    """Elasticsearch客户端封装"""
    
    def __init__(self, config: SearchConfig):
        self.config = config
        self.es = self._create_connection()
        
    def _create_connection(self) -> Elasticsearch:
        """创建ES连接"""
        try:
            es = Elasticsearch(
                hosts=self.config.ES_HOSTS,
                timeout=self.config.ES_TIMEOUT,
                max_retries=3,
                retry_on_timeout=True
            )
            # 测试连接
            if not es.ping():
                raise ConnectionError("无法连接到Elasticsearch")
            logger.info("成功连接到Elasticsearch")
            return es
        except Exception as e:
            logger.error(f"创建ES连接失败: {e}")
            raise
    
    async def create_index_if_not_exists(self) -> bool:
        """创建索引（如果不存在）"""
        try:
            if not self.es.indices.exists(index=self.config.ES_INDEX):
                # 这里可以加载完整的索引配置
                index_config = self._get_index_config()
                self.es.indices.create(
                    index=self.config.ES_INDEX,
                    body=index_config
                )
                logger.info(f"创建索引 {self.config.ES_INDEX}")
            return True
        except Exception as e:
            logger.error(f"创建索引失败: {e}")
            return False
    
    def _get_index_config(self) -> Dict[str, Any]:
        """获取索引配置"""
        return {
            "settings": {
                "number_of_shards": 3,
                "number_of_replicas": 1,
                "analysis": {
                    "analyzer": {
                        "message_analyzer": {
                            "type": "custom",
                            "tokenizer": "ik_max_word",
                            "filter": ["lowercase", "trim"]
                        }
                    }
                }
            },
            "mappings": {
                "properties": {
                    "message_id": {"type": "keyword"},
                    "conversation_id": {"type": "keyword"},
                    "sender_id": {"type": "keyword"},
                    "content": {
                        "type": "text",
                        "analyzer": "message_analyzer",
                        "search_analyzer": "ik_smart"
                    },
                    "message_type": {"type": "keyword"},
                    "created_at": {
                        "type": "date",
                        "format": "yyyy-MM-dd HH:mm:ss||yyyy-MM-dd||epoch_millis"
                    },
                    "permissions": {"type": "keyword"}
                }
            }
        }
    
    async def index_message(self, message: MessageIndex) -> bool:
        """索引单条消息"""
        try:
            doc = {
                "message_id": message.message_id,
                "conversation_id": message.conversation_id,
                "sender_id": message.sender_id,
                "content": message.content,
                "message_type": message.message_type.value,
                "media_url": message.media_url,
                "created_at": message.created_at.isoformat(),
                "permissions": message.permissions
            }
            
            response = self.es.index(
                index=self.config.ES_INDEX,
                id=message.message_id,
                body=doc
            )
            
            return response['result'] in ['created', 'updated']
        except Exception as e:
            logger.error(f"索引消息失败: {e}")
            return False
    
    async def bulk_index_messages(self, messages: List[MessageIndex]) -> int:
        """批量索引消息"""
        try:
            actions = []
            for message in messages:
                action = {
                    "_index": self.config.ES_INDEX,
                    "_id": message.message_id,
                    "_source": {
                        "message_id": message.message_id,
                        "conversation_id": message.conversation_id,
                        "sender_id": message.sender_id,
                        "content": message.content,
                        "message_type": message.message_type.value,
                        "media_url": message.media_url,
                        "created_at": message.created_at.isoformat(),
                        "permissions": message.permissions
                    }
                }
                actions.append(action)
            
            success, failed = helpers.bulk(self.es, actions, stats_only=True)
            logger.info(f"批量索引完成: 成功 {success}, 失败 {failed}")
            return success
        except Exception as e:
            logger.error(f"批量索引失败: {e}")
            return 0
    
    async def search_messages(
        self, 
        request: SearchRequest, 
        user_id: int
    ) -> Dict[str, Any]:
        """搜索消息"""
        try:
            # 构建基础查询
            must_conditions = []
            filter_conditions = []
            
            # 权限过滤（用户只能看到自己有权查看的消息）
            filter_conditions.append({
                "term": {"permissions": user_id}
            })
            
            # 关键词搜索
            if request.keyword:
                must_conditions.append({
                    "multi_match": {
                        "query": request.keyword,
                        "fields": ["content"],
                        "type": "best_fields",
                        "fuzziness": "AUTO",
                        "prefix_length": 2
                    }
                })
            
            # 会话过滤
            if request.conversation_id:
                filter_conditions.append({
                    "term": {"conversation_id": request.conversation_id}
                })
            
            # 发送者过滤
            if request.sender_id:
                filter_conditions.append({
                    "term": {"sender_id": request.sender_id}
                })
            
            # 消息类型过滤
            if request.message_type:
                filter_conditions.append({
                    "term": {"message_type": request.message_type.value}
                })
            
            # 时间范围过滤
            time_range = {}
            if request.start_time:
                time_range["gte"] = request.start_time.isoformat()
            if request.end_time:
                time_range["lte"] = request.end_time.isoformat()
            
            if time_range:
                filter_conditions.append({
                    "range": {"created_at": time_range}
                })
            
            # 构建查询体
            query = {
                "bool": {
                    "must": must_conditions if must_conditions else [{"match_all": {}}],
                    "filter": filter_conditions
                }
            }
            
            # 排序
            sort = []
            if request.sort_by == "relevance" and request.keyword:
                sort.append("_score")
            sort.append({
                "created_at": {"order": request.sort_order.value}
            })
            
            # 高亮配置
            highlight = {}
            if request.highlight and request.keyword:
                highlight = {
                    "fields": {
                        "content": {
                            "pre_tags": ["<em>"],
                            "post_tags": ["</em>"]
                        }
                    },
                    "fragment_size": 150,
                    "number_of_fragments": 3
                }
            
            # 分页参数
            from_val = (request.page - 1) * request.page_size
            
            # 执行查询
            search_body = {
                "query": query,
                "sort": sort,
                "from": from_val,
                "size": request.page_size,
                "highlight": highlight,
                "_source": ["message_id", "conversation_id", "sender_id", 
                           "content", "message_type", "media_url", "created_at"]
            }
            
            response = self.es.search(
                index=self.config.ES_INDEX,
                body=search_body,
                timeout=f"{self.config.ES_TIMEOUT}s"
            )
            
            # 解析结果
            results = []
            for hit in response['hits']['hits']:
                source = hit['_source']
                highlight_content = None
                
                # 提取高亮内容
                if 'highlight' in hit and 'content' in hit['highlight']:
                    highlight_content = ' '.join(hit['highlight']['content'])
                
                result = SearchResult(
                    message_id=source['message_id'],
                    conversation_id=source['conversation_id'],
                    sender_id=source['sender_id'],
                    content=source['content'],
                    message_type=MessageType(source['message_type']),
                    media_url=source.get('media_url'),
                    created_at=datetime.fromisoformat(source['created_at']),
                    highlight_content=highlight_content,
                    score=hit.get('_score', 0.0)
                )
                results.append(result)
            
            return {
                "total": response['hits']['total']['value'],
                "results": results,
                "max_score": response['hits']['max_score']
            }
            
        except RequestError as e:
            logger.error(f"搜索请求错误: {e}")
            # 返回空结果而不是抛出异常
            return {
                "total": 0,
                "results": [],
                "max_score": 0
            }
        except Exception as e:
            logger.error(f"搜索失败: {e}")
            raise
    
    async def delete_message(self, message_id: int) -> bool:
        """删除消息索引"""
        try:

        except Exception as e:

            return []
```

```python
# search_service.py
import json
import time
import hashlib
import logging
from datetime import datetime, timedelta
from typing import Optional, List, Dict, Any
import asyncio
import redis.asyncio as redis
from redis.exceptions import RedisError

from config import SearchConfig
from models import SearchRequest, SearchResponse, SearchResult
from elasticsearch_client import ElasticsearchClient
from database_client import DatabaseClient

logger = logging.getLogger(__name__)

class SearchService:
    """消息搜索服务"""
    
    def __init__(self, config: SearchConfig):
        self.config = config
        self.es_client = ElasticsearchClient(config)
        self.db_client = DatabaseClient(config)
        self.redis_client: Optional[redis.Redis] = None
        self._initialized = False
    
    async def initialize(self) -> bool:
        """初始化服务"""
        try:
            # 初始化ES连接
            await self.es_client.create_index_if_not_exists()
            
            # 初始化Redis连接
            self.redis_client = redis.Redis(
                host=self.config.REDIS_HOST,
                port=self.config.REDIS_PORT,
                db=self.config.REDIS_DB,
                decode_responses=True
            )
            
            # 测试连接
            await self.redis_client.ping()
            logger.info("搜索服务初始化完成")
            
            self._initialized = True
            return True
        except Exception as e:
            logger.error(f"搜索服务初始化失败: {e}")
            return False
    
    async def search_messages(
        self, 
        request: SearchRequest, 
        user_id: int
    ) -> SearchResponse:
        """搜索消息"""
        if not self._initialized:
            raise RuntimeError("搜索服务未初始化")
        
        start_time = time.time()
        
        try:
            # 生成缓存键
            cache_key = self._generate_cache_key(request, user_id)
            
            # 尝试从缓存获取
            cached_result = await self._get_from_cache(cache_key)
            if cached_result:
                search_time_ms = (time.time() - start_time) * 1000
                cached_result.search_time_ms = search_time_ms
                cached_result.from_cache = True
                return cached_result
            
            # 执行搜索
            es_result = await self.es_client.search_messages(request, user_id)
            
            # 计算分页信息
            total = es_result["total"]
            total_pages = (total + request.page_size - 1) // request.page_size
            
            # 构建响应
            response = SearchResponse(
                success=True,
                total=total,
                page=request.page,
                page_size=request.page_size,
                total_pages=total_pages,
                results=es_result["results"],
                search_time_ms=(time.time() - start_time) * 1000,
                from_cache=False
            )
            
            # 缓存结果
            await self._set_to_cache(cache_key, response)
            
            return response
            
        except Exception as e:
            logger.error(f"搜索消息失败: {e}")
            # 返回空结果
            return SearchResponse(
                success=False,
                total=0,
                page=request.page,
                page_size=request.page_size,
                total_pages=0,
                results=[],
                search_time_ms=(time.time() - start_time) * 1000
            )
    
    async def get_search_suggestions(
        self, 
        keyword: str, 
        user_id: int, 
        size: int = 5
    ) -> List[str]:
        """获取搜索建议"""
        try:
            # 这里可以结合ES的suggest功能实现
            # 简单实现：返回包含关键词的最近消息内容片段
            if not keyword or len(keyword) < 2:
                return []
            
            # 构建一个简单的搜索请求
            request = SearchRequest(
                keyword=keyword,
                page=1,
                page_size=size,
                highlight=False
            )
            
            result = await self.search_messages(request, user_id)
            
            # 提取建议内容
            suggestions = []
            for item in result.results:
                # 截取包含关键词的内容片段
                content = item.content
                if keyword.lower() in content.lower():
                    # 找到关键词位置，截取周围内容
                    idx = content.lower().find(keyword.lower())
                    start = max(0, idx - 20)
                    end = min(len(content), idx + len(keyword) + 20)
                    snippet = content[start:end]
                    if snippet not in suggestions:
                        suggestions.append(snippet)
            
            return suggestions[:size]
        except Exception as e:
            logger.error(f"获取搜索建议失败: {e}")
            return []
    
    async def index_new_message(self, message_data: Dict[str, Any]) -> bool:
        """索引新消息"""
        try:
            # 转换为索引模型
            from models import MessageIndex, MessageType
            
            message = MessageIndex(
                message_id=message_data["id"],
                conversation_id=message_data["conversation_id"],
                sender_id=message_data["sender_id"],
                content=message_data["content"],
                message_type=MessageType(message_data.get("message_type", "text")),
                media_url=message_data.get("media_url"),
                created_at=message_data["created_at"],
                updated_at=message_data.get("updated_at", message_data["created_at"]),
                permissions=message_data.get("permissions", [])
            )
            
            # 索引到ES
            success = await self.es_client.index_message(message)
            
            if success:
                logger.info(f"消息 {message_data['id']} 索引成功")
                # 清除相关缓存
                await self._invalidate_cache(message.conversation_id)
            
            return success
        except Exception as e:
            logger.error(f"索引新消息失败: {e}")
            return False
    
    async def reindex_conversation(self, conversation_id: int) -> bool:
        """重新索引整个会话的消息"""
        try:
            # 从数据库获取会话的所有消息
            messages = await self.db_client.get_conversation_messages(conversation_id)
            
            if not messages:
                logger.warning(f"会话 {conversation_id} 没有消息")
                return True
            
            # 批量索引
            success_count = await self.es_client.bulk_index_messages(messages)
            
            # 清除缓存
            await self._invalidate_cache(conversation_id)
            
            logger.info(f"会话 {conversation_id} 重新索引完成: {success_count} 条消息")
            return success_count > 0
        except Exception as e:
            logger.error(f"重新索引会话失败: {e}")
            return False
    
    def _generate_cache_key(self, request: SearchRequest, user_id: int) -> str:
        """生成缓存键"""
        # 将请求参数序列化为字符串
        request_dict = request.dict()
        request_dict["user_id"] = user_id
        
        # 排序以确保相同参数生成相同键
        sorted_dict = sorted(request_dict.items())
        key_str = json.dumps(sorted_dict, sort_keys=True, default=str)
        
        # 生成MD5哈希
        return f"search:{hashlib.md5(key_str.encode()).hexdigest()}"
    
    async def _get_from_cache(self, cache_key: str) -> Optional[SearchResponse]:
        """从缓存获取结果"""
        if not self.redis_client:
            return None
        
        try:
            cached = await self.redis_client.get(cache_key)
            if cached:
                return SearchResponse.parse_raw(cached)
        except RedisError as e:
            logger.warning(f"从缓存获取失败: {e}")
        
        return None
    
    async def _set_to_cache(self, cache_key: str, response: SearchResponse) -> bool:
        """设置缓存"""
        if not self.redis_client:
            return False
        
        try:
            await self.redis_client.setex(
                cache_key,
                self.config.SEARCH_CACHE_TTL,
                response.json()
            )
            return True
        except RedisError as e:
            logger.warning(f"设置缓存失败: {e}")
            return False
    
    async def _invalidate_cache(self, conversation_id: Optional[int] = None) -> None:
        """清除相关缓存"""
        if not self.redis_client:
            return
        
        try:
            if conversation_id:
                # 清除特定会话的缓存
                pattern = f"search:*conversation_id*{conversation_id}*"
                keys = []
                async for key in self.redis_client.scan_iter(match=pattern):
                    keys.append(key)
                
                if keys:
                    await self.redis_client.delete(*keys)
                    logger.info(f"清除会话 {conversation_id} 的 {len(keys)} 个缓存")
```

本方案实现了一个即时通讯系统的核心功能——消息路由与存储，采用客户端-服务器架构。系统支持用户在线/离线状态管理、实时消息转发、离线消息存储、历史消息查询等功能。设计上注重可靠性、可扩展性和安全性。

```python
import asyncio
from typing import Dict, List, Optional
from datetime import datetime
from .models import Message, User
from .storage import MessageStorage, UserStorage
from .connection_manager import ConnectionManager

class MessageRouter:
    """消息路由器，负责消息的转发和存储"""
    
    def __init__(self):
        self.connection_manager = ConnectionManager()
        self.message_storage = MessageStorage()
        self.user_storage = UserStorage()
        
        # 消息处理队列
        self.message_queue = asyncio.Queue()
        
        # 启动消息处理循环
        asyncio.create_task(self._process_message_queue())
    
    async def handle_incoming_message(self, message: Message, sender_connection):
        """处理接收到的消息"""
        try:
            # 验证发送者身份
            if not await self._verify_sender(message.sender_id, sender_connection):
                await self._send_error(sender_connection, "认证失败")
                return
            
            # 添加到消息队列
            await self.message_queue.put((message, sender_connection))
            
        except Exception as e:
            await self._send_error(sender_connection, f"处理消息错误: {str(e)}")
    
    async def _process_message_queue(self):
        """异步处理消息队列"""
        while True:
            try:
                message, sender_connection = await self.message_queue.get()
                
                # 路由消息
                delivery_status = await self._route_message(message)
                
                # 发送送达回执给发送者
                await self._send_delivery_receipt(message, sender_connection, delivery_status)
                
                # 标记任务完成
                self.message_queue.task_done()
                
            except Exception as e:
                print(f"消息处理错误: {str(e)}")
                await asyncio.sleep(1)  # 避免忙等待
    
    async def _route_message(self, message: Message) -> List[Dict]:
        """路由消息到接收者"""
        delivery_results = []
        
        if message.is_group_message:
            # 群聊消息路由
            participants = await self._get_conversation_participants(message.conversation_id)
            
            for participant in participants:
                if participant.user_id != message.sender_id:
                    result = await self._deliver_to_user(participant.user_id, message)
                    delivery_results.append({
                        'user_id': participant.user_id,
                        'delivered': result
                    })
        else:
            # 单聊消息路由
            result = await self._deliver_to_user(message.receiver_id, message)
            delivery_results.append({
                'user_id': message.receiver_id,
                'delivered': result
            })
        
        # 存储消息
        await self._store_message(message)
        
        # 处理离线消息
        await self._handle_offline_messages(message, delivery_results)
        
        return delivery_results
    
    async def _deliver_to_user(self, user_id: int, message: Message) -> bool:
        """将消息投递给指定用户"""
        # 检查用户是否在线
        if self.connection_manager.is_user_online(user_id):
            # 直接转发消息
            connection = self.connection_manager.get_user_connection(user_id)
            await connection.send(self._serialize_message(message))
            
            # 更新消息状态为已送达
            await self.message_storage.update_delivery_status(
                message.message_uuid, 
                'delivered'
            )
            return True
        else:
            # 用户离线，存储为离线消息
            await self.message_storage.store_offline_message(
                user_id, 
                message.message_uuid
            )
            return False
    
    async def _store_message(self, message: Message):
        """存储消息到数据库"""
        # 生成唯一消息ID
        if not message.message_uuid:
            message.message_uuid = self._generate_uuid()
        
        # 存储到数据库
        await self.message_storage.store_message(message)
        
        # 缓存近期消息
        await self._cache_recent_message(message)
    
    async def _cache_recent_message(self, message: Message):
        """缓存近期消息到Redis"""
        cache_key = f"conversation:{message.conversation_id}:recent"
        await self.cache_store.lpush(cache_key, self._serialize_message(message))
        await self.cache_store.ltrim(cache_key, 0, 99)  # 保留最近100条消息
        await self.cache_store.expire(cache_key, 3600)  # 1小时过期
    
    async def _handle_offline_messages(self, message: Message, delivery_results: List[Dict]):
        """处理离线消息通知"""
        for result in delivery_results:
            if not result['delivered']:
                # 用户离线，可以发送推送通知
                user = await self.user_storage.get_user(result['user_id'])
                await self._send_push_notification(user, message)
    
    async def handle_user_online(self, user_id: int, connection):
        """处理用户上线事件"""
        # 注册连接
        self.connection_manager.register_user(user_id, connection)
        
        # 更新用户状态
        await self.user_storage.update_user_status(user_id, 'online')
        
        # 拉取离线消息
        await self._push_offline_messages(user_id)
    
    async def handle_user_offline(self, user_id: int):
        """处理用户离线事件"""
        # 注销连接
        self.connection_manager.unregister_user(user_id)
        
        # 更新用户状态
        await self.user_storage.update_user_status(user_id, 'offline')
    
    async def _push_offline_messages(self, user_id: int):
        """推送离线消息给上线用户"""
        offline_messages = await self.message_storage.get_offline_messages(user_id)
        
        if offline_messages:
            connection = self.connection_manager.get_user_connection(user_id)
            
            for message in offline_messages:
                await connection.send(self._serialize_message(message))
                
                # 标记为已送达
                await self.message_storage.update_delivery_status(
                    message.message_uuid, 
                    'delivered'
                )
            
            # 清除离线消息队列
            await self.message_storage.clear_offline_messages(user_id)
    
    def _serialize_message(self, message: Message) -> str:
        """序列化消息为JSON字符串"""
        import json
        from dataclasses import asdict
        
        message_dict = asdict(message)
        message_dict['timestamp'] = message.timestamp.isoformat()
        
        return json.dumps(message_dict)
    
    def _generate_uuid(self) -> str:
        """生成唯一消息ID"""
        import uuid
        return str(uuid.uuid4())
    
    async def _verify_sender(self, sender_id: int, connection) -> bool:
        """验证发送者身份"""
        # 检查连接是否属于该用户
        connected_user_id = self.connection_manager.get_user_from_connection(connection)
        return connected_user_id == sender_id
    
    async def _send_error(self, connection, error_message: str):
        """发送错误消息"""
        error = {
            'type': 'error',
            'message': error_message,
            'timestamp': datetime.now().isoformat()
        }
        await connection.send(json.dumps(error))
    
    async def _send_delivery_receipt(self, message: Message, sender_connection, delivery_results: List[Dict]):
        """发送送达回执给发送者"""
        receipt = {
            'type': 'delivery_receipt',
            'original_message_uuid': message.message_uuid,
            'timestamp': datetime.now().isoformat(),
            'delivery_results': delivery_results
        }
        await sender_connection.send(json.dumps(receipt))
    
    async def _send_push_notification(self, user: User, message: Message):
        """发送推送通知"""
        # 这里可以集成推送服务（如Firebase、APNs等）
        print(f"发送推送通知给用户 {user.username}: 新消息来自 {message.sender_id}")
```

```python
import aiosqlite
from typing import List, Optional, Dict, Any
from datetime import datetime, timedelta
from .models import Message, User, Conversation

class Database:
    """异步数据库操作类"""
    
    def __init__(self, db_path: str = "messaging.db"):
        self.db_path = db_path
        self.db = None
    
    async def connect(self):
        """连接到数据库"""
        self.db = await aiosqlite.connect(self.db_path)
        await self.db.execute("PRAGMA journal_mode=WAL")  # 启用WAL模式提高并发性能
        await self._create_tables()
    
    async def close(self):
        """关闭数据库连接"""
        if self.db:
            await self.db.close()
    
    async def _create_tables(self):
        """创建数据库表"""
        await self.db.executescript("""
            CREATE TABLE IF NOT EXISTS users (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                username VARCHAR(50) UNIQUE NOT NULL,
                password_hash VARCHAR(255) NOT NULL,
                public_key TEXT,
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                last_login TIMESTAMP,
                status ENUM('online', 'offline', 'away') DEFAULT 'offline'
            );
            
            CREATE TABLE IF NOT EXISTS messages (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                message_uuid VARCHAR(36) UNIQUE NOT NULL,
                sender_id INTEGER NOT NULL,
                receiver_id INTEGER NOT NULL,
                conversation_id VARCHAR(100),
                content TEXT NOT NULL,
                message_type ENUM('text', 'image', 'file', 'system') DEFAULT 'text',
                timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                delivery_status ENUM('sent', 'delivered', 'read') DEFAULT 'sent',
                is_read BOOLEAN DEFAULT FALSE,
                metadata JSON,
                FOREIGN KEY (sender_id) REFERENCES users(id),
                FOREIGN KEY (receiver_id) REFERENCES users(id)
            );
            
            CREATE INDEX IF NOT EXISTS idx_messages_conversation ON messages(conversation_id);
            CREATE INDEX IF NOT EXISTS idx_messages_timestamp ON messages(timestamp);
            CREATE INDEX IF NOT EXISTS idx_messages_sender ON messages(sender_id);
            CREATE INDEX IF NOT EXISTS idx_messages_receiver ON messages(receiver_id);
        """)
        await self.db.commit()
    
    async def store_message(self, message: Message) -> int:
        """存储消息到数据库"""
        async with self.db.execute("""
            INSERT INTO messages 
            (message_uuid, sender_id, receiver_id, conversation_id, content, 
             message_type, timestamp, delivery_status, is_read, metadata)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
        """, (
            message.message_uuid,
            message.sender_id,
            message.receiver_id,
            message.conversation_id,
            message.content,
            message.message_type,
            message.timestamp,
            message.delivery_status,
            message.is_read,
            json.dumps(message.metadata) if message.metadata else None
        )) as cursor:
            return cursor.lastrowid
    
    async def get_conversation_history(
        self, 
        conversation_id: str, 
        limit: int = 50, 
        before: Optional[datetime] = None
    ) -> List[Message]:
        """获取会话历史消息"""
        query = """
            SELECT message_uuid, sender_id, receiver_id, conversation_id, 
                   content, message_type, timestamp, delivery_status, is_read, metadata
            FROM messages 
            WHERE conversation_id = ?
        """
        params = [conversation_id]
        
        if before:
            query += " AND timestamp < ?"
            params.append(before)
        
        query += " ORDER BY timestamp DESC LIMIT ?"
        params.append(limit)
        
        messages = []
        async with self.db.execute(query, params) as cursor:
            async for row in cursor:
                messages.append(self._row_to_message(row))
        
        return list(reversed(messages))  # 按时间正序返回
    
    async def get_offline_messages(self, user_id: int) -> List[Message]:
        """获取用户离线消息"""
        async with self.db.execute("""
            SELECT m.* FROM messages m
            JOIN offline_messages o ON m.id = o.message_id
            WHERE o.user_id = ?
            ORDER BY m.timestamp ASC
        """, (user_id,)) as cursor:
            messages = []
            async for row in cursor:
                messages.append(self._row_to_message(row))
            return messages
    
    async def store_offline_message(self, user_id: int, message_uuid: str):
        """存储离线消息"""
        # 首先获取消息ID
        async with self.db.execute("""
            SELECT id FROM messages WHERE message_uuid = ?
        """, (message_uuid,)) as cursor:
            row = await cursor.fetchone()
            if not row:
                raise ValueError(f"消息不存在: {message_uuid}")
            
            message_id = row[0]
        
        # 存储到离线消息队列
        await self.db.execute("""
            INSERT INTO offline_messages (user_id, message_id)
            VALUES (?, ?)
        """, (user_id, message_id))
        await self.db.commit()
    
    async def clear_offline_messages(self, user_id: int):
        """清除用户离线消息"""
        await self.db.execute("""
            DELETE FROM offline_messages WHERE user_id = ?
        """, (user_id,))
        await self.db.commit()
    
    async def update_delivery_status(self, message_uuid: str, status: str):
        """更新消息送达状态"""
        await self.db.execute("""
            UPDATE messages 
            SET delivery_status = ?
            WHERE message_uuid = ?
        """, (status, message_uuid))
        await self.db.commit()
    
    async def mark_as_read(self, message_uuid: str, user_id: int):
        """标记消息为已读"""
        await self.db.execute("""
            UPDATE messages 
            SET is_read = TRUE 
            WHERE message_uuid = ? AND receiver_id = ?
        """, (message_uuid, user_id))
        await self.db.commit()
    
    def _row_to_message(self, row) -> Message:
        """将数据库行转换为Message对象"""
        return Message(
            message_uuid=row[0],
            sender_id=row[1],
            receiver_id=row[2],
            conversation_id=row[3],
            content=row[4],
            message_type=row[5],
            timestamp=datetime.fromisoformat(row[6]) if isinstance(row[6], str) else row[6],
            delivery_status=row[7],
            is_read=bool(row[8]),
            metadata=json.loads(row[9]) if row[9] else None
        )
```

```java
@Service
@Transactional
public class GroupServiceImpl implements GroupService {
    
    @Autowired
    private GroupRepository groupRepository;
    
    @Autowired
    private GroupMemberRepository memberRepository;
    
    @Autowired
    private UserService userService;
    
    @Override
    public GroupVO createGroup(Long userId, CreateGroupRequest request) {
        // 1. 验证用户身份
        User user = userService.getUserById(userId);
        
        // 2. 创建群组实体
        Group group = new Group();
        group.setGroupName(request.getGroupName());
        group.setGroupDesc(request.getGroupDesc());
        group.setOwnerId(userId);
        group.setGroupAvatar(generateDefaultAvatar());
        
        // 3. 保存群组
        Group savedGroup = groupRepository.save(group);
        
        // 4. 创建群主记录
        GroupMember ownerMember = new GroupMember();
        ownerMember.setGroupId(savedGroup.getId());
        ownerMember.setUserId(userId);
        ownerMember.setRole(RoleEnum.OWNER.getValue());
        ownerMember.setNickname(user.getNickname());
        memberRepository.save(ownerMember);
        
        // 5. 添加初始成员
        if (request.getInitialMembers() != null) {
            for (Long memberId : request.getInitialMembers()) {
                addMemberToGroup(savedGroup.getId(), memberId);
            }
        }
        
        // 6. 生成邀请码
        String inviteCode = generateInviteCode(savedGroup.getId());
        
        return GroupVO.fromEntity(savedGroup, inviteCode);
    }
    
    @Override
    public void joinGroup(Long userId, Long groupId, String inviteCode) {
        // 1. 验证群组状态
        Group group = groupRepository.findById(groupId)
                .orElseThrow(() -> new GroupNotFoundException(groupId));
        
        // 2. 检查是否已是成员
        if (memberRepository.existsByGroupIdAndUserId(groupId, userId)) {
            throw new AlreadyInGroupException(groupId);
        }
        
        // 3. 检查人数限制
        long memberCount = memberRepository.countByGroupIdAndStatus(groupId, 1);
        if (memberCount >= group.getMaxMembers()) {
            throw new GroupFullException(groupId);
        }
        
        // 4. 添加成员
        addMemberToGroup(groupId, userId);
        
        // 5. 发送系统消息
        sendSystemMessage(groupId, 
            MessageType.GROUP_JOIN,
            String.format("%s 加入了群聊", userService.getNickname(userId))
        );
    }
    
    private void addMemberToGroup(Long groupId, Long userId) {
        User user = userService.getUserById(userId);
        
        GroupMember member = new GroupMember();
        member.setGroupId(groupId);
        member.setUserId(userId);
        member.setRole(RoleEnum.MEMBER.getValue());
        member.setNickname(user.getNickname());
        
        memberRepository.save(member);
    }
}
```

```java
@Component
public class GroupMessageHandler extends TextWebSocketHandler {
    
    @Autowired
    private GroupService groupService;
    
    @Autowired
    private MessageService messageService;
    
    @Autowired
    private UserSessionManager sessionManager;
    
    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) {
        try {
            // 1. 解析消息
            GroupMessageRequest request = parseMessage(message.getPayload());
            Long userId = getUserIdFromSession(session);
            
            // 2. 验证用户是否在群组中
            if (!groupService.isMemberOfGroup(userId, request.getGroupId())) {
                sendErrorMessage(session, "您不是群成员");
                return;
            }
            
            // 3. 检查是否被禁言
            if (groupService.isMuted(userId, request.getGroupId())) {
                sendErrorMessage(session, "您已被禁言");
                return;
            }
            
            // 4. 保存消息到数据库
            GroupMessage savedMessage = messageService.saveGroupMessage(
                request.getGroupId(),
                userId,
                request.getPayload()
            );
            
            // 5. 广播消息给群内所有在线成员
            GroupMessageResponse response = buildResponse(savedMessage);
            broadcastToGroup(request.getGroupId(), response, userId);
            
            // 6. 推送离线通知给不在线成员
            pushOfflineNotification(request.getGroupId(), userId, savedMessage);
            
        } catch (Exception e) {
            log.error("处理群消息失败", e);
            sendErrorMessage(session, "消息发送失败");
        }
    }
    
    private void broadcastToGroup(Long groupId, GroupMessageResponse message, Long senderId) {
        // 获取群组内所有在线成员
        List<Long> onlineMembers = groupService.getOnlineMembers(groupId, senderId);
        
        for (Long memberId : onlineMembers) {
            WebSocketSession memberSession = sessionManager.getSession(memberId);
            if (memberSession != null && memberSession.isOpen()) {
                try {
                    memberSession.sendMessage(new TextMessage(
                        objectMapper.writeValueAsString(message)
                    ));
                } catch (Exception e) {
                    log.error("推送消息给用户{}失败", memberId, e);
                }
            }
        }
    }
}
```

```typescript
    return response.data;

  name: 'group',
  initialState: {
    groups: [],
    currentGroup: null,
    messages: [],
    loading: false,
    error: null
  } as GroupState,
  reducers: {
    setCurrentGroup: (state, action: PayloadAction<Group>) => {
      state.currentGroup = action.payload;
    },
    addMessage: (state, action: PayloadAction<GroupMessage>) => {
      state.messages.unshift(action.payload);
      // 限制消息数量
      if (state.messages.length > 100) {
        state.messages.pop();
      }
    },
    updateGroup: (state, action: PayloadAction<Group>) => {
      const index = state.groups.findIndex(g => g.id === action.payload.id);
      if (index !== -1) {
        state.groups[index] = action.payload;
      }
    }
  },
  extraReducers: (builder) => {
    builder
      .addCase(fetchMessages.pending, (state) => {
        state.loading = true;
      })
      .addCase(fetchMessages.fulfilled, (state, action) => {
        state.loading = false;
        state.messages = [...action.payload, ...state.messages];
      })
      .addCase(fetchMessages.rejected, (state, action) => {
        state.loading = false;
        state.error = action.error.message || '获取消息失败';
      });
  }
});
```

#### 3.3.1 消息分页与缓存
```typescript
// services/messageCache.ts
class MessageCache {
  private cache: Map<number, GroupMessage[]> = new Map();
  private maxSize: number = 1000;
  
  getMessages(groupId: number): GroupMessage[] {
    return this.cache.get(groupId) || [];
  }
  
  addMessage(groupId: number, message: GroupMessage): void {
    let messages = this.cache.get(groupId) || [];
    
    // 避免重复添加
    if (!messages.some(m => m.id === message.id)) {
      messages.unshift(message);
      
      // 保持缓存大小
      if (messages.length > this.maxSize) {
        messages = messages.slice(0, this.maxSize);
      }
      
      this.cache.set(groupId, messages);
    }
  }
  
  loadMessages(groupId: number, newMessages: GroupMessage[]): void {
    const existing = this.getMessages(groupId);
    const merged = [...newMessages, ...existing];
    
    // 去重并排序
    const unique = [...new Map(merged.map(m => [m.id, m])).values()];
    unique.sort((a, b) => b.createTime - a.createTime);
    
    this.cache.set(groupId, unique);
  }
}

export const messageCache = new MessageCache();
```

```java
// MessageQueueService.java
@Service
public class MessageQueueService {
    
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    @Autowired
    private PushNotificationService pushService;
    
    /**
     * 发送群消息到队列
     */
    public void sendGroupMessage(Long groupId, GroupMessage message) {
        // 1. 发送到消息队列，异步处理
        GroupMessageEvent event = new GroupMessageEvent(
            groupId,
            message,
            System.currentTimeMillis()
        );
        
        rabbitTemplate.convertAndSend(
            "group.message.exchange",
            "group.message",
            event
        );
        
        // 2. 推送离线通知
        List<Long> offlineMembers = groupService.getOfflineMembers(groupId);
        for (Long memberId : offlineMembers) {
            pushService.sendPushNotification(
                memberId,
                buildPushPayload(message)
            );
        }
    }
    
    @RabbitListener(queues = "group.message.queue")
    public void handleGroupMessage(GroupMessageEvent event) {
        try {
            // 1. 存储消息到数据库
            messageRepository.save(event.getMessage());
            
            // 2. 更新会话列表
            conversationService.updateConversation(
                event.getGroupId(),
                event.getMessage()
            );
            
            // 3. 更新未读消息计数
            unreadService.incrementUnreadCount(
                event.getGroupId(),
                event.getMessage().getSenderId()
            );
            
        } catch (Exception e) {
            log.error("处理群消息失败", e);
            // 发送到死信队列处理
            sendToDeadLetterQueue(event);
        }
    }
}
```
