## 技术架构

- **AI 模型**: MiMo v2.5 Pro
- **并发数**: 16 个 Agent
- **语言**: Python
- **框架**: asyncio + aiohttp

## 快速开始

```bash
# 启动任务
python mimo_perfect.py

# 监控进度
python mimo_perfect_monitor.py
```
